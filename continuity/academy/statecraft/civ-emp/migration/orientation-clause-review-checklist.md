## Core Clause Checks

Run these eight checks on any serious draft.

### 1. Object Check

Can you name what kind of clause this is trying to be?

- settlement carry
- access / room architecture
- contact procedure
- bounded coercion
- guarantor or enforcement design
- relief / review / rollback mechanism

If you cannot name the object cleanly, the clause is probably still carrying multiple tasks at once.

### 2. Bounded-End Check

What condition would make the clause count as enough?

Ask:

- what bounded political or strategic result is this language trying to produce?
- what would later carriers point to as proof that the clause had done its job?

If the clause can justify continuation more easily than completion, it is underbounded.

### 3. Carrier Check

Who actually carries this clause after the initiating summit, shock, or coalition moment passes?

Ask:

- which institution, guarantor, ministry, alliance body, corridor authority, mediator, or state carrier owns implementation?
- can later actors inherit the clause without inventing a new story for why it matters?

If the clause has admirable language but no believable inheritor, it is theatrical.

### 4. Geography Check

What map becomes more inhabitable if this clause succeeds?

Ask:

- what route, corridor, port, strait, inspection path, border, or access pattern changes in lived practice?
- who can actually move, review, verify, or breathe more easily because of the clause?

If the text improves while the room or route stays practically the same, the clause is probably decorative.

### 5. Contact-Procedure Check

What living procedure keeps the clause legible while pressure or implementation is active?

Ask:

- what hotline, inspection, review, incident, mediator, or reciprocal-reset channel keeps misunderstanding from outrunning the draft?
- does the clause depend on an inherited procedural world that no longer really exists?

If the clause borrows seriousness from dead procedure, it is false-governed.

### 6. Lane-Specific Falsifier Check

Which lane would reject this clause first, and why?

Use the current comparison surfaces:

- [settlement-room lane comparison](canonical-family-settlement-room-lane-comparison.md)
- [escalation-governance lane comparison](canonical-family-escalation-governance-lane-comparison.md)
- [continuity / self-misread lane comparison](canonical-family-continuity-misread-lane-comparison.md)

Test the draft against the live lane-specific falsifiers:

- America: hidden authorship or unspeakable stop conditions
- Russia: recognition without equilibrium, or deterrent seriousness without reciprocity
- China: humiliating visibility, or quiet leverage already reclassified publicly
- Iran: permission-based inclusion, or restraint that now reads as exposure

If one lane would falsify the clause immediately, the language is not yet robust enough for a cross-lane claim.

### 7. Counterweight Check

What keeps the clause from becoming a one-way permission structure?

Ask:

- what review, rollback, reciprocity, exposure limit, or successor check prevents drift into managed hierarchy?
- what visible condition would force reconsideration rather than automatic extension?

If the clause only empowers continuation and never names a disciplined brake, it will drift.

### 8. Plain-Statement Check

Can the clause be stated plainly without losing its real architecture?

Ask:

- can you explain the clause in ordinary language to a serious outsider?
- does the simple version still preserve the same carrier, map, and stop-condition logic?

If the clause only sounds persuasive at high abstraction, it is probably still hiding a structural hole.

## Settlement-Specific Add-On

If the clause belongs mainly to settlement-room design, add these four tests:

1. Does the room become more inhabitable, not merely more politely described?
2. Is inclusion backed by access rather than ceremonial presence?
3. Can later carriers own the settlement without concealed outside authorship?
4. Which lane would experience the draft first as hidden authorship, false recognition, humiliating visibility, or permission-based inclusion?

If these cannot be answered, return to:

- [canonical-family-settlement-room-architecture.md](canonical-family-settlement-room-architecture.md)
- [canonical-family-settlement-room-lane-comparison.md](canonical-family-settlement-room-lane-comparison.md)

## Escalation-Specific Add-On

If the clause belongs mainly to escalation governance, add these four tests:

1. Is the stopping rule as real as the escalation ladder?
2. Is the containing procedure alive now, not merely remembered from an older order?
3. Does the clause keep quiet leverage quiet, reciprocal deterrence reciprocal, and restraint legible?
4. Which lane would experience the draft first as unspeakable stopping, dead reciprocity, public reclassification, or exposed restraint?

If these cannot be answered, return to:

- [canonical-family-escalation-governance.md](canonical-family-escalation-governance.md)
- [canonical-family-escalation-governance-lane-comparison.md](canonical-family-escalation-governance-lane-comparison.md)

## Continuity-Specific Add-On

If the clause belongs mainly to continuity review, inherited plausibility, or self-misread correction, add these four tests:

1. What inherited memory is still classifying the clause as prudent or unserious before policy argument begins?
2. What present carrier makes that inherited grammar materially alive?
3. Is the draft auditing carrying capacity, or only repeating inherited seriousness?
4. Which lane would experience the draft first as false authorization, false room, false quiet capacity, or false reopening?

If these cannot be answered, return to:

- [canonical-family-continuity-misread-architecture.md](canonical-family-continuity-misread-architecture.md)
- [canonical-family-continuity-misread-lane-comparison.md](canonical-family-continuity-misread-lane-comparison.md)

## Quick Review Sequence

Use this shorter sequence when you need a fast but serious pass:

1. What is the clause trying to do?
2. What counts as enough?
3. Who carries it?
4. What map or procedure changes?
5. Which lane falsifies it first?
6. What keeps it from drifting?

If any of those six cannot be answered cleanly, the draft is not ready to trust.
