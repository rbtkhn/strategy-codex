# Civilizational Pattern To Statecraft
<!-- word_count: 416 -->

Canonical hinge:

> Civilizational pattern and narrative become statecraft only when converted into authority, restraint, and settlement.

Short form:

> pattern / narrative -> authority / restraint / settlement

Use this sheet when a PH-CIV pattern, historical analogy, civilizational memory, legitimacy story, or political narrative is becoming material for a treaty, policy paper, negotiation brief, crisis memo, or statecraft transaction.

## Conversion Rule

PH-CIV supplies recurrence, story, legitimacy, and memory. Academy-statecraft must convert that input into:

- **Authority** - who can command, carry, authorize, enforce, or inherit the instrument.
- **Restraint** - where the action stops, what is enough, and what overreach must be prevented.
- **Settlement** - the durable arrangement, bargain, recognition formula, compliance path, or return to equilibrium.

If a historical pattern cannot name all three, it remains commentary or warning. It is not yet statecraft.

## Authority

Ask:

- Which current government claims authority?
- Which current state institution can carry the instrument?
- Which predecessor institutions, geography, or civilizational memory support legitimacy?
- What possible successor authority could inherit the instrument if the current regime changes?
- Who commands, implements, reviews, and can refuse?

## Restraint

Ask:

- What is enough?
- Which ambition would create the next balancing coalition?
- Which adversary must not be unified with another adversary?
- Which ally or partner must be restrained?
- What scope boundary prevents the instrument from becoming crusade, drift, or emergency permanence?

## Settlement

Ask:

- What durable arrangement survives the immediate crisis?
- What concession can be accepted without humiliation?
- What compliance path, review clause, relief sequence, or recognition formula makes the settlement real?
- What lets each party claim prudence rather than surrender?
- What event would require reopening the settlement?

## Transaction Use

When a statecraft transaction uses civilizational pattern or narrative, include a compact line:

```text
Pattern / narrative: ...
Authority: ...
Restraint: ...
Settlement: ...
```

Then continue into the normal transaction template.

## Anti-Patterns

- **Analogy as prophecy:** assuming a pattern must repeat exactly.
- **Historical nostalgia:** treating memory as policy without a carrier.
- **Institution-free insight:** naming what should happen without who can do it.
- **Unlimited crusade:** letting a real pattern justify boundless aims.
- **No-settlement policy:** treating escalation, sanctions, blockade, or emergency authority as a permanent condition.

## Output

Produce one compact WORK artifact:

- a transaction preface;
- a treaty preamble discipline note;
- a policy memo paragraph;
- a negotiation brief assumption;
- a settlement path;
- or a warning that the pattern is not yet statecraft.
