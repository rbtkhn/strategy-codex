# Mutation Statecraft
<!-- word_count: 905 -->


## Purpose

Use this sheet when a familiar object keeps its name but changes its operating function under pressure.

The governing question:

**What has this object become?**

Statecraft often fails when it treats a changed instrument as if it still had its original bounded function. Mutation statecraft watches for the threshold where adaptation becomes a new strategic role.

## Core Rule

Do not classify only the object. Classify the function change.

The practical law:

**Every state mutates when its strength overuses itself.**

America's strength is lawful reach. Russia's strength is depth. China's strength is order. Iran's strength is dignity. Each becomes dangerous when it stops being a strength and becomes a trap.

Original identity may remain stable while operational meaning mutates:

- alliance -> containment lattice.
- trade -> dependency channel.
- peacekeeping -> tutelage.
- infrastructure -> sovereignty claim.
- deterrence -> escalation platform.
- recognition -> humiliation trap.
- technology cooperation -> denial architecture.
- energy purchase -> sanctions-resistance corridor.
- development assistance -> extraction or ideological suppression.
- defensive screening -> platform / identity control.

## Mutation Test

| Field | Question |
|---|---|
| Object | What familiar object is being discussed? |
| Original function | What bounded purpose did it claim or historically serve? |
| New function | What new role is being attached under pressure? |
| Trigger evidence | What language, basing, logistics, sensors, payments, insurance, supply chains, law, command, exercises, ownership, or implementation channels show the shift? |
| Defensive reading | Who can plausibly read the mutation as adaptation, resilience, deterrence, or stabilization? |
| Threatening reading | Who can plausibly read it as containment, tutelage, humiliation, extraction, dependency, escalation, or control? |
| Threshold formula | What sentence separates tolerable adaptation from strategic mutation? |

## Naming Fight

Mutation conflicts are often fights over what the object is allowed to be called.

Ask:

- Who benefits from calling the object unchanged?
- Who benefits from calling it mutated?
- Which label preserves legitimacy?
- Which label creates permission for countermeasures?
- What concrete evidence would make the mutation claim hard to dismiss?

Examples:

- Washington calls U.S.-South Korea alliance modernization defensive; Beijing calls it a containment lattice.
- NATO calls enlargement collective defense; Russia calls it encirclement architecture.
- America calls sanctions rules-based enforcement; targets may call them extraterritorial governance.
- Iran calls nuclear latency sovereign deterrence; America may call it weaponization drift.

## Hex-Lattice Use

Run this after the six arc-lenses vote when the object appears familiar but its role has shifted.

- `god` asks whether the mutation crosses a sacred boundary or forbidden bargain.
- `lit` asks what new story legitimates or captures the mutation.
- `art` asks whether public form hides the operational change.
- `geo` asks what routes, terrain, resources, or infrastructure make the mutation real.
- `war` asks whether the mutation changes command, coercion, sacrifice, or escalation.
- `peace` asks whether the mutation preserves an off-ramp or turns restraint into submission.

## Transaction Use

Use mutation statecraft to decide whether an event is:

- an ordinary instance of an existing transaction object;
- a near fit that uses an existing object by analogy;
- a hidden function change inside an existing transaction;
- a threshold that deserves a recursive candidate;
- a new transaction candidate only if the mutation creates a distinct contested mechanism.

For each transaction, ask:

```markdown
What does this transaction become if it mutates?
```

Do not create a new transaction merely because a mutation is imaginable. Create or recommend a new transaction only when the mutation produces a distinct contested mechanism with actors, settlement spine, entropy signal, and recursive utility.
