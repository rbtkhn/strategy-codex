# Russia Civilization Seed Patterns
<!-- word_count: 191 -->

These seeds translate CIV-MEM into Russia-lane civilization patterns. State rules should draw from these patterns and the Russia empire folder, not directly from CIV-MEM.

## Encirclement And Security Depth

- **CIV-MEM pointers:** `research/repos/civilization_memory/content/civilizations/RUSSIA/MEM–RELEVANCE–RUSSIA.md`; `research/repos/civilization_memory/content/civilizations/RUSSIA/CIV–CORE–RUSSIA.md`; `research/repos/civilization_memory/content/civilizations/RUSSIA/MEM–RUSSIA–GOLDEN–HORDE.md`; `research/repos/civilization_memory/content/civilizations/RUSSIA/MEM–RUSSIA–MUSCOVY.md`.
- **Pattern:** Security depth is treated as survival logic, not just prestige.
- **Statecraft use:** Translate depth claims into reciprocal security zones, infrastructure limits, and inspection rules instead of maximal spheres.
- **Failure mode:** Unlimited depth demands create the encirclement coalition they fear.

## State Continuity Through Collapse

- **CIV-MEM pointers:** `research/repos/civilization_memory/content/civilizations/RUSSIA/CIV–STATE–RUSSIA.md`; `research/repos/civilization_memory/content/civilizations/RUSSIA/MEM–RUSSIA–NOVGOROD–RURIK.md`; `research/repos/civilization_memory/content/civilizations/RUSSIA/MEM–RUSSIA–VARANGIANS.md`; `research/repos/civilization_memory/content/civilizations/RUSSIA/MEM–RUSSIA–KIEVAN–RUS.md`; `research/repos/civilization_memory/content/civilizations/RUSSIA/MEM–RUSSIA–EMPIRE.md`; `research/repos/civilization_memory/content/civilizations/RUSSIA/MEM–RUSSIA–ROMANOV–DYNASTY.md`; `research/repos/civilization_memory/content/civilizations/RUSSIA/MEM–RUSSIA–BOLSHEVIK–REVOLUTION.md`; `research/repos/civilization_memory/content/civilizations/RUSSIA/MEM–RUSSIA–SOVIET–UNION.md`; `research/repos/civilization_memory/content/civilizations/RUSSIA/MEM–RUSSIA–GORBACHEV.md`; `research/repos/civilization_memory/content/civilizations/RUSSIA/MEM–RUSSIA–FEDERATION.md`.
- **Pattern:** Russia reads state continuity through empire, revolution, collapse, and restoration.
- **Statecraft use:** Draft for successor-stable security interests, nuclear continuity, and institutional inheritance rather than a single leader's preference.
- **Failure mode:** A settlement personalizes Russia and cannot survive succession.

## Great-Power Recognition

- **CIV-MEM pointers:** `research/repos/civilization_memory/content/civilizations/RUSSIA/CIV–DOCTRINE–RUSSIA.md`; `research/repos/civilization_memory/content/civilizations/RUSSIA/CIV–INDEX–RUSSIA.md`.
- **Pattern:** Recognition as a civilizational pole is treated as a security condition.
- **Statecraft use:** Offer recognition formulas that distinguish legitimate security voice from unlimited veto.
- **Failure mode:** Recognition language becomes license for overreach or permanent mobilization.
