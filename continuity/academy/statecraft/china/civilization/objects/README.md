This surface is non-authoritative and subject to revision.

Civilization objects hold long-pattern authority grammars for the China lane. They are not biographies and not current officeholder profiles. Use them to connect Chinese civilizational memory to current state carriers, diplomatic transmitters, and transaction authority checks.

## Objects

- [State memory](state-memory.md) - deep Chinese authority memory from Xia / Shang / Zhou dynastic order through Qin-Han standardization, imperial bureaucratic cycles, conquest-dynasty absorption, humiliation / fragmentation, PRC reconstruction, reform development legitimacy, and Xi-era party-state consolidation.

## Use

Open a civilization object before treating a current Chinese leader, party organ, ministry, bank, firm, port, province, PLA signal, or diplomat as sufficient evidence that a settlement can be carried by the state. The object asks what deeper authority burden the current carrier inherits.
