# China State

This surface is non-authoritative and subject to revision.

Use this folder for the current Chinese party-state apparatus: top leadership, party organs, State Council, foreign ministry, PLA, banks, firms, ports, insurers, provinces, and diplomatic channels. This is the near-term institutional layer that turns Chinese civilizational memory and imperial/security striving into quiet pressure, warnings, finance, logistics, forums, guarantees, and implementable instruments.

## Start Here

- [Xi carrier](xi.md) - visible top-leader carrier of party-state authority, unity, rejuvenation, and anti-disorder discipline.
- [Party-state carrier](party-state.md) - institutional implementation surface for party organs, State Council, PLA, banks, firms, ports, insurers, and provinces.
- [Authority carrier objects](objects/) - ministers, party-state officials, military figures, diplomats, and institutional voices whose statements carry Chinese state intent across raw-inputs.
- [Wang Yi](objects/wang-yi.md) - foreign-ministry / national-security continuity carrier for anti-disorder posture, sanctions resistance, security architecture, and quiet mediation.

## Boundary

State is the current-government and institutional-carrier layer. It is not the whole China lane:

- [Civilization](../civilization/) names inherited code, order memory, mandate logic, humiliation memory, unity, geography, fear, and successor-stable state interest.
- [Empire](../empire/) names outward striving for energy, routes, finance, infrastructure, technology, law, dependency instruments, and anti-coercion control.
- [Helix](../helix.md) tests how civilization and empire regulate each other through statecraft.

## Drafting Use

Open this folder when a China-lane instrument depends on who can quietly implement, finance, insure, warn, broker, or restrain a policy. A settlement that cannot pass through this state layer is declaratory diplomacy, not statecraft.
