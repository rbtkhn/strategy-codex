# Workshop Method
<!-- word_count: 309 -->


The method is practical: build study pages and interpretive instruments from stable sources without turning the workshop into another corpus.

## Pattern

**Corpus stays separate from workshop.** OpenITI and Perseus are useful reminders that a corpus should be stable, sourceful, and navigable. Academy theology keeps copied civ-mem texts in `essays/` and `notes/`; workshop files interpret and recombine them.

**Source-sheet study beats abstract inventory.** Sefaria's source-sheet pattern is the nearest model: gather a few relevant anchors, add framing, ask live questions, and make the page usable for a session.

**Practice belongs beside doctrine.** Open Siddur's liturgical pattern matters because theology is lived form, not only propositions. Workshop sheets should include an exercise, output prompt, or operator practice.

**Training modules keep hard material usable.** Translation Academy shows how sacred-text work can become teachable without becoming shallow. Each sheet should be short enough to use in one sitting.

**Layer commentary.** Use five layers when useful: source, plain summary, interpretation, counter-reading, and operator use.

**Synthesize across traditions carefully.** The workshop may compare Christianity, Islam, Hindu, Daoist, Confucian, classical, and modern sources, but it should not flatten them into one doctrine.

**Keep provenance visible.** If a sheet quotes or depends on copied academy material, link it. If it points upstream, name the source path or Bookshelf id.

**Produce instruments.** A good workshop session ends with a reusable lens, question set, distinction, or note, not just an opinion.

## Sheet Template

Use this structure for new sheets:

1. Purpose
2. Core academy links
3. Bookshelf anchors
4. Working questions
5. Counter-reading
6. Output prompts

## Output Rule

Every workshop output should answer at least one of these:

- What pressure is acting here?
- What sacred or moral vocabulary carries it?
- What does this reveal across traditions?
- Where does the interpretation become dangerous?
- What instrument should be reused later?
