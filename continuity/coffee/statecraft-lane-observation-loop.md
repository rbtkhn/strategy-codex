# Statecraft Lane Observation Loop

Use this note to evaluate the first `5-10` real uses of the rewired `coffee -> C. Statecraft` submenu.

The purpose is not telemetry for its own sake. The purpose is to test whether the new civilization-first lane router improves first-hop choice without increasing second-step confusion.

## What To Record

For each real use, capture:

- date or session anchor
- chosen lane: `America`, `China`, `Persia`, or `Russia`
- next surface opened
- smooth continuation or reorientation needed
- whether the operator immediately asked for treaty / policy / negotiation / stress-test shapes
- any lane confusion or label drift worth noting

## Failure Thresholds

- `3 of first 5` uses needing reorientation = submenu wording or lane-entry wording failure
- `3 of first 5` uses immediately asking for treaty / policy options = downstream drafting bridge too hidden
- repeated confusion between the same two lanes = orthogonality failure
- repeated generic Iran-event use of `Persia` without civilizational/statecraft framing = `Persia` label drift

## Refinement Order

If the first batch shows friction, refine in this order:

1. submenu descriptors
2. lane-entry framing sentence
3. best-next-drafting bridge
4. only then restore more visible instrument cues
