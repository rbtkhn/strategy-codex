> **`continuity/`** — durable chronology, accumulation, and notebook continuity (formerly `codex/`). Legacy redirect: [`../codex/README.md`](../codex/README.md). Public project name: **strategy-codex**. [`docs/codex-to-continuity-rename.md`](../docs/codex-to-continuity-rename.md).

## What this is

The **continuity layer** beneath [statecraft](../statecraft/README.md): dated notebook chronology, inbox accumulation, chapters, and thread/page continuity. **`memory.md`** at repo root is the rotatable **session** buffer — not this tree.

**Stack:** [`source-archive/`](../source-archive/README.md) (evidence) → **`continuity/`** (chronology) → [`statecraft/`](../statecraft/README.md) / [`singularity/`](../singularity/README.md) (judgment).

## What belongs here

- `chapters/YYYY-MM/days.md`, inbox, STATUS, thread accumulation
- Notebook templates, watches, compiled-view **sources** (not authority)
- Operator prefs and architecture docs for the notebook layer

## What does not belong here

- Full source captures → `source-archive/`
- Live voice shelves and first-class notes → `statecraft/`
- Session rotation buffer → `memory.md`
