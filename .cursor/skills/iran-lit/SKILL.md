# Iran Lit

`iran-lit` is a WORK-only academy-statecraft command. It applies Iran's civilization literature surface to operational statecraft judgment.

It is not a literature lecture, author biography, or book-summary mode. It converts Iranian / Persian literary memory into tests for dignity, continuity, martyrdom, recognition, non-regime-change assurances, and restraint as sovereignty rather than surrender.

## Boundary

- WORK only; not Record.
- Do not edit CIV-MEM, PH-CIV, transactions, Record surfaces, or lane files.
- Do not invent literary claims beyond the local Iran `lit.md` and state-memory frame unless the operator explicitly asks for source expansion.
- Treat literature as a civilization-layer lens that informs statecraft indirectly through dignity, endurance, recognition, continuity, and settlement constraints.
- Use transaction objects only as tests or analogies; do not create or edit transaction files unless separately requested.

## Calibrated Option Rule

Every A-D option must be specific to the named topic. Do not reuse generic labels when a crisis, transaction, policy question, or clause is named.

Good options name:

- the relevant actor or authority carrier;
- the dignity, recognition, martyrdom, continuity, or surrender problem;
- the proposed output shape;
- the failure mode to test.

Examples:

- `A. Hormuz dignity clause - draft wording that trades transit restraint for recognition without treating Iran as managed`
- `B. Sanctions relief witness test - assess whether sequencing converts endurance into relief or locks martyrdom into veto`
- `C. Beyond-regime memo - test whether a settlement speaks to Iranian continuity rather than only current factional authority`
- `D. Humiliation-lock patch - revise verification language that makes restraint look like surrender`

## Transaction Fit

When the topic names a transaction, near-transaction, or current-event crisis object:

1. Identify whether the topic fits an existing transaction object.
2. Use `iran-lit` to stress-test the Iran lane's acceptance language, not to rerun the full `current-event` workflow.
3. If no transaction fits, name the possible candidate only; do not create files.

For a transaction-aware read, include one option path that uses the transaction directly, such as an Iran-lane objection test, clause revision, or recursive update candidate.

## Handoff Rule

When the operator replies with a letter after an `iran-lit` output, execute the matching calibrated option rather than reprinting the menu.

- `A` = the first topic-specific next move.
- `B` = the second topic-specific next move.
- `C` = the third topic-specific next move.
- `D` = the fourth topic-specific next move.

Keep the handoff within the Iran literature lens unless the operator explicitly shifts to another lens or command.
