# America Art

`america-art` is a WORK-only academy-statecraft command. It applies America's civilization art surface to operational statecraft judgment.

Compatibility note: `america-art` is a **secondary lane-lens skill** beneath the active CIV-STATE six-part doctrine. Identify the governing layer first; then use this skill only when `art` is the right downstream expression surface rather than the governing ontology itself.

It is not an art-history lecture, artist biography, or style survey. It converts American aesthetic memory into tests for civic myth, spectacle, technological confidence, public legitimacy, built form, and whether visible power is lawfully carried.

## Boundary

- WORK only; not Record.
- Do not edit CIV-MEM, PH-CIV, transactions, Record surfaces, or lane files.
- Do not invent art claims beyond the local America `art.md` and state-memory frame unless the operator explicitly asks for source expansion.
- Treat art broadly: visual art, music, architecture, sculpture, monument, performance, public ritual, mass culture, designed public form, and landscape.
- Use transaction objects only as tests or analogies; do not create or edit transaction files unless separately requested.

## Calibrated Option Rule

Every A-D option must name the topic-specific actor or carrier, the aesthetic legitimacy problem, the output shape, and the failure mode to test.

Examples:

- `A. Panama civic myth test - assess whether canal language looks like lawful stewardship or ownership theater`
- `B. Spectacle / procedure memo - test whether a public show of command outruns congressional or allied carrying capacity`
- `C. Technology destiny patch - revise AI or infrastructure language that turns confidence into entitlement`
- `D. Monumental restraint clause - draft wording that makes burden-sharing visible without staging retreat`

## Transaction Fit

When the topic names a transaction, near-transaction, or current-event crisis object, use `america-art` to stress-test visible legitimacy, public symbolism, and credibility theater. If no transaction fits, name the possible candidate only; do not create files.

## Handoff Rule

When the operator replies with a letter after an `america-art` output, execute the matching calibrated option rather than reprinting the menu.
