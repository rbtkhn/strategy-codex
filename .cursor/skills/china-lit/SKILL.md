# China Lit

`china-lit` is a WORK-only academy-statecraft command. It applies China's civilization literature surface to operational statecraft judgment.

It is not a literature lecture, author biography, or book-summary mode. It converts Chinese literary and classical memory into tests for order, harmony, strategic patience, face, anti-disorder legitimacy, and state implementation.

## Boundary

- WORK only; not Record.
- Do not edit CIV-MEM, PH-CIV, transactions, Record surfaces, or lane files.
- Do not invent literary claims beyond the local China `lit.md` and state-memory frame unless the operator explicitly asks for source expansion.
- Treat literature as a civilization-layer lens that informs statecraft indirectly through legitimacy, order, hierarchy, restraint, and settlement constraints.
- Use transaction objects only as tests or analogies; do not create or edit transaction files unless separately requested.

## Calibrated Option Rule

Every A-D option must be specific to the named topic. Do not reuse generic labels when a crisis, transaction, policy question, or clause is named.

Good options name:

- the relevant actor or authority carrier;
- the order, harmony, face, hierarchy, or anti-disorder problem;
- the proposed output shape;
- the failure mode to test.

Examples:

- `A. Taiwan access harmony test - assess whether maritime-access language reduces disorder without recognizing a blockade`
- `B. Strategic patience memo - test whether delay preserves leverage or lets insurance panic become facts on the water`
- `C. Face-saving clause - draft wording that lets Beijing accept restraint without looking managed by Washington`
- `D. Disorder ownership patch - revise language that accidentally makes China publicly responsible for chaos it cannot command`

## Transaction Fit

When the topic names a transaction, near-transaction, or current-event crisis object:

1. Identify whether the topic fits an existing transaction object.
2. Use `china-lit` to stress-test the China lane's acceptance language, not to rerun the full `current-event` workflow.
3. If no transaction fits, name the possible candidate only; do not create files.

For a transaction-aware read, include one option path that uses the transaction directly, such as a China-lane objection test, clause revision, or recursive update candidate.

## Handoff Rule

When the operator replies with a letter after a `china-lit` output, execute the matching calibrated option rather than reprinting the menu.

- `A` = the first topic-specific next move.
- `B` = the second topic-specific next move.
- `C` = the third topic-specific next move.
- `D` = the fourth topic-specific next move.

Keep the handoff within the China literature lens unless the operator explicitly shifts to another lens or command.
