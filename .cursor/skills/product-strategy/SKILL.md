# Product strategy

**Preferred activation:** **`product strategy`**.

**Aliases:** `venture ideation`, `runbook venture ideation`.

Umbrella skill for commercial and purpose-aligned product work. Default composed workflow: [venture-ideation.runbook.md](../../skills/runbooks/venture-ideation.runbook.md).

## Modes

| Mode | Legacy trigger | Action |
|------|----------------|--------|
| **Ideation** | `ideation engine`, `opportunity scan` | Top-3 approval-first briefs from existing lanes |
| **MTP** | `mtp`, `mtp orient` | Purpose governor before scale/ship |
| **Ventures** | `abundance ventures`, `abundance-native` | Abundance-native framing on selected thesis |

Pick one mode or run the full **venture-ideation** runbook chain.

## Ideation mode (summary)

- Gather signals from active lanes, assets, constraints.
- Produce exactly **Top 3** opportunity briefs unless operator widens scope.
- Approval-first: propose only; no spend, publish, or lane spawn without operator upgrade.

## MTP mode (summary)

- One-sentence MTP + pivot test before large ship or automation.
- EXO stack diagnosis and delete-legacy when bureaucracy digitization is the risk.
- Think lane default; no Record merge.

## Ventures mode (summary)

- Apply abundance-native venture framing to operator-selected thesis.
- Ground in existing assets; name liability and jurisdiction.

## Default runbook

For repeated multi-step work, say **`runbook venture ideation`** — composes ideation → MTP → abundance-native ventures.

## Verification / Proof Standard

Do not call this complete unless:

- mode or runbook path is named in the receipt
- Top 3 or MTP governor output is captured
- approval boundaries stated (no silent ship)

Evidence to report:

- selected mode
- runbook or skill chain used
- operator pick among ideation options
