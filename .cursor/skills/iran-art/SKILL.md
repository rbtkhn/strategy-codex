# Iran Art

`iran-art` is a WORK-only academy-statecraft command. It applies Iran's civilization art surface to operational statecraft judgment.

Compatibility note: `iran-art` is a **secondary lane-lens skill** beneath the active CIV-STATE six-part doctrine. Identify the governing layer first; then use this skill only when `art` is the right downstream expression surface rather than the governing ontology itself.

It is not an art-history lecture, artist biography, or style survey. It converts Iranian / Persian aesthetic memory into tests for dignity, sacred legitimacy, recognition, protected space, beauty as endurance, and whether technical language treats Iran as a civilization or a managed file.

## Boundary

- WORK only; not Record.
- Do not edit CIV-MEM, PH-CIV, transactions, Record surfaces, or lane files.
- Do not invent art claims beyond the local Iran `art.md` and state-memory frame unless the operator explicitly asks for source expansion.
- Treat art broadly: architecture, garden, sculpture, relief, miniature, calligraphy, music, shrine, sacred geometry, city, ceremony, and public form.
- Use transaction objects only as tests or analogies; do not create or edit transaction files unless separately requested.

## Calibrated Option Rule

Every A-D option must name the topic-specific actor or carrier, the aesthetic legitimacy problem, the output shape, and the failure mode to test.

Examples:

- `A. Hormuz recognition form - assess whether transit restraint can be staged as dignity, not submission`
- `B. Sacred-space verification memo - test whether inspection language protects sovereignty or violates reverence`
- `C. Beauty-as-endurance patch - revise sanctions language that converts pressure into refusal`
- `D. Civilizational respect clause - draft recognition wording that avoids managed-file humiliation`

## Transaction Fit

When the topic names a transaction, near-transaction, or current-event crisis object, use `iran-art` to stress-test recognition, protected dignity, sacred legitimacy, and beauty as endurance. If no transaction fits, name the possible candidate only; do not create files.

## Handoff Rule

When the operator replies with a letter after an `iran-art` output, execute the matching calibrated option rather than reprinting the menu.
