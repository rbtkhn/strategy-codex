# Russia Art

`russia-art` is a WORK-only academy-statecraft command. It applies Russia's civilization art surface to operational statecraft judgment.

Compatibility note: `russia-art` is a **secondary lane-lens skill** beneath the active CIV-STATE six-part doctrine. Identify the governing layer first; then use this skill only when `art` is the right downstream expression surface rather than the governing ontology itself.

It is not an art-history lecture, artist biography, or style survey. It converts Russian aesthetic memory into tests for ceremonial dignity, sacred / imperial form, sacrifice, recognition, endurance, and beauty under pressure.

## Boundary

- WORK only; not Record.
- Do not edit CIV-MEM, PH-CIV, transactions, Record surfaces, or lane files.
- Do not invent art claims beyond the local Russia `art.md` and state-memory frame unless the operator explicitly asks for source expansion.
- Treat art broadly: icon, liturgy, architecture, music, ballet, monument, museum, ceremony, performance, and public form.
- Use transaction objects only as tests or analogies; do not create or edit transaction files unless separately requested.

## Calibrated Option Rule

Every A-D option must name the topic-specific actor or carrier, the aesthetic legitimacy problem, the output shape, and the failure mode to test.

Examples:

- `A. Ceasefire ceremony test - assess whether signing form gives Russia recognition without borderland veto`
- `B. Sacrifice aesthetics memo - test whether endurance language is bargaining leverage or refusal logic`
- `C. Monumental overreach patch - revise wording that turns dignity into sanctified escalation`
- `D. Recognition stagecraft clause - draft language for formal respect without imperial concession`

## Transaction Fit

When the topic names a transaction, near-transaction, or current-event crisis object, use `russia-art` to stress-test ceremonial dignity, symbolic recognition, and sacrifice aesthetics. If no transaction fits, name the possible candidate only; do not create files.

When the operator replies with a letter after a `russia-art` output, execute the matching calibrated option rather than reprinting the menu.
