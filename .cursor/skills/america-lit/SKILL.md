# America Lit

`america-lit` is a WORK-only academy-statecraft command. It applies America's civilization literature surface to operational statecraft judgment.

It is not a literature lecture, author biography, or book-summary mode. It converts American literary memory into tests for republic conscience, rights language, dissent, constitutional restraint, anti-imperial critique, and whether power still sounds lawful.

## Boundary

- WORK only; not Record.
- Do not edit CIV-MEM, PH-CIV, transactions, Record surfaces, or lane files.
- Do not invent literary claims beyond the local America `lit.md` and state-memory frame unless the operator explicitly asks for source expansion.
- Treat literature as a civilization-layer lens that informs statecraft indirectly through legitimacy, consent, dissent, rights, restraint, and settlement constraints.
- Use transaction objects only as tests or analogies; do not create or edit transaction files unless separately requested.

## Calibrated Option Rule

Every A-D option must be specific to the named topic. Do not reuse generic labels when a crisis, transaction, policy question, or clause is named.

Good options name:

- the relevant actor or authority carrier;
- the republic, dissent, consent, anti-imperial, or constitutional-restraint problem;
- the proposed output shape;
- the failure mode to test.

Examples:

- `A. Panama republic test - assess whether transit-sovereignty language sounds like lawful stewardship or canal control politics`
- `B. War-fatigue memo - test whether public exhaustion is a restraint signal or a credibility-theater obstacle`
- `C. Anti-imperial clause - draft wording that protects transit reliability without making ownership politics the point`
- `D. Liberty-as-empire patch - revise language that turns procedural restraint into enforcement drift`

## Transaction Fit

When the topic names a transaction, near-transaction, or current-event crisis object:

1. Identify whether the topic fits an existing transaction object.
2. Use `america-lit` to stress-test the America lane's acceptance language, not to rerun the full `current-event` workflow.
3. If no transaction fits, name the possible candidate only; do not create files.

For a transaction-aware read, include one option path that uses the transaction directly, such as an America-lane objection test, clause revision, or recursive update candidate.

## Handoff Rule

When the operator replies with a letter after an `america-lit` output, execute the matching calibrated option rather than reprinting the menu.

- `A` = the first topic-specific next move.
- `B` = the second topic-specific next move.
- `C` = the third topic-specific next move.
- `D` = the fourth topic-specific next move.

Keep the handoff within the America literature lens unless the operator explicitly shifts to another lens or command.
