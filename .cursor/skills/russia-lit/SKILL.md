# Russia Lit

`russia-lit` is a WORK-only academy-statecraft command. It applies Russia's civilization literature surface to operational statecraft judgment.

It is not a literature lecture, author biography, or book-summary mode. It converts Russian literary memory into tests for recognition, humiliation, sacrifice, moral injury, settlement language, and state authority.

## Boundary

- WORK only; not Record.
- Do not edit CIV-MEM, PH-CIV, transactions, Record surfaces, or lane files.
- Do not invent literary claims beyond the local Russia `lit.md` and state-memory frame unless the operator explicitly asks for source expansion.
- Treat literature as a civilization-layer lens that informs statecraft indirectly through legitimacy, dignity, sacrifice, and settlement constraints.
- Use transaction objects only as tests or analogies; do not create or edit transaction files unless separately requested.

## Calibrated Option Rule

Every A-D option must be specific to the named topic. Do not reuse generic labels when a crisis, transaction, policy question, or clause is named.

Good options name:

- the relevant actor or authority carrier;
- the recognition, humiliation, sacrifice, or compromise problem;
- the proposed output shape;
- the failure mode to test.

Examples:

- `A. Ceasefire dignity clause - draft wording that gives Russia recognition of security concern without conceding permanent border revision`
- `B. Sacrifice veto test - assess whether Great Patriotic War memory is being used as bargaining leverage or as refusal logic`
- `C. State / soul memo - test whether a proposed settlement preserves Russian state continuity while lowering human cost`
- `D. Overfed grievance patch - revise a clause that accidentally confirms encirclement or humiliation narratives`

## Transaction Fit

When the topic names a transaction, near-transaction, or current-event crisis object:

1. Identify whether the topic fits an existing transaction object.
2. Use `russia-lit` to stress-test the Russia lane's acceptance language, not to rerun the full `current-event` workflow.
3. If no transaction fits, name the possible candidate only; do not create files.

For a transaction-aware read, include one option path that uses the transaction directly, such as a Russia-lane objection test, clause revision, or recursive update candidate.

## Handoff Rule

When the operator replies with a letter after a `russia-lit` output, execute the matching calibrated option rather than reprinting the menu.

- `A` = the first topic-specific next move.
- `B` = the second topic-specific next move.
- `C` = the third topic-specific next move.
- `D` = the fourth topic-specific next move.

Keep the handoff within the Russia literature lens unless the operator explicitly shifts to another lens or command.
