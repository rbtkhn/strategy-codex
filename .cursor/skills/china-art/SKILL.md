# China Art

`china-art` is a WORK-only academy-statecraft command. It applies China's civilization art surface to operational statecraft judgment.

Compatibility note: `china-art` is a **secondary lane-lens skill** beneath the active CIV-STATE six-part doctrine. Identify the governing layer first; then use this skill only when `art` is the right downstream expression surface rather than the governing ontology itself.

It is not an art-history lecture, artist biography, or style survey. It converts Chinese aesthetic memory into tests for disciplined form, harmony, hierarchy, refined restraint, infrastructural legitimacy, face, and quiet execution.

## Boundary

- WORK only; not Record.
- Do not edit CIV-MEM, PH-CIV, transactions, Record surfaces, or lane files.
- Do not invent art claims beyond the local China `art.md` and state-memory frame unless the operator explicitly asks for source expansion.
- Treat art broadly: calligraphy, painting, music, architecture, sculpture, ritual object, garden, city, landscape, ceremony, infrastructure, and public form.
- Use transaction objects only as tests or analogies; do not create or edit transaction files unless separately requested.

## Calibrated Option Rule

Every A-D option must name the topic-specific actor or carrier, the aesthetic legitimacy problem, the output shape, and the failure mode to test.

Examples:

- `A. Taiwan disciplined-form test - assess whether maritime access can be managed as order without blockade recognition`
- `B. Face-saving refinement memo - test whether quiet implementation preserves dignity or looks like containment`
- `C. Infrastructure legitimacy clause - draft wording around ports, insurers, or routes as stability rather than command`
- `D. Harmony-mask patch - revise language that hides coercion under refined order`

## Transaction Fit

When the topic names a transaction, near-transaction, or current-event crisis object, use `china-art` to stress-test face, refined restraint, infrastructural legitimacy, and visible versus harmonized order. If no transaction fits, name the possible candidate only; do not create files.

## Handoff Rule

When the operator replies with a letter after a `china-art` output, execute the matching calibrated option rather than reprinting the menu.
