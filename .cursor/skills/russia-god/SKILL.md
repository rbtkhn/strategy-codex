# Russia God

`russia-god` is a WORK-only academy-statecraft command. It applies Russia's civilization `god.md` surface to operational statecraft judgment.

It is not theology, devotional writing, or metaphysical adjudication. It converts Russian sacred legitimacy into tests for forbidden bargains, sacred-safe clause design, humiliation, Orthodoxy / Rus inheritance, suffering / redemption, civilizational sovereignty, and managed-periphery refusal.

## Boundary

- WORK only; not Record.
- Do not edit CIV-MEM, PH-CIV, transactions, Record surfaces, or lane files.
- Do not invent sacred claims beyond the local Russia `god.md` and state-memory frame unless the operator explicitly asks for source expansion.
- Treat sacred legitimacy as a civilization-layer lens that informs statecraft indirectly through ultimate legitimacy, symbolic desecration risk, humiliation, and settlement constraints.
- Use transaction objects only as tests or analogies; do not create or edit transaction files unless separately requested.

## Calibrated Option Rule

Every A-D option must be specific to the named topic. Do not reuse generic labels when a crisis, transaction, policy question, or clause is named.

Good options name:

- the relevant actor or authority carrier;
- the sacred boundary, humiliation, profanation, or managed-periphery problem;
- the proposed output shape;
- the failure mode to test.

Examples:

- `A. Ukraine sacred-continuity test - assess whether ceasefire language touches Rus inheritance without granting borderland veto`
- `B. NATO managed-periphery memo - test whether security guarantees read as equilibrium or tutelage`
- `C. Inspection profanation patch - revise verification language that makes restraint look like spiritual defeat`
- `D. Recognition-without-holy-veto clause - draft wording that respects Russia as a pole while preserving reciprocal limits`

## Transaction Fit

When the topic names a transaction, near-transaction, or current-event crisis object:

1. Identify whether the topic fits an existing transaction object.
2. Use `russia-god` to stress-test the Russia lane's sacred-boundary acceptance language, not to rerun the full `current-event` workflow.
3. If no transaction fits, name the possible candidate only; do not create files.

For a transaction-aware read, include one option path that uses the transaction directly, such as a Russia-lane forbidden-bargain test, sacred-safe clause revision, or recursive update candidate.

## Handoff Rule

When the operator replies with a letter after a `russia-god` output, execute the matching calibrated option rather than reprinting the menu.

- `A` = the first topic-specific next move.
- `B` = the second topic-specific next move.
- `C` = the third topic-specific next move.
- `D` = the fourth topic-specific next move.

Keep the handoff within the Russia sacred-boundary lens unless the operator explicitly shifts to another lens or command.
