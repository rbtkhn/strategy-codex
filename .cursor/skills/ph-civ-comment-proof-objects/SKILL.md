# ph-civ-comment-proof-objects

Use this skill when drafting `ph-civ` Civilization YouTube comments that are meant to prove analytical capability in public.

**Read first:**

- [`docs/skill-write/predictive-history-youtube-comments.md`](../../../docs/skill-write/predictive-history-youtube-comments.md)
- [`docs/archive/skill-work-legacy/work-strategy/predictive-history-comment-rollout/wave-one-civ-01-to-civ-06.md`](../../../docs/archive/skill-work-legacy/work-strategy/predictive-history-comment-rollout/wave-one-civ-01-to-civ-06.md)

## Core rule

The comment is not a summary, not a repo doorway, and not praise. It is a compressed public proof object.

Every comment must:

- state the lecture's governing inversion or deepest move
- argue from at least two specific historical examples
- use those examples to support the lecture thesis rather than decorate it
- end in a larger civilizational implication

## Output contract

- one paragraph
- usually 120-200 words unless the operator sets a tighter cap
- no links
- no visible `statecraft`, `civ-state`, `civ-mem`, `MEM CONNECTIONS`, or other internal vocabulary
- no flattery
- no summary sprawl

## Drafting workflow

1. Extract the lecture's strongest inversion.
2. Choose at least two concrete examples that actually bear argumentative weight.
   - Prefer one or two examples the lecture itself leans on.
   - Add a later written-history echo only if it clarifies the same pattern.
3. Explain why the examples matter.
   - Do not merely list Gobekli Tepe, Troy, Rome, etc.
   - Show what each case demonstrates and how that supports the lecture thesis.
4. Compress to one paragraph with a strong final implication.

## Sequential wave mode

When drafting a run such as `civ-01` through `civ-06`:

- make the comments read like one unfolding essay
- let each comment inherit the prior move and open the next one
- keep the self-reference light
- vary the evidence so the sequence does not feel templated

Use this arc by default for early Civilization waves:

1. sacred imagination before administration
2. religion as a condition of social formation
3. religion as a whole lived world
4. rival sacred orders create rival social logics
5. conquest spreads a durable operating system
6. victorious orders later fracture from within

## Failure checks

Revise if the draft does any of the following:

- uses broad labels like "medieval Christendom" without saying what pattern it proves
- names examples that do not actually support the claim
- sounds like a mini-essay summary instead of a compressed insight
- exposes internal machinery
- breaks the thematic arc of the wave

## Preferred test

Before shipping, ask:

- Are there at least two concrete examples?
- Does each example do reasoning work?
- Could the author of the lecture recognize a real engagement with the thesis?
- Would the paragraph still feel strong if the named examples were removed? If not, the evidence is doing real work.
