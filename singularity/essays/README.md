## Authority Rule

This README is the **canonical prose-discovery surface for compatibility holdings** in `singularity/essays/` — not the default destination for new essays.

Use the classifications below strictly:

- `shelf-native` = current essay-class prose authority for this shelf
- `mirrored legacy promotion` = readable compatibility material while taxonomy settles, but **not canonical prose authority**
- `review-needed` = intentionally present edge case that should not be treated as proof that the shelf taxonomy is fully settled

Only items explicitly marked `shelf-native` should be treated as current shelf-native prose authority.

## Formal Role

Use `singularity/essays/` for:

- more stable singularity arguments
- long-form theses about agency, acceleration, substrate, alignment, displacement, and human meaning
- stand-alone essays that rise above one workshop sheet or one bounded exploratory note

The local distinction is:

- a **singularity essay** should carry a thesis that survives outside the original workshop or month context
- a **singularity note** should preserve one bounded promoted seam without pretending to become the thesis above it

Do **not** use this folder for:

- workshop operating sheets
- source sheets
- raw captures
- root domain-orientation files
- generic AI news capture

## Routing Rule

- use `../notes/` when the piece is exploratory, bounded, workshop-adjacent, route-shaping, or interpretively partial
- use `essays/` when the piece is synthesized enough to stand on its own as a more stable argument or carriage-bearing long-form output

If the argument can travel without the original month or sheet beside it, it is usually essay-class.

Machine-constitutional and source-bearing files stay where they already belong:

- root domain orientation stays at `singularity/`
- workshop operating doctrine stays in `workshop/`
- sheets stay in `workshop/sheets/`
- raw captures stay in `source-archive/`

## Promotion Path

Most singularity essays should come from:

- notes whose promoted seam begins organizing multiple cases
- workshop-born arguments rewritten into carriage-bearing form
- domain-level theses that no longer belong only to one sheet, month, or route

Literature-backed essays may also carry:

- a support cluster
- an evidence matrix
- a short evidence posture naming what the citations can honestly sustain

When the evidence base is too large or heterogeneous for one essay, prefer a
cluster rather than overloading the essay body.
