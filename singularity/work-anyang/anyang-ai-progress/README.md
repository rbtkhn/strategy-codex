# anyang-ai-progress

**Purpose:** Member progress, proof packets, weekly review — evidence-labeled, not vanity joins.

**Lane hub:** [anyang-ai-lanes.md](../anyang-ai-lanes.md)

## Required fields (per member)

| Field | Values |
|---|---|
| `learning_lane` | `foundation` \| `builder` |
| `infra_track` | `china_default` \| `bridge` (optional) |
| `initiation` | `not_started` \| `foundation_done` \| `builder_done` |
| `seven_day_active` | `pending` \| `yes` \| `no` |
| `family_id` | optional household link (e.g. `fam-zhang-01`) — analytics only |
| `family_buddy` | optional Gitee username of in-family helper — not mentor |

## Proof sources

- WeChat screenshots / quotes (pointer files under `evidence/`)
- Gitee URLs (**Builder** and post-graduation Foundation)
- Weekly meeting roll (mentor note)

## Skills rubric

Sponsor-facing outcomes: [skills-rubric.md](skills-rubric.md) — **Not yet / Emerging / Solid** per lane.

## Failure criteria (pilot pause)

From [philanthropist calibration §9](../anyang-philanthropist-calibration.md#9-credibility--controlled-pilot):

- Month 3: &lt;3 individuals at Emerging+ on lane-relevant rows
- Month 6: &lt;2 Solid profiles and no institutional-host path
- Any time: &gt;50% families = one active + passive tag-alongs only
