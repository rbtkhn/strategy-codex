# anyang-ai-foundation (预备轨)

**Learning lane:** members **below** minimal coding readiness — not ready for solo Gitee fork/clone/push in week one.

**Lane hub:** [anyang-ai-lanes.md](../anyang-ai-lanes.md)

---

## Purpose

Reduce drop-off **before** git exists. Foundation members still join `anyang-ai`, attend weekly meetings, and post proof in WeChat — but the **first wins** do not require Gitee.

The mentor uses the **physical room** heavily here: follow-along, buddy seating, no public shame for “basic” questions.

---

## Who belongs here

- No confident terminal / IDE use
- Never created a repo or only submitted zip homework
- Mentor placement says Foundation (see [placement table](../anyang-ai-lanes.md#placement-mentor-week-zero))

Current **students of the Anyang SWE mentor** may still land here — CS class ≠ git fluency. Placement, not assumptions.

---

## Tools (Foundation)

| Tool | Role |
|---|---|
| **WeChat** | All proof posts |
| **Weekly in-person** | Primary learning surface |
| **Domestic AI** (DeepSeek etc.) | Guided prompts on **mentor-prepared** exercises — not repo agents yet |
| **腾讯文档 / 本地 Markdown** (optional) | Personal goal doc before git |
| **Gitee** | **Not required** until graduation to [Builder](../anyang-ai-builder/README.md) |

---

## Foundation initiation bar

Member counts as **Foundation initiation complete** when all are true:

1. Joined WeChat `anyang-ai`; posted intro (name + one-sentence goal).
2. Attended **≥1** weekly session.
3. Completed **one** mentor-defined non-git artifact (examples):
   - fill personal goal template (doc or printed);
   - run a **3-step** domestic-AI exercise (screenshot of prompt + reply);
   - label a mentor demo screenshot with “what I want to learn next.”
4. Posted **完成** or **卡在：…** in WeChat within 48h of that session.

**Not required:** Gitee account, git, local clone.

---

## Graduation to Builder (预备 → 实操)

Mentor (or mentor + peer buddy) signs off when member can:

- [ ] Register Gitee with mentor watching (or confirm existing account)
- [ ] Open terminal or VS Code without freezing
- [ ] Follow written clone steps **once** with ≤2 mentor rescues

Record graduation in progress sheet: `learning_lane=builder`, date, evidence pointer (WeChat screenshot or meeting note).

---

## What mentor must not do

- Skip Foundation and dump full Cici/Gitee README on day one
- Complete git steps **for** the member without a public **stuck** post
- Treat Foundation as “not real anyang-ai” — they count toward cohort activation if bar is met
