# anyang-ai work lanes

WORK only; not Record.

These lanes split the `anyang-ai` operator surface. They are coordination surfaces in strategy-codex — not member Record and not Cici governed state.

**Two orthogonal splits:**

1. **Learning readiness** (this doc’s main addition) — **Foundation** vs **Builder**
2. **Operating territory** — WeChat / Core / Progress (same family as [cici-ai-lanes](../work-cici/cici-ai-lanes.md))

**Do not confuse** learning lanes with the optional **Bridge track** (GitHub + Claude parity) in [anyang-ai-cn-software-stack.md](anyang-ai-cn-software-stack.md) — Bridge is infrastructure advanced, not beginner-vs-ready coding.

---

## Learning lanes (readiness)

| Lane | Chinese label | Who | Default proof |
|---|---|---|---|
| **[Foundation](anyang-ai-foundation/README.md)** | **预备轨** | Below minimal coding: terminal/git fear, no prior repo habit, needs follow-along lab | WeChat + in-room artifacts; **no Gitee week one** |
| **[Builder](anyang-ai-builder/README.md)** | **实操轨** | Minimal coding ready: can register Gitee, clone, edit a file, push with mentor support | Gitee fork + commit + WeChat URL |

### Placement (mentor, week zero)

Mentor assigns **one lane per member** before wave-one kickoff. Signals:

| → Foundation | → Builder |
|---|---|
| Never used git or only copied homework | Has used git or IDE for class/project |
| Unsure what a terminal is | Can open terminal / VS Code when shown once |
| Needs mentor to click through first setup | Can retry setup after one demo |

**Rule:** Default **generous** — place in Foundation if unsure. **Graduation** Foundation → Builder is a named milestone, not shame.

### Operating sentence

**WeChat creates motion; Foundation builds nerve; Builder builds repos; Progress proves what happened.**

## Territory lanes (operator routing)

| Sequence | Lane | Purpose |
|---:|---|---|
| 1 | [anyang-ai-wechat](anyang-ai-wechat/README.md) | WeChat posts, pin, norms, intake — **both** learning lanes |
| 2 | [anyang-ai-core](anyang-ai-core/README.md) | Templates, stack law, Gitee import — **Builder** primary; Foundation uses subset |
| 3 | [anyang-ai-progress](anyang-ai-progress/README.md) | Dashboard, proof packets, weekly review — tag `learning_lane=foundation\|builder` |

### Weekly physical meeting (both lanes)

Same room; **split artifact block**:

- **Foundation table:** typed goal doc, AI chat exercise, screenshot to WeChat — mentor or buddy at shoulder
- **Builder table:** Gitee fork/clone/push — mentor circulates

Do not force Foundation members onto Gitee because Builder members are ready.

## Monthly rhythm

| Week | Foundation emphasis | Builder emphasis |
|---|---|---|
| 1 | Join WeChat; name goal; first **non-git** win (doc + AI prompt) | Gitee account; fork template; first clone |
| 2 | Repeatable check-in; terminal **tour** optional | First commit pushed; domestic AI on local repo |
| 3 | **Graduation attempt** for ready members | 7-day active + peer help |
| 4 | Weekly review; count graduations + Builder initiations | Same review row; separate counts |

---

## Operating rule

Pick the lane that owns the **next concrete action**:

- Silent or scared → **WeChat** + **Foundation**
- Gitee-ready but stuck on git → **Builder** + room
- Activity but untrusted counts → **Progress**

Do not optimize both learning lanes identically every week. Mentor may run **mostly Builder** in wave one if all recruits are CS students — still document placement explicitly.

### Family households

When recruiting **whole families** ([mission § Family recruitment](anyang-community-mission-operator.md#family-recruitment)):

- Assign **each person** their own `learning_lane` — common pattern: parent **Foundation**, teen **Builder**, or two siblings on different lanes.
- In-room seating: family **buddy pairs** at Foundation table are encouraged; proof posts remain **individual**.
- Progress metrics: `activated_individuals / family_units_joined` — not one activation per household.

## Short-term success (phase 1, combined)

Target **5 activated members** total, counting **either**:

- **Foundation complete** — [initiation bar](anyang-ai-foundation/README.md#foundation-initiation-bar), or
- **Builder complete** — [initiation bar](anyang-ai-cn-software-stack.md#phase-1-initiation-checklist-replaces-cici-ob1-day-one-bar)

Plus **7-day active** per lane-specific proof rules.

Optional stretch: **≥2 Foundation → Builder graduations** in first month (proves the ladder works).
