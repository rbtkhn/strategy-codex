# work-anyang — advisor / cohort module (strategy-codex)

## Purpose

**Anyang AI** (`anyang-ai`) is a singularity-native cohort activation program modeled on [cici-ai](../work-cici/cici-community-mission-operator.md), localized for **Anyang, China**: WeChat social room, weekly in-person collaboration, and a professional software-engineer mentor recruiting from his current students.

This folder is the **operator/advisor WORK layer** in strategy-codex. It is **not** any member's Record and does not replace governed state in companion or OB1 instance repositories.
