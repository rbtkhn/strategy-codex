## What this is

A beginner-friendly entry page for the `cici-ai` daily brief flow.

Use it when someone needs to understand, quickly, what the daily brief is for, what counts as proof, and how to re-enter the group without guessing.

## First 3 steps

1. Read the latest daily brief or operator prompt and find the one concrete reply ask.
2. Gather one proof-bearing item:
   - URL
   - screenshot
   - artifact
   - one-line status in the requested format
3. Reply with that proof instead of a general update.

If you are blocked, reply with the exact blocker instead of staying silent.

## What counts as proof

Good proof:

- a GitHub URL
- a screenshot of the fork, commit, or task result
- a posted artifact
- one clearly formatted status line when the brief asks for it

Weak unless confirmed:

- "I'm almost done"
- "I worked on it"
- greetings, reactions, or enthusiasm without visible output

## What the system will ask you for

The daily brief flow usually asks for one of these:

- one artifact from your first task
- one screenshot showing setup or proof
- one URL to visible work
- one exact blocker if you are stuck

The message is short on purpose. It is trying to route the next step, not tell your whole story.

## What it will not do

The brief system will not:

- count self-report as proof by default
- post directly without operator review
- make scholarship, payment, or job promises
- act as Cici's governed instance or durable Record
- hide weak evidence behind polished summary language

## Re-entry rule

If you have been quiet, the easiest re-entry is:

1. read the current ask,
2. post one proof-bearing item,
3. ask one exact question if you are blocked.

Do not wait for a perfect update. A small verified step is enough.
