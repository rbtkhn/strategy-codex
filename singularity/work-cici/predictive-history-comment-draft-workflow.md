# Predictive History Comment Draft Workflow

## Purpose

This is the practical operating flow for turning one Predictive History video into one reviewable comment candidate set and one tracked posting receipt.

This workflow is for the promotion/distribution layer only. It does not modify the `ph-civ` corpus, chapter structure, commentary, or publication pipeline.

## One-Video Workflow

1. Choose a target using [predictive-history-comment-targeting-rubric.md](predictive-history-comment-targeting-rubric.md).
2. Write one sentence answering:
   - what is the lecture really saying?
3. Pick one archetype from [predictive-history-comment-template-pack.md](predictive-history-comment-template-pack.md).
4. Draft `1-3` candidate comments.
5. Score each candidate:
   - doctrine fit
   - specificity
   - usefulness
   - tone
6. Operator picks one final comment.
7. Log it in [predictive-history-comment-tracker.md](predictive-history-comment-tracker.md).
8. After posting, add a public receipt and later reach notes.

## Apprentice-Safe Task Split

Safe tasks for cohort contributors:

- extract the lecture's central claim
- suggest target score
- draft candidate comments
- label candidate archetype
- log tracker rows
- collect posting receipts after operator review

Operator-only tasks:

- final approval
- posting from the live account
- deciding when a comment crosses into public-positioning sensitivity
- handling contentious reply threads

## Close Rule

A pass is only complete when one of these is true:

- the comment was posted and logged
- the comment was parked with a reason
- the target was rejected as low leverage

Do not leave video work in a half-drafted state without tracker notes.
