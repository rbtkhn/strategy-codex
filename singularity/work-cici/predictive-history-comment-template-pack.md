# Predictive History Comment Template Pack

## Purpose

Use these as draft archetypes, not copy-paste defaults. Every posted comment should still be lecture-specific.

## Template Types

### 1. Pattern

Use when the lecture reveals a deeper civilizational or institutional pattern.

```text
What stands out here is not just the event itself, but the pattern behind it: systems keep acting as if older incentives still hold after the underlying environment has changed.
```

### 2. Distinction

Use when one conceptual distinction sharpens the thread.

```text
The useful distinction here is between short-term crisis management and real structural adaptation. A lot of actors can still do the first. Much fewer can do the second.
```

### 3. Bridge

Use when the lecture can be connected to a larger Predictive History frame.

```text
This is one of those topics that gets clearer when you zoom out from the headline level to the civilizational level: legitimacy, coordination, and memory are doing more work here than the rhetoric on the surface.
```

### 4. Counter-Intuition

Use when the less obvious takeaway is stronger than the obvious one.

```text
The interesting thing may be that the visible conflict matters less than the learning process underneath it. Pressure reveals what institutions actually optimize when the cost of pretending gets high enough.
```

### 5. Question

Use when you want to invite serious replies without sounding empty.

```text
The real question may not be whether this is a one-off disruption, but whether it shows that the underlying institutional model is losing its ability to absorb shocks without changing itself.
```

## Draft Workflow

For each target video:

1. write one sentence on the lecture's central claim
2. choose one archetype only
3. draft up to three candidate comments
4. pick the shortest candidate that still says something worth reading

## Quality Checks

Before posting, ask:

- does this sound like a serious human reader?
- is it specific to this lecture?
- does it say something more useful than generic praise?
- would it still be respectable if no one clicked through?
- does it avoid hype, boilerplate, and self-advertising smell?

## Mini Review Labels

- `strong`: specific, sharp, quiet, worth reading
- `usable`: good enough, but slightly generic or wordy
- `weak`: vague, hypey, repetitive, or promotional
