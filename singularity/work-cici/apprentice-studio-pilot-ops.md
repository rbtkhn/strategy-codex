## Lane Ownership

### Telegram

Telegram owns motion.

- ask for one artifact at a time
- keep prompts simple
- avoid broad motivational asks when one concrete task would do
- route confused members toward one safe first assignment

Preferred ask:

`Reply with one artifact only: your listing-QA note, research summary, or message draft.`

### Core

Core owns safety and instructions.

- keep the task menu current
- keep the prompt skeleton stable
- define what is not allowed in month one
- make sure no apprentice is asked to do live customer action without review

### Progress

Progress owns proof.

- collect one proof packet per completed task
- record reviewer disposition
- update weekly counts from artifacts, not vibes
- track returners separately from first-time submissions

## 30-Day Rhythm

### Week 1

- recruit 3-5 apprentices
- assign one safe task each
- require one artifact each
- complete proof packets

### Week 2

- reuse the same task classes with clearer instructions
- compare where confusion dropped and where rescue was still required

### Week 3

- assign one slightly harder supervised task to returners
- watch whether second-pass quality improves

### Week 4

- run the review
- decide whether the loop is reusable
- capture one prompt, rubric, or workflow improvement worth keeping

## Required Evidence

Every completed pilot task should have:

- participant alias or non-sensitive identifier
- task type
- artifact link or evidence pointer
- reviewer status
- reviewer/owner
- follow-up note if needed

Use the existing proof-packet standard. Do not invent a parallel recordkeeping system.

## Weekly Review Questions

Every weekly review should answer:

- what improved because of AI scaffolding?
- what still depended on operator rescue?
- which artifact types are becoming reusable?
- which prompts or instructions caused confusion?

## Stop Conditions

Pause or reset if:

- artifacts are mostly enthusiasm with no real output
- the operator is doing the hard part invisibly
- review burden grows faster than apprentice usefulness
- unsafe customer-facing behavior appears before the gate

## Success Readout

Month-one success means:

- at least 3 participants attempt a real task
- at least 2 evidence-linked task completions
- at least 1 returning participant completes a second task
- at least 1 workflow or prompt improvement is reused across more than one person
