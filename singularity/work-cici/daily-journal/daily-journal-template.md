# Daily Journal Template

Use one file per day at:

`docs/personal/daily-journal/YYYY-MM-DD.md`

```md
# Daily Journal - YYYY-MM-DD

## What I worked on
- 

## What changed
- 

## What is blocked
- 

## What I plan to do next
- 

## Evidence or notes
- GitHub:
- Screenshots:
- Links:
- Other notes:
```

## Rules

- Keep entries short and concrete.
- If something is unknown, write `Needs follow-up` instead of guessing.
- Keep the headings in the same order every day.
- Link to GitHub when possible so progress stays visible to the team.
