# Daily Journal Helper

This is the beginner quick-start version of the journal routine.

If you want a simple semi-automated helper, use [scripts/cici_daily_journal_helper.py](../../../../scripts/cici_daily_journal_helper.py).

## Daily routine

1. Write a few rough notes while you work.
2. Ask Claude to turn them into the daily journal draft.
3. Check the draft for accuracy.
4. Save it as `docs/personal/daily-journal/YYYY-MM-DD.md`.
5. Commit and push the file to GitHub.

## Example input

```text
worked on: reviewed the template and set up the journal folder
changed: added a daily helper script
blocked: still learning the commit flow
next: draft today's entry and save it
evidence: script path scripts/cici_daily_journal_helper.py
```

## What to collect before drafting

- one or two repo links
- any commit hashes
- a screenshot if something important changed
- blocker notes
- what you want to do next

## What to avoid

- long essays
- guesswork
- changing the template headings
- publishing without review

## Suggested rule for beginners

If a detail cannot be confirmed, mark it as `Needs follow-up` and keep moving.

## Good habit

Keep the journal short enough that it can be updated every day without stress.
