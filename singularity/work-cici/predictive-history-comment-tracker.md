# Predictive History Comment Tracker

WORK only; not Record.

## Purpose

Track comment candidates, posted comments, and public receipts in one simple operator-readable ledger.

## Active Tracker

| Date | Video title | URL | Priority tier | Archetype | Draft status | Posted? | Quality (1-5) | Reach (1-5) | Receipt / evidence | Notes |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | ---: | ---: | :--- | :--- |
| YYYY-MM-DD |  |  |  |  | target / drafted / approved / posted | no / yes |  |  |  |  |
|  |  |  |  |  |  |  |  |  |  |  |
|  |  |  |  |  |  |  |  |  |  |  |

## Status Meanings

- `target`: chosen for possible comment work, no candidate drafted yet
- `drafted`: one or more candidate comments exist
- `approved`: operator-selected draft ready to post
- `posted`: public comment is live and receipt is logged

## Evidence Rule

Every posted row should include at least one of:

- public comment URL
- screenshot pointer
- operator posting note
- thread follow-up note

If a comment is scored for quality or reach without a public receipt, mark that in `Notes`.

## Weekly Read

At the end of each review window, summarize:

- how many comments were posted
- which archetypes performed best
- where AI helped
- where operator rescue was still heavy
