# Narrative Systems (NST)

work only; not Record.

## Status

Research-stage meta-framework defining relationships between independent discourse models.

## Scope

Narrative Systems is NOT a container for other modules.

It is a relational framework that describes how:

- [Epistemic Geometry](../epistemic-geometry/README.md) (structure)
- [Predictive History](../predictive-history/README.md) (time)

interact as coupled components of a unified narrative system.

## Core Idea

NST defines the mapping:

NST: (EG, PH) → R

Where:

- EG = epistemic structure space
- PH = temporal narrative evolution
- R = relational coupling system

Formal specification: [formal_model.md](formal_model.md) (functor F and transformation space Δ).
