# Skills

Public operating recipes for *Civilizational Statecraft* — repeatable reading and judgment moves that cross civilization cases.

Volume-local skills and lane instruments stay under each [volume](../volumes/README.md). This shelf holds **whole-work skills** only.

These are **reader skill cards** (Trigger → Steps → Return paths). They distill doctrine from [Reader Guide](../docs/reader-guide.md), [theory](../theory/README.md), and [Source-Lattice](../sources/source-lattice.md) — not workshop automation tools.

## P0 — start here

| Skill | Use when |
|-------|----------|
| [Governing term first](governing-term-first.md) | You need the load-bearing theory term before volume or shelf descent |
| [Source-lattice read](source-lattice-read.md) | You know the case but must traverse evidence without confusing layers |

**Suggested order for a new object:** civilization-first **or** governing-term-first (pick entry mode) → source-lattice-read when evidence trouble appears.
