# Connectivity Rome

## Where This Sits

Operator routing map for the six volume-local **`rome-{term}.md`** theory files. Open when the question is *which file owns this seam* — not when the question is narrative continuity alone ([Civilization Rome](civilization-rome.md) · [Empire Rome](empire-rome.md)).

## Reading Posture

Each term file **deepens** one whole-work lens from [theory shelf](../../../theory/README.md). [`rome-memory.md`](../rome-memory.md) indexes the **five spines**; siblings **cross-read** via segment **`Cross-reads:`** lines and Bridge blocks — they do not duplicate full spine tables.

**Membrane laws:**

1. **Empire overreach ≠ entropy** — amplification without shock stays civilization + empire.
2. **Ethic ≠ institution** — civilization owns ethic rosters; empire owns institutional/chronicle rosters.
3. **Rupture-primary** lives on entropy (except **1054** primary on faith).
4. **Placement first** — open memory spine anchor, then governing term segment.
