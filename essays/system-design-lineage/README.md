# System Design Lineage Cluster

This folder is the canonical support cluster behind
[System Design Lineage Is Not Unique in Kind](../system-design-lineage-is-not-unique-in-kind.md).

Use this cluster when the main essay is too compressed and you need the
literature lines separated by function:

- [evidence-matrix.md](./evidence-matrix.md) for the annotated bibliography and
  comparison matrix
- [reflective-metacognitive-lineage.md](./reflective-metacognitive-lineage.md)
  for reflective, metacognitive, and self-improvement precedents
- [collaborative-architecture-lineage.md](./collaborative-architecture-lineage.md)
  for blackboard, distributed problem solving, and role-specialized
  collaboration precedents
- [governed-judgment-lineage.md](./governed-judgment-lineage.md) for
  mixed-initiative, intelligibility, and authority-preserving judgment-support
  precedents

The cluster is intentionally subordinate to the carriage-bearing essay above it.
These notes exist so the essay can stay compact without losing the primary
source trail.

This cluster follows the preferred research-support shape:

- `README.md` as cluster front door
- `evidence-matrix.md` as annotated bibliography and comparison surface
- family-separated support notes
- one synthesized essay above the cluster
