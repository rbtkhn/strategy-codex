## Authority rule

This README is the **canonical prose-discovery surface** for repo-root `essays/`.

- **Primary shelf** — new stand-alone essays **default here**, including cross-channel arguments.
- **Notes stay channel-scoped** — bounded interpretive objects remain in [statecraft/notes/](../statecraft/notes/README.md) or [singularity/notes/](../singularity/notes/README.md) only.
- **Compatibility holdings** — [statecraft/essays/](../statecraft/essays/README.md) and [singularity/essays/](../singularity/essays/README.md) retain existing files until bounded migration; do not treat them as the default destination for new essays.

## Formal role

Use repo-root `essays/` when the piece:

- carries a **transportable thesis** that can leave its original routing context
- may **span statecraft and singularity** (legitimacy/command/settlement **and** agency/substrate/acceleration)
- is synthesized enough to stand alone without a channel workshop, month, or single seam beside it

Use **channel notes** (not essays) when the piece:

- preserves **one bounded seam**, mechanism, audit, comparison, or promoted object
- belongs clearly to **one channel's** live judgment or acceleration work
- is not yet a cross-channel or stand-alone thesis

Do **not** use this folder for:

- constitutional kernels, domain READMEs, work membranes
- sheets, bridges, transactions, journals, indexes
- source-archive or verbatim capture
- speaker-shelf support files (route promoted prose to notes or essays per [prose-index](../docs/prose-index.md))

## Local test

If the argument can be detached from its originating route **and** may need both channels to make its claim honestly → **repo-root essay**.

If the object is still one channel's bounded seam → that channel's **note**.

If the object is thesis-bearing but **only** statecraft-native or **only** singularity-native and you are not ready to treat it as cross-channel → repo-root essay is still preferred; channel `essays/` folders are legacy compatibility only.
