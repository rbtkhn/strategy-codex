# Military Workshop

WORK only; not Record.

The Military Workshop is the active-use layer of academy military. The shelf answers "what should I read?" The workshop answers "how do I read force, command, logistics, escalation, and responsibility without losing the human reality inside the map?"

## Workflow

1. **Read campaign.** Start with one Bookshelf anchor, writer lane, or campaign problem.
2. **Name force.** Identify combat power, geography, logistics, industry, command, morale, alliance structure, and political purpose.
3. **Test logistics.** Ask what can be supplied, moved, repaired, reinforced, replaced, or sustained.
4. **Test command responsibility.** Ask who ordered, who executed, who had alternatives, and who bears responsibility.
5. **Separate lanes.** Keep primary evidence, official claims, imagery, ORBAT work, writer interpretation, and operator synthesis distinct.
6. **Produce reuse.** End with an instrument, campaign sheet, warning, or bridge note.

## Quick Start

For a fresh campaign or book, use this sequence:

1. Open the relevant sheet.
2. Run the [Campaign Reading Sheet](instruments.md#campaign-reading-sheet).
3. Run either the [Logistics Vs Narrative Test](instruments.md#logistics-vs-narrative-test) or the [Attrition Vs Decision Test](instruments.md#attrition-vs-decision-test).
4. Run the [Command Responsibility Check](instruments.md#command-responsibility-check).
5. If the case touches sacred legitimacy, sacrifice, civilians, or empire, run the [Academy cross-shelf bridge](../../cross-shelf-bridge.md).
6. Produce one reusable note: a warning, instrument amendment, source boundary, or Bookshelf pairing.
