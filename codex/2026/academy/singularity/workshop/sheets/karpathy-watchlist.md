## Agency Under Acceleration

- **Agent:** A lone researcher, a swarm of autonomous research agents, and the human operator programming the `program.md` context.
- **Objective:** Improve model behavior, run faster experiment loops, and compress research iteration into overnight autonomous cycles.
- **Authority:** Split between the profile owner, the repo instructions, the training code, and the compute substrate.
- **Observability:** High enough to see repo movement, but not enough to see every judgment, experiment discard, or autonomy edge case.
- **Rollback:** Partial. Code changes can be reverted, but once a research loop or substrate assumption hardens, the workflow itself becomes sticky.

## Boundary Warnings

- **Pinned repos are not the whole story.** The profile is useful because it shows a compact public frontier, but watchlist judgment should still stay repo-specific.
- **Autonomy is not magic.** `autoresearch` is about agent loops, but the human still defines the training context and the stop conditions.
- **Substrate matters.** `llm.c` is a reminder that model capability depends on compute, tooling, and reproducibility, not only on prompts.
- **Educational clarity matters.** `nanoGPT` should stay in the watchlist because it keeps the frontier teachable rather than purely performative.
