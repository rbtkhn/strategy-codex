# Theology Workshop

WORK only; not Record.

The Theology Workshop is the active-use layer of academy theology. The shelf answers "what should I read?" The workshop answers "what can this help me see, test, and reuse?"

Use it as a bench for operator study: gather source, name the pressure, compare traditions, test moral risk, and leave behind a reusable note.

## Workflow

1. **Read source.** Start with one academy essay, one note, or one Bookshelf anchor. Keep corpus material separate from workshop output.
2. **Name pressure.** Identify the sacred, moral, ritual, institutional, or civilizational pressure at work.
3. **Compare traditions.** Ask whether the same pressure appears in another vocabulary: covenant, dharma, Tao, law, conscience, grace, sacrifice, apocalypse.
4. **Test moral risk.** Look for category-over-face, false universality, providential certainty, sacred violence, or empire hiding inside virtue.
5. **Produce reuse.** End with an instrument, prompt, sheet, or upstream note that can be used again.
