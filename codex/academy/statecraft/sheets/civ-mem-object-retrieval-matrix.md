# CIV-MEM Object Retrieval Matrix

WORK only; not Record.

## Purpose

Use this sheet before creating or upgrading academy-statecraft civilization objects from CIV-MEM. CIV-MEM is the deep civilizational memory graph; strategy-codex is the operational command surface. This matrix prevents urgent statecraft work from flattening months of CIV-MEM work into shallow summaries.

The matrix applies to major backfills for:

- `civilization/objects/state-memory.md`
- `civilization/god.md`
- `civilization/lit.md`
- `civilization/art.md`
- `civilization/war.md`
- `civilization/peace.md`

## Retrieval Contract

For each object, run three retrieval layers:

1. **Direct lane retrieval** - Open the lane's `CIV-CORE`, `CIV-STATE`, `MEM-RELEVANCE`, and seed-pattern surfaces where present.
2. **Lens retrieval** - Search for the object-specific seed terms below.
3. **Graph retrieval** - Follow `MEM CONNECTIONS` from high-signal MEMs to find counterweights, analogies, rupture points, adjacent lenses, and transaction constraints.

Quantitative default:

- Baseline heavy backfill: core/state plus 8-12 opened MEM bodies.
- MEM-connections backfill: expand to a 20-35 candidate pool, then open the strongest 8-12 plus at least 2 connection-discovered counterweights.
- Mark the object `Provisional` if no useful connection path or counterweight is found.

Do not cite files that were not opened and used. Every connected source used must yield a named statecraft pattern.

## Output Benchmarks

A full-strength object backfill should improve retrieval quality over direct search alone:

- **2-3x broader candidate discovery** through connected MEM expansion.
- **30-50% better counterweight detection** by requiring contradiction or rupture sources.
- **40-60% better cross-lens bridge detection** when one lens routes into another, such as `god` into `lit`, `art` into `war`, or `peace` into `state-memory`.
- **30-40% lower shallow-backfill risk** when every opened source must yield a named statecraft pattern.

These are planning benchmarks, not automated scores. Use them to judge whether the backfill process is doing graph-aware CIV-MEM work or merely citing the library.

## Membrane Rule

Graph retrieval can propose durable lane improvements, but it cannot absorb them automatically.

Route durable discoveries as:

`MEM CONNECTIONS signal -> named statecraft pattern -> lane-local update candidate -> human review -> accepted lane change`

Use `<lane>/updates/pending.md` for candidates. Do not directly rewrite transactions, CIV-MEM, PH-CIV, Record surfaces, or current state carrier files unless the operator separately requests that implementation.
