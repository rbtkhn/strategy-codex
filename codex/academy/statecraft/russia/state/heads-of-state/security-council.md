# Security Council Carrier

WORK only; not Record.

Use this note when a Russia-lane instrument appears to require collective elite backing rather than only presidential signature.

## Role In Current State Form

The Security Council carrier represents the collective security-state surface: defense, intelligence, foreign policy, domestic security, and strategic planning.

## Carrier Function

- Turns presidential preference into elite/institutional consensus.
- Signals that a settlement is state policy, not personal improvisation.
- Tests whether military, intelligence, diplomatic, and domestic-security institutions can implement restraint.

## Settlement Credibility

Use this carrier when:

- negotiations affect Ukraine, NATO, Iran, the Caucasus, nuclear signaling, or sanctions architecture;
- a concession would otherwise look personal or weak;
- implementation requires military or intelligence restraint;
- the settlement must survive succession.

## Warning

If a Russia transaction lacks a Security Council or equivalent institutional carrier, treat it as fragile.
