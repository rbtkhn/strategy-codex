# Russia State

WORK only; not Record.

Use this folder for the current Russian state apparatus: government, presidency, Security Council, foreign ministry, military-security institutions, and official authority carriers. This is the near-term institutional layer that turns Russian civilizational memory and imperial/security striving into orders, statements, negotiations, and implementable instruments.

## Start Here

- [Putin carrier](putin.md) - current presidential / security-state carrier of state continuity, strategic depth, and recognition demands.
- [Security Council carrier](security-council.md) - institutional continuity surface for elite/security consensus and durable implementation.
- [Authority carrier objects](objects/) - ministers, negotiators, security figures, and institutional voices whose statements carry Russian state intent across raw-inputs.
- [Sergey Lavrov](objects/lavrov.md) - foreign-ministry continuity carrier for agreement capability, red-line language, and settlement signals.

## Boundary

State is the current-government and institutional-carrier layer. It is not the whole Russia lane:

- [Civilization](../civilization/) names inherited code, memory, legitimacy, geography, fear, and successor-stable state interest.
- [Empire](../empire/) names outward striving for buffers, control, recognition, energy leverage, and security depth.
- [Helix](../helix.md) tests how civilization and empire regulate each other through statecraft.

## Drafting Use

Open this folder when a Russia-lane instrument depends on who can actually carry, sign, implement, restrain, or contradict a policy. A settlement that cannot pass through this state layer is commentary, not statecraft.
