# Russia Statecraft Transactions

WORK only; not Record.

This bench spends compact speaker-state into Russia-lane instruments. Use the canonical [Statecraft Transaction Template](../../templates/statecraft-transaction.md) for any reusable transaction.

## Transaction Bias

Russia transactions should prioritize recognition, strategic optionality, leverage without entrapment, ambiguity that preserves bargaining space, and equilibrium after disruption.

Each transaction should separate:

- current Russian government policy;
- Russian state continuity through security depth and institutional memory;
- geography as constraint and asset;
- successor-stable interests that survive factional or wartime shifts.

## Spendable Inputs

- Crooke for order rupture and Western misreading.
- Diesen for multipolar structure and order-transition altitude.
- Ritter / Macgregor / Martyanov for force constraints and military-industrial capacity.
- Parsi / Freeman for settlement architecture and diplomatic prudence.
- Pape when coercive-center leverage affects Russian optionality.

## Preferred Transaction Families

- recognition formulas;
- security-zone language;
- mediator or guarantor channels;
- sanctions workarounds and energy arrangements;
- deconfliction mechanisms;
- linkage notes that preserve ambiguity without creating unlimited commitments.

## Validity Questions

- Does the instrument gain recognition without saying more than Moscow can sustain?
- Does it exploit disruption without becoming trapped by Iran's or another partner's escalation calendar?
- Which adversaries must not be unified against Russia?
- What settlement lets Russia claim prudence rather than maximal victory?
