# Crooke-CIV-EMP Theme Companions

Purpose: hold the `civ-emp`-facing companion surfaces for the six Crooke historical themes activated in the `2025-01-01 -> present` Crooke arc.

These files move backward through real history from a present-day Crooke activation surface. They are not transcript commentary files. They are thin source scaffolds or pointer objects for statecraft retrieval.

## Theme Set

- [Treaty form vs transactional settlement](treaty-form-vs-transactional-settlement.md)
- [Cold War overmatch and war metamorphosis](cold-war-overmatch-and-war-metamorphosis.md)
- [Mechanistic fallacy and civilizational memory](mechanistic-fallacy-and-civilizational-memory.md)
- [Monroe reassertion and hegemonic retrenchment](monroe-reassertion-and-hegemonic-retrenchment.md)
- [Ben-Gurion, Clausewitz, and redemptive permanent war](ben-gurion-clausewitz-and-redemptive-permanent-war.md)
- [Decapitation theater and regime-collapse fantasy](decapitation-theater-and-regime-collapse-fantasy.md)

## Use

Open this folder when:

- the Crooke-side theme is already known
- the task now needs backward historical scaffolding
- a theme needs a compact `civ-emp` retrieval surface before lane-local translation

## Boundary

- These files do not replace lane-local `civilization/`, `empire/`, `state/`, `helix.md`, or `transactions/` surfaces.
- These files do not make Crooke the upstream authority for civilizational history.
- When an existing `civ-emp` object already carries the pattern, point to it rather than duplicating it.
