# Broken Settlement, Minsk, And Istanbul Sequencing

## Purpose

Provide a `civ-emp` source scaffold for the Mercouris theme in which false sequencing destroys trust and later negotiations return under harsher military conditions.

## Cybernetic Activation

Mercouris-side activation surface: [Broken settlement, Minsk, and Istanbul sequencing](../../../../../speakers/mercouris/themes/broken-settlement-minsk-and-istanbul-sequencing.md)

## Backward Historical Question

When does a ceasefire or interim process fail because it postpones the real political settlement, and how does delay harden the later terms?

## Source Basis

- Mercouris modern examples: Minsk failure, Istanbul 2022, Istanbul Plus
- `civ-emp` retrieval contract for `peace`
- lane-local settlement, armistice, or sequencing objects where they exist
- legacy `civ-mem` only if a particular settlement genealogy needs deeper provenance

## Arc Pattern

`interim process without core settlement -> trust exhaustion -> renewed war -> later return under worse terms`

## Continuity / Transformation / Current Carrier / Failure Mode

- Continuity: war termination requires real political carriers
- Transformation: media and alliance politics often reward theatrical early phases
- Current carrier: neutrality terms, identity protections, territorial status, sovereign guarantees
- Failure mode: ceasefire language replaces settlement design and becomes a time-buying mechanism

## Statecraft Use

Use this scaffold when drafting or testing:

- ceasefire-first proposals
- confidence-building measures
- neutrality formulas
- verification or guarantee sequences

## Counterweight

Some interim arrangements are necessary; the point is not to reject staging altogether but to reject staging that substitutes for the actual political deal.

## Transaction Hooks

- ask whether the core dispute is being solved now or deferred
- ask whether the proposed sequence would be trusted by the losing or distrustful side
- ask how battlefield change alters the meaning of returning to an earlier settlement line

## Citation Preference

1. Use lane-local peace objects when they already hold the settlement logic.
2. Use this scaffold when the problem is still sequencing and trust exhaustion.
3. Use legacy `civ-mem` only when a deeper settlement genealogy is needed.
