# Russia Transfer Probe

This is a bounded transfer probe against the current America pilot template. It does not materialize Russia to pilot maturity. Its job is only to test whether the current America pattern transfers cleanly enough that Russia can become the next lane without redesigning the scaffold.

## Pair Under Review

- Lane: `Russia`
- Civilization-side object: [Russia state memory](../../russia/civilization/objects/state-memory.md)
- Empire-side object: [Russia empire seed instruments](../../russia/empire/seed-instruments.md)
- Current statuses from the control plane: `unstarted` / `unstarted`
- Reviewer / date: Codex / 2026-05-22

## Transfer Verdict

The America pattern **does transfer structurally**, but not yet operationally.

That means:

- the same civilization / empire split still makes sense for Russia
- the same six-audit gate still makes sense for Russia
- the same first-wave target classes still make sense for Russia

But it also means:

- Russia is not yet close to pilot readiness
- the current Russia pair would fail much earlier in the audit stack than America now does
- the next Russia pass should use America as a shape, not as a copy target

## Where The Pattern Transfers Cleanly

### Civilization-side fit is already real

[Russia state memory](../../russia/civilization/objects/state-memory.md) already behaves like a recognizable first-wave civilization object. It has a strong continuity spine, a usable authority ladder, explicit falsifiers, current carriers, and a real statecraft question.

The main strength is that Russia state memory already carries a long causal line:

- founding and route memory
- tribute and subordination memory
- gathering and centralization
- imperial and Soviet continuity
- post-1991 rupture and restoration

That means the file already resembles an earlier-stage version of America state memory rather than a mere placeholder.

### Empire-side class fit is conceptually sound

[Russia empire seed instruments](../../russia/empire/seed-instruments.md) also fits the correct object class. Its three current families:

- borderland buffer control
- energy leverage
- mediator disruption optionality

are plausible Russia empire instruments and already answer the right kind of outward-power question. So the object class itself is not the problem.

### The audit template still applies

The reusable six-audit stack in [pilot-lane-audit-template.md](pilot-lane-audit-template.md) remains valid for Russia. No new audit category is required just because the lane is Russian rather than American.

## Where The Pattern Does Not Yet Transfer Cleanly

### Russia would fail the public-orientation audit immediately

The Russia civilization object opens with meaningful content, but it does not yet perform the PH-CIV-style orientation jobs explicitly:

- no `Where this sits`
- no `Reading posture`
- no `Historical pressure points` section near the top
- no plain-language `Limits of the frame`
- no explicit `Return path`

The empire-side object is even earlier-stage. It is still a seed list, not a public-facing object surface. So if America now represents a conditional-pass orientation model, Russia is still materially before that line.

### Russia empire is much too thin to serve as a paired volume

The control plane already shows the quantitative gap:

- `russia-state-memory`: `1075` words
- `russia-empire-instrument`: `214` words
- Russia civilization:empire ratio: `19.19:1`
- empire share of civilization weight: `0.05`

So even before qualitative review, Russia is nowhere near the symmetric-first threshold. The current empire file is still a seed shelf, not a real paired answer surface.

### Russia state memory is closer to old-style lane memory than to normalized CIV-EMP contract

The civilization side is promising, but it does not yet expose the America-normalized top-level contract explicitly:

- no top-level `Source Basis`
- no top-level `Arc Pattern`
- no top-level `Statecraft Use`
- no top-level `Counterweight`
- no top-level `Transaction Hooks`
- no explicit `Symmetry Link`

In other words, Russia already has substance, but not yet the object contract shape that makes the migration system operationally uniform.

## Russia-Specific Shape Difference The Template Must Respect

America and Russia do not fail in the same place.

- America's challenge was to thicken empire enough that the two-volume claim became real.
- Russia's challenge is split:
  - normalize an already-substantive civilization object into the migration contract
  - turn a much thinner empire seed into a real paired surface

So the Russia pass should not begin by copying America's exact order of operations mechanically. It should begin with:

1. contract-normalize Russia state memory
2. promote Russia empire seed instruments into a real object
3. only then do public-orientation polishing

That sequence is different from America because Russia's civilization side starts stronger, while its empire side starts thinner.

## Template Learning

The probe teaches three useful things about the current America template:

1. **The architecture generalizes.**
   The civilization / empire pairing and six-audit gate remain valid.

2. **The template must stay shape-first, not prose-first.**
   Russia confirms that another lane may already have deep content but still fail the migration contract because it lacks normalized object shape.

3. **The next-lane playbook should be staged.**
   A future Russia pilot should be executed in this order:
   - contract normalization
   - empire promotion
   - public-orientation pass
   - metrics recompute
   - full pilot audit

## Recommendation

Do not materialize Russia yet.

America should still be brought to full template readiness first. But once America clears that bar, Russia is a valid next lane and does not require a redesign of the migration scaffold. The main requirement is to start Russia with a more explicit contract-normalization pass than America needed.
