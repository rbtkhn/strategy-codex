
# China Helix Verification

## Scope

This note checks whether China now works as a **helix-primary lane**, not merely as a maturity-complete first-wave lane.

It sits above:

- [China pilot lane audit](china-pilot-lane-audit.md), which proves the paired `state-memory` / `empire-instrument` opening is template-ready
- [China first-wave verification note](china-first-wave-verification.md), which proves the individual civilization-side slices can move beyond `materialized`
- [China lane-level verification](china-lane-verification.md), which proves the lane is a maturity-complete Phase 1C first-wave lane

The question here is different:

- has the China lane actually become helix-first in its top-level interpretation?

Reviewer / date: Codex / 2026-05-22

## Helix-Primary Verification Standard

For the China transfer case, helix-primary verification requires all of the following:

1. the helix is now the preferred top-level interpretive surface for the lane
2. the lane README routes to the helix first and to strand objects second
3. the helix routes clearly to all five first-wave strand objects
4. all five first-wave strand objects route back to the helix
5. canonical-family service is legible through helix-plus-strand interaction
6. the lane no longer depends on the two-volume split as its governing interpretation, even though the strand split remains valid as scaffold history
7. the strand layer still preserves provenance, counterweight, and transaction hooks
8. the control plane reflects China as a transfer case from the America-plus-Russia proof rather than as an unbounded all-lanes rewrite

## Verdict

- Helix-primary lane: `yes`
- Ready to transfer pattern beyond China: `not yet`

China now works as a **helix-primary lane**.

That claim is justified because the lane no longer needs the two-volume split to provide its top-level interpretation. The split still exists as a supporting strand scaffold, but a reader can now enter at the helix, understand the order / exposure / leverage problem as one integrated object, and then descend into the correct strand when the question narrows.

At the same time, this transfer remains bounded. China is the third successful helix-primary lane because the earlier proving cases held strongly enough to transfer, not because Phase 2 has silently become the default for every lane. Iran still remains on the Phase 1C architecture until explicitly promoted.

## Recommended Interpretation

Use China to establish that Phase 2 is now robust across distinct lane types:

- **America** proves the architecture can work
- **Russia** proves the architecture is not America-specific
- **China** proves the architecture also transfers to a lane where quiet leverage and anti-disorder logic matter more than overt coercive ownership

That distinction keeps the repo from confusing a widening proving set with a completed all-lanes migration while still showing that the helix-first model now travels across very different strategic grammars.
