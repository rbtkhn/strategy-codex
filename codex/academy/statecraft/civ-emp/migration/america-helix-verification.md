# America Helix Verification

## Scope

This note checks whether America now works as a **helix-primary lane**, not merely as a maturity-complete first-wave lane.

It sits above:

- [America pilot lane audit](america-pilot-lane-audit.md), which proves the paired `state-memory` / `empire-instrument` opening is template-ready
- [America first-wave verification note](america-first-wave-verification.md), which proves the individual civilization-side slices can move beyond `materialized`
- [America lane-level verification](america-lane-verification.md), which proves the lane is a maturity-complete Phase 1C first-wave lane

The question here is different:

- has the America lane actually become helix-first in its top-level interpretation?

Reviewer / date: Codex / 2026-05-22

## Helix-Primary Verification Standard

For the America proving case, helix-primary verification requires all of the following:

1. the helix is now the preferred top-level interpretive surface for the lane
2. the lane README routes to the helix first and to strand objects second
3. the helix routes clearly to all five first-wave strand objects
4. all five first-wave strand objects route back to the helix
5. canonical-family service is legible through helix-plus-strand interaction
6. the lane no longer depends on the two-volume split as its governing interpretation, even though the strand split remains valid as scaffold history
7. the strand layer still preserves provenance, counterweight, and transaction hooks
8. the control plane reflects the America-only proving case honestly and does not over-transfer the pattern to Russia, China, or Iran

## Verdict

- Helix-primary lane: `yes`
- Ready to transfer pattern beyond America: `not yet`

America now works as a **helix-primary lane**.

That claim is justified because the lane no longer needs the two-volume split to supply its top-level interpretation. The split still exists, but now as a supporting strand scaffold rather than as the governing reader-facing ontology. A reader can enter at the helix, understand the republic / empire problem as one integrated object, and then move into the correct strand when the question narrows.

At the same time, this proving case is intentionally bounded. America is the first successful helix-primary lane, but the pattern should not yet be transferred automatically. The point of this note is to establish that the architecture works in one mature lane before Russia, China, or Iran are rerouted.

## Recommended Interpretation

Use America to establish the Phase 2 distinction:

- **maturity-complete first-wave lane** means the strand layer is complete, verified, and strong enough to stand on its own
- **helix-primary lane** means the strand layer still matters, but the top-level interpretation has moved upward into the helix

That distinction keeps the repo from confusing a successful strand scaffold with the final authored architecture.
