# Helix-First Orientation Surface

## Purpose

Use this note as the first corpus-level orientation / retrieval surface for the helix-first statecraft layer.

It answers a different question than the lane READMEs and a different question than the canonical-family synthesis notes:

- lane READMEs tell you how to enter one lane
- synthesis notes tell you what a shared family means across lanes
- this note tells you where to start when you do **not yet know** whether the real problem is America, Russia, China, Iran, or one of the shared families

## What This Layer Is

The active statecraft corpus now has two stacked layers:

1. **Helix layer**
   The primary authored interpretation for each lane.
2. **Strand layer**
   The five first-wave source surfaces beneath each helix:
   - `state-memory`
   - `geo`
   - `war`
   - `peace`
   - `empire-instrument`

The helix layer is where to start when the crisis object is still whole. The strand layer is where to go after the governing line is clear and the question has narrowed.

## When To Start With A Lane

Start with a lane helix when the live problem is clearly carried by one state's grammar of authority, exposure, leverage, or restoration.

- [America helix](../../america/helix.md)
  Start here when the real problem is constitutional carry, burden-sharing, lawful enforcement, or how a hegemon narrows power without hollowing out legitimacy.
- [Russia helix](../../russia/helix.md)
  Start here when the real problem is strategic depth, recognition, escalation timing, reciprocal security geometry, or overbinding through pressure.
- [China helix](../../china/helix.md)
  Start here when the real problem is anti-disorder stabilization, quiet leverage, route continuity, public visibility risk, or cumulative control without ownership burden.
- [Iran helix](../../iran/helix.md)
  Start here when the real problem is dignity, sanctions pressure, deterrent conversion, humiliating reversibility, or leverage that must be cashed out without surrender.

## When To Start With A Family

Start with a canonical-family synthesis note when the live problem is already obviously cross-lane and the key uncertainty is conceptual rather than national.

- [Canonical-family synthesis: real settlement](canonical-family-settlement-real.md)
  Start here when the question is whether a proposed peace, ceasefire, review mechanism, or relief sequence is real or merely theatrical across several lanes at once.
- [Canonical-family synthesis: coercion conversion](canonical-family-coercion-conversion.md)
  Start here when the question is why pressure, force, or leverage is still escalating or persisting even though nobody can clearly say what bounded political outcome would count as enough.
- [Canonical-family synthesis: exclusion and direct settlement](canonical-family-exclusion-settlement.md)
  Start here when the question is whether a major-power room really includes the actors it claims to include, or whether route authorship, access patterns, and review carriers still leave the decisive map elsewhere.
- [Canonical-family synthesis: pressured hegemon misreading power](canonical-family-pressured-hegemon.md)
  Start here when the question is whether a state is mistaking the persistence of its instruments, stories, or leverage habits for proof that its deeper political or strategic durability remains intact.
- [Canonical-family synthesis: older strategic memories](canonical-family-older-strategic-memories.md)
  Start here when the question is whether an older continuity, humiliation, exposure, or sovereignty memory is still silently determining what present actors can call prudent, serious, or survivable.
- [Canonical-family synthesis: broken contact regimes and arms-control inheritances](canonical-family-broken-contact-regimes.md)
  Start here when the question is whether proxy or indirect pressure looks manageable only because the actors are borrowing escalation habits from an older contact regime whose review, hotline, or inspection channels have already thinned.

If the problem is cross-lane but no synthesis note exists yet for the family, start with the most likely governing helix, then compare sideways only after the first lane has named the real hinge.

## Retrieval Router

Use this quick router when the object is still blurry:

1. **If the question is “who is this really about?”**
   Start with the most likely lane helix.

2. **If the question is “what kind of problem is this?”**
   Start with the closest canonical-family synthesis note.

3. **If the question is “what part of the lane is governing?”**
   Start with the helix, then drop to the strand that the helix names as decisive.

4. **If the question is “how do I draft a clause or instrument?”**
   Start with the helix or synthesis note, then move into the relevant strand and finally into the lane or cross-lane `transactions/` surface.

## Strand Descent Rule

Once the top-level line is clear, descend by question type:

- `state-memory`
  Use when the problem is inherited legitimacy, authority carry, humiliation memory, or successor stability.
- `geo`
  Use when the problem is access, corridors, chokepoints, plateau or maritime exposure, or settlement geography.
- `war`
  Use when the problem is coercive design, escalation architecture, enoughness, or contact-channel decay.
- `peace`
  Use when the problem is settlement carry, review, relief, recognition, successor ownership, or theatrical versus real closure.
- `empire-instrument`
  Use when the problem is the outward control stack itself: guarantors, enforcement carriers, route leverage, sanctions architecture, or quiet versus visible power.
