# Iran Statecraft Transactions

WORK only; not Record.

This bench spends compact speaker-state into Iran-lane instruments. Use the canonical [Statecraft Transaction Template](../../templates/statecraft-transaction.md) for any reusable transaction.

## Transaction Bias

Iran transactions should prioritize legitimated coercive leverage, sanctions relief, deterrence with control, dignity-preserving recognition, and regional architecture that prevents Iran from being treated as a disposable target.

Each transaction should separate:

- current Iranian government and security institutions;
- deeper Iranian / Persian state continuity;
- geography, resource self-sufficiency, and Hormuz as durable leverage;
- successor-stable interests in sovereignty, deterrence, sanctions relief, and regional recognition.

## Spendable Inputs

- Pape for fourth-center leverage, shortage clocks, and falsifiers.
- Parsi / Marandi for Iranian bargaining logic and settlement architecture.
- Crooke for Western misreading and structural rupture.
- Ritter for regime-change skepticism, military danger, and escalation risk.
- Mearsheimer when coercive leverage must be checked against balancing pressure.

## Preferred Transaction Families

- transit-security bargains;
- phased sanctions relief;
- non-regime-change guarantees;
- regional non-aggression clauses;
- Oman or Gulf backchannels;
- energy-export mechanisms;
- dignity-preserving recognition formulas.

## Exemplars

- [Hormuz recognition transit transaction](hormuz-recognition-transit-transaction.md) - volatile first pass that converts Iran's Hormuz leverage into a recognition, restraint, sanctions-relief, and transit-security clause.

## Validity Questions

- Does the instrument convert leverage into recognition rather than permanent spoiler status?
- Does it preserve deterrence without inviting regime-threatening escalation?
- What sanctions relief can be verified without humiliation?
- What clause reopens transit and diplomacy while preserving control?
