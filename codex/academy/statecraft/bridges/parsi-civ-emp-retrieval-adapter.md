# Parsi CIV-EMP Retrieval Adapter

WORK only; not Record.

## Purpose

Use this adapter when a Parsi-style claim needs to extract settlement mechanism, guarantee logic, bargaining architecture, or institutional durability from `civ-emp` without flattening the civilizational/state substrate that the mechanism depends on.

## When To Use

Use this adapter when the live claim is primarily about:

- sanctions relief and sequencing
- guarantees and implementation realism
- blockade failure or anti-silver-bullet logic
- bargaining room after coercion failure
- regional architecture and durable settlement

If the live question is still mainly about dignity, legitimacy, recognition leakage, or sovereignty grammar under pressure, use the [Marandi adapter](marandi-civ-emp-retrieval-adapter.md) instead.

## Primary Conversion Chain

`leverage -> bargaining room -> guarantees -> settlement durability`

The core task is to determine what kind of mechanism can turn surviving leverage into usable and successor-stable terms.

## Field Weighting

Weight `civ-emp` objects in this order:

1. `current carrier`
2. `failure mode`
3. `transaction use`
4. `counterweight`
5. `transaction hooks`

This weighting keeps the retrieval focused on whether a civilizational/state pattern can survive institutionalization, not just whether it is intelligible.

## Failure Test

Do not mistake leverage survival for successful institutionalization.

This adapter is meant to prevent two common collapses:

- treating bargaining room as if it automatically yields a durable settlement
- drafting mechanism in a way that forgets the dignity, recognition, and sovereignty substrate it must carry

Force one degradation check:

- where does the mechanism fail because carriers are weak, relief is humiliating, verification is theatrical, or architecture cannot survive the next pressure cycle?

## Output Shape

This adapter should usually produce one of:

- settlement brief
- guarantee logic note
- sequencing design
- architecture diagnosis

It should not stop at civilizational interpretation once the operator's real question has already become transactional.
