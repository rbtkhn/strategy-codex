# Arc-Conditioned CIV-EMP Worked Examples

WORK only; not Record.

Purpose: preserve compact proof runs showing how the same `civ-emp` object can be queried differently by different speaker-conditioned retrieval adapters.

This note is not a new front door. It is a reuse aid for the bridge layer.

## Reading Rule

Each example should be read in the same cadence:

1. identify the shared source ground
2. run the Marandi path
3. run the Parsi path
4. compare the outputs

The goal is not to prove one adapter right and the other wrong. The goal is to prove that the same source base can be queried in two disciplined ways that produce different statecraft outputs.

## Example 1: Graham / Iran / Hormuz

Both runs start from the same source base:

- [Hormuz Recognition / Transit Restraint](../civ-emp/iran/hormuz-recognition-transit-restraint.md)
- [Iran helix](../iran/helix.md)

The test is whether the adapters produce different statecraft outputs from the same object rather than from different corpora.

- Adapter: [Marandi CIV-EMP retrieval adapter](marandi-civ-emp-retrieval-adapter.md)
- Live claim shape: pressure survival, dignity, recognition leakage, Hormuz leverage meaning
- Weighted fields:

  - [Iran state memory](../iran/civilization/objects/state-memory.md)

### Parsi-path run

- Adapter: [Parsi CIV-EMP retrieval adapter](parsi-civ-emp-retrieval-adapter.md)

Settlement-durability result:

- the claim is read as evidence of bargaining room, not yet of settled political success
- the central question becomes what sanctions relief, verification, and carrier structure could make the leverage usable
- the output is a **settlement brief** or **guarantee logic note**, not a recognition memo

Failure test:

- do not mistake leverage survival for institutional success
- force one read on humiliating verification, discretionary relief, weak carriers, or architecture collapse

## Example 1 Comparison Rule

Use the Marandi adapter when the core question is:

- what has already become politically meaningful for Iran through endurance and pressure survival?

Use the Parsi adapter when the core question is:

- what would make that meaning durable enough to survive as a settlement?

Shortest split:

- Marandi path = `pressure -> legitimacy -> recognition threshold`
- Parsi path = `leverage -> bargaining room -> settlement durability`

## Family Pattern

Across the current proof set, the stable split is:

- Marandi path asks what the event has already made politically or morally legible for Iran
- Parsi path asks what would make that legibility carryable as mechanism, review, guarantee, or settlement

Shortest family rule:

- Marandi path = meaning first
- Parsi path = carry first

That family rule expresses the three example rules in one line:

- Hormuz = recognition leakage versus settlement durability
- Latency = deterrent dignity versus inspection architecture
- Minab = sacred injury versus protected humanitarian mechanism
