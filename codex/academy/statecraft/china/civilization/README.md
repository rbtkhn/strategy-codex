# China Civilization

WORK only; not Record.

Purpose: name the inherited Chinese code that shapes order, continuity, industrial confidence, and the fear of disorder.

## Inherited Code

- Centrality, continuity, and the memory of civilizational restoration.
- Order over chaos as a legitimacy test.
- Mandate logic: performance, stability, competence, and unity.
- Long time horizon and preference for patient accumulation.
- Humiliation memory and resistance to external containment.

## Historical Continuity

Distinguish the current party-state from the deeper Chinese state-space: Xia / Shang / Zhou dynastic and mandate memory, Qin-Han standardization, imperial bureaucratic restoration cycles, Yuan / Qing frontier incorporation, late-imperial humiliation and disorder, Republican fragmentation, PRC reconstruction, reform-era development legitimacy, population, industrial base, ports, rivers, bureaucracy, food and energy needs, and successor claims to order.

## Legitimacy Memory

China's legitimacy grammar is order, development, competence, unity, stability, and restoration after humiliation. Instruments that create visible disorder damage the code they are supposed to protect.

## Durable Fear

The durable fear is chaos: internal fragmentation, energy disorder, supply-chain disruption, external containment, or premature confrontation before the balance is ready.

## Successor-Stable State Interest

Any successor Chinese authority would still need unity, food and energy security, industrial continuity, trade-route stability, technological capacity, and a regional environment that does not invite blockade.
