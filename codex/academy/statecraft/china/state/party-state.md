# Party-State Carrier

WORK only; not Record.

Use this note when a China-lane instrument requires institutional implementation beyond the top leader.

## Role In Current State Form

The party-state carrier joins party authority, state administration, military command, industrial policy, finance, ports, insurers, and provincial execution.

## Civilizational Pattern Link

The party-state is the institutional implementation carrier of [China state memory](../civilization/objects/state-memory.md). It converts civilizational order, mandate performance, development legitimacy, and anti-disorder discipline into ministries, banks, firms, ports, insurers, provinces, PLA restraint, and diplomatic execution.

## Carrier Function

- Converts strategic line into bureaucratic and commercial execution.
- Lets China act quietly without needing public credit.
- Keeps anti-disorder policy from becoming personalized brinkmanship.

## Settlement Credibility

Use this carrier when:

- the instrument involves energy, shipping, insurance, infrastructure, sanctions workarounds, or regional forums;
- implementation depends on banks, firms, ports, insurers, or provincial authorities;
- public leader-level commitments would be too visible or costly.

## Warning

If a China transaction lacks party-state implementation channels, it may be rhetoric rather than statecraft.
