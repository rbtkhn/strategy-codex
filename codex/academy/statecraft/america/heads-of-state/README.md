## Core Question

Who can turn American state interest into binding authority, and what can they not concede without breaking domestic legitimacy, alliance credibility, or successor continuity?

## Use In Transactions

Before drafting an America transaction, ask:

- Does the executive have authority to sign and implement this?
- Does Congress, the courts, the military, or allied command structure need to carry it?
- Would a successor American authority honor it?
- What phrase lets restraint look like command rather than decline?
