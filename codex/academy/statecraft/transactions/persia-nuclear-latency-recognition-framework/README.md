# Iran Nuclear Latency Recognition Framework

This surface is non-authoritative and subject to revision.

Purpose: compare one crisis object across the four academy-statecraft national lanes. This framework tests whether Iran's nuclear latency can be converted from an escalation trigger into a bounded recognition, inspection, restraint, and non-regime-change bargain.

## Crisis Object

Iran's nuclear latency is not the same as an openly declared nuclear arsenal. It is a threshold condition: enough knowledge, infrastructure, and deterrent ambiguity to shape bargaining, but not necessarily a settled weaponization decision. A durable framework must recognize the threshold without rewarding breakout, humiliating Iran, or inviting preventive war.
