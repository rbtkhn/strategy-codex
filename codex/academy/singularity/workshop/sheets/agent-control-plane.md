# Agent Control Plane

WORK only; not Record.

## Purpose

Use this as the first singularity workshop sheet. It tests any agent governance system by asking where agency, authority, alignment, receipts, rollback, and human meaning actually live.

## Case Anchor

The local reference case is enterprise agent governance: Agent 365 as a control-plane pattern, and Grace-Mar/strategy-codex as a local-first, human-gated analogue. The comparison is useful only if the boundary remains clear: enterprise control planes govern agent fleets; the local substrate protects authorship, provenance, and Record authority.

## Working Questions

- What can now act faster, cheaper, longer, or at larger scale?
- Who or what is the agent: model, tool, workflow, admin layer, human operator, institution, or hybrid?
- What objective is being optimized, and who set it?
- Who can inspect tool calls, memory, permissions, traces, receipts, and failures?
- Where does authority live: model context, enterprise tenant, local repo, gate, human judgment, or external policy?
- What can stop the system before it canonicalizes a mistake?
- What human role, dignity, attention pattern, or relationship is displaced?

## Counter-Reading

Agent governance can become a comfort story. Observability is not authority, traces are not judgment, and administrative control is not the same as humane alignment. Conversely, local sovereignty can become theater if it lacks receipts, rollback, and usable review paths.

## Output Prompts

- Write a control-plane note with five fields: agent, objective, authority, observability, rollback.
- Mark one boundary that must not be absorbed by enterprise tooling.
- Name one human skill or office that becomes weaker if the agent layer succeeds.
- Draft one test that would prove whether a system preserves authorship rather than merely logging activity.
