# Scenario Lab Pilot

WORK only; not Record.

Use this sheet when a singularity question needs more than a memo and less than a full strategic doctrine rewrite.

Scenario Lab is the right route when the live question is:

- structured future branching
- ranked scenario families
- actor pressure or decision pressure
- explicit assumptions versus evidence
- statecraft-style or company-action style futures under acceleration

Use it for questions like:

- what does compute sovereignty pressure do to agent-control choices over the next 12 months?
- what company-action branches become more likely if local-first AI control planes get cheaper?
- which actor families dominate if a live acceleration front keeps compounding?

Do **not** use it as:

- governed truth
- automatic gate input
- a replacement for ordinary forecasting, strategy writing, or technical implementation notes

## Pilot Boundaries

- Scenario Lab outputs are **derived simulation artifacts**
- they are **advisory only**
- they do **not** imply approval, evidence truth, or Record authority
- any durable downstream claim must still be routed separately and explicitly

## Default Pilot Flow

1. Pick one singularity-shaped question.
2. Build one intake/evidence packet from local surfaces.
3. Run one bounded simulation.
4. Produce one readable report.
5. Produce one visualization-ready artifact.
6. Decide whether the pilot should expand, contain itself, or retire.
