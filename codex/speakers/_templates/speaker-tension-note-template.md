# Speaker tension note template

WORK only; not Record.

Purpose: define a reusable scaffold for **expert-vs-expert disagreement notes** that cut across existing speaker surfaces without pretending to be an arc or a thread.

System grammar:

- **Person arc:** `<speaker>-arc.md` for one speaker's continuity across hosts, contexts, and time.
- **Relational arc:** `<host>-<speaker>-arc.md` for what a specific host repeatedly elicits from that speaker.
- **Topical thread:** `<speaker>-thread-<topic>.md` for one recurring topic inside a larger arc.
- **Tension note:** `<speaker-a>-vs-<speaker-b>-<window>.md` for a bounded disagreement or interpretive split between two speakers.

Ownership rule:

- Choose an **arc** when the question is "whose continuity is this?"
- Choose a **thread** when the question is "which recurring strand inside that arc needs its own named surface?"
- Choose a **tension note** when the question is "where exactly do these two speakers diverge, and how should the notebook route that disagreement?"

## Tension note

# `<speaker-a> vs <speaker-b> - <window>`

WORK only; not Record.

Use a tension note when two speakers meaningfully disagree and the notebook needs a compact, source-backed map of that split.

**Naming rule:**

- Use a concrete time or event window, for example `2026-05`, `iran-war-window`, or `ukraine-spring-2026`.
- Keep the filename symmetric and plain: `<speaker-a>-vs-<speaker-b>-<window>.md`.

**Recommended shape:**

- `Scope`
- `Main split`
- `Specific disagreements`
- `Deeper pattern`
- `Notebook use`

## Scope

List the local anchors that substantiate the disagreement.

- [{source-1}]({source-1-path})
- [{source-2}]({source-2-path})
- [{optional-source-3}]({optional-source-3-path})

State the bounded claim:

- what dispute this note captures
- why this comparison window matters
- what it does **not** try to settle

## Main split

State the headline disagreement in one or two sentences.

Then map each side cleanly:

`{speaker-a}`:

- {claim-a-1}
- {claim-a-2}

`{speaker-b}`:

- {claim-b-1}
- {claim-b-2}

## Specific disagreements

Break the split into a few discrete sub-questions.

### 1. {first-point-of-disagreement}

Explain where the two lines part company and what evidence in the local source spine supports that reading.

### 2. {second-point-of-disagreement}

Repeat only where the disagreement is materially distinct.

### 3. {optional-third-point}

Use only if needed.

## Deeper pattern

Name the underlying worldview or method split.

Examples:

- macro-intent vs material constraint
- systemic scripting vs operational realism
- legitimacy framing vs force-balance framing

This section should explain why the disagreement recurs, not just how it appeared once.

## Notebook use

Use this note when the notebook needs:

- a fast map of where two speakers disagree
- a bridge between multiple speaker arcs without flattening them
- a reusable citation surface for future conflict-window comparisons
- a reminder that the disagreement lives in method as well as conclusion

## Boundary

Do not use a tension note for:

- a single speaker's continuity surface that should be an arc
- a recurring topic nested inside one speaker's arc that should be a thread
- a host-local lane that should be a relational arc
- a verdict memo that pretends the disagreement has already been settled
- a raw-input ledger or transcript sink

Treat a tension note as a cross-surface comparison aid. It routes disagreement; it does not replace the underlying arcs, threads, or source anchors.
