## Strand tests for backward promotion

Use these tests before pulling earlier material into the canonical atlas:

- does the earlier item clearly express one of the current canonical Johnson strands?
- does it change routing use, or is it only a proto-version of a later stronger anchor?
- is the strand already visible across more than one host, or only in one isolated appearance?
- would adding the earlier item sharpen continuity, or merely increase volume?

If an earlier item fails those tests, keep it in the raw-input bench or in a bridge prep note rather than broadening the atlas prematurely.
