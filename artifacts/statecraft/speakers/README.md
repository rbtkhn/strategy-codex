# Statecraft speaker artifacts

This directory holds **derived, rebuildable, non-canonical** speaker-centric statecraft observability outputs.

- `speaker-dashboard.md` and `speaker-dashboard.json` summarize recurring guests across the dated statecraft archive.
- Saved guest slices are written under `artifacts/statecraft/voices/slices/`.
- Rebuild with `python scripts/build_statecraft_speaker_dashboard.py`.
- These files are navigation and observability surfaces only; they do not replace the underlying archive captures, day indices, or day dashboards.
