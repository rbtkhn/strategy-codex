# Civilizational Pattern Library

Use this as the pattern shelf above the Rome, China, and Persia bibliographies.

This library extracts reusable CIV-STATE patterns without flattening the civilizations into one template. It is optimized for retrieval and drafting: each card names a recurring civilizational mechanism, shows how it appears across the three core shelves, and points back to source doors rather than reproducing whole bibliographies.

This is distinct from:

- the [Glossary](../../glossary.md), which defines terms more generally
- the volume bibliographies, which remain the primary source-bearing shelves
- [Continuity Mechanism](../continuity-mechanism.md), which remains a separate comparison sheet focused on one governing question

## Working Rule

Use this shelf when the operator needs:

- a reusable comparative pattern
- a cross-civilizational drafting lens
- a quick route from abstract mechanism back to source doors

When the question becomes civilization-dominant rather than pattern-dominant, return to the relevant bibliography or comparison sheet before drafting.
