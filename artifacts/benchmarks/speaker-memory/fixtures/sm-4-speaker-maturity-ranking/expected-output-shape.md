# SM-4 Expected Output Shape

A strong answer should produce:

- a ranked comparison of at least three speakers
- visible dimension language for each ranked shelf
- a reasoned winner, not just a numeric winner
- at least one mismatch case:
  - dense but incomplete
  - thin but coherent
  - mature branch without full helix

The best answers preserve the distinction between:

- `helix-first`
- `single-branch mature`
- `cross-host reinforced`
- `still embryonic`

Weak answers:

- rank by file count alone
- treat all mature shelves as the same shape
- flatten cross-host and host-local structures into one bucket
