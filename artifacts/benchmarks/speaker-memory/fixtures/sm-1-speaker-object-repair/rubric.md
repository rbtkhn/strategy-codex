# SM-1 Rubric - Speaker Object Repair

Score each dimension from 1 to 5.

| Dimension | 5 | 3 | 1 |
|---|---|---|---|
| Object-shape judgment | Chooses and justifies `cross-host-reinforced` from the evidence | Uses a plausible but under-justified shape | Chooses an unsupported shape |
| Open-first quality | Gives concrete entry paths that help future agents route quickly | Gives generic or weak entry paths | No useful open-first path |
| Boundary discipline | Clearly names what not to overclaim | Mentions limits vaguely | Overclaims or omits limits |
| Source restraint | Stays inside the source pack | Minor unsupported embellishment | Invents biography or facts |
| Routing usefulness | Future check-streams or speaker-routing work can use the note directly | Some routing help, but unclear | Not useful as an orientation object |

Close as `Held` only if every dimension is at least 4.
