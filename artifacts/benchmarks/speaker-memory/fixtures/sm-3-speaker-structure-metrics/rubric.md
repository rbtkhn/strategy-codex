# SM-3 Rubric - Speaker Structure Metrics

Score each dimension from 1 to 5.

| Dimension | 5 | 3 | 1 |
|---|---|---|---|
| Metric discipline | Keeps the four dimensions distinct and justified | Distinctions partly blur | Everything collapses into one impression |
| Evidence grounding | Uses concrete shelf evidence, counts, and linked surfaces | Some evidence, some hand-waving | Mostly vibe or unsupported claims |
| Density restraint | Rewards structured recurrence, not pileup | Mixed signal | Equates more files with better shelf |
| Completeness realism | Names missing surfaces, gaps, or URL holes accurately | Notes some gaps | Pretends the shelf is closed when it is not |
| Coherence judgment | Correctly identifies classification consistency or drift | Partly sees structure | Misses contradiction or legacy leakage |
| Maturity judgment | Derives maturity from structure and continuity | Plausible but thin | Inflates or misclassifies the object |

Close as `Held` only if every dimension is at least 4.
