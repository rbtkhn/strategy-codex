# SM-4 Rubric - Speaker Maturity Ranking

Score each dimension from 1 to 5.

| Dimension | 5 | 3 | 1 |
|---|---|---|---|
| Comparative discipline | Uses a shared metric language across all cases | Comparison is partial | Cases are incomparable or ad hoc |
| Ranking judgment | Winner and ordering are well defended | Ordering is plausible but thin | Ranking is arbitrary |
| Shape awareness | Distinguishes helix-first, single-branch mature, and reinforced objects | Some shape distinctions | All objects treated as the same thing |
| Mismatch insight | Identifies dense-but-messy or thin-but-clean cases clearly | Notes one mismatch weakly | No mismatch insight |
| Boundary restraint | Keeps claims bounded to the compared shelves | Some overreach | Declares universal doctrine from a few cases |

Close as `Held` only if every dimension is at least 4.
