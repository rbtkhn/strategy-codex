# Source-Mode Tension Note

**Conductor:** `furtwangler`  
**Prompt:** source-mode tension after first Kleiber CM-1 run  
**Benchmark:** `cm-1-humanoid-robots`  
**Prior closeout:** `Held`  

## Tension

The first CM-1 run held as a composition benchmark, but only in `prompt_only` mode. That means the run tested whether the model could obey Strategy-codex page structure, use civ-mem as mechanism, preserve mismatch, and produce a revisitable call. It did **not** test whether the model could ground the humanoid-robotics frame in dated evidence.

This is not a flaw in the run. It is the condition that must remain visible.

## What Prompt-Only Proved

- The strategy-page template can contain the CM-1 task cleanly.
- The model can use civ-mem mechanistically rather than decoratively.
- The output can label analogy strength and state mismatches.
- The Call / Falsifier / Revisit loop can be made explicit.
- The prose avoided obvious doom/utopia flattening.

## What Prompt-Only Did Not Prove

- Whether Figure, 1X, Tesla Optimus, or other humanoid robotics claims are current or accurate.
- Whether deployment timelines, cost curves, capabilities, or customer use cases support the strategic frame.
- Whether the civ-mem mechanism survives contact with dated evidence.
- Whether the proposed falsifier is properly calibrated to actual industry milestones.
- Whether "status migration" remains the best strategic call after source-pack grounding.

## Source-Pack Risk

A future `source_pack` run may weaken the benchmark in either direction:

- **Too much evidence:** the model may become a summary engine and lose the strategy-page shape.
- **Too little evidence:** the model may preserve the elegant mechanism but smuggle in unsupported current claims.
- **Mixed evidence:** the real test is whether it can keep capability claims, market claims, labor claims, and meaning claims in separate lanes.

## Guardrail For Next Run

The next CM-1 run should keep the original prompt but add a dated source pack and require:

- one line separating verified evidence from interpretation
- one line naming the weakest current factual link
- no company capability claim unless tied to the source pack
- revised Call / Falsifier / Revisit if the source pack changes the frame

## Furtwangler Close

The result should stay `Held`, but only for `prompt_only` composition. The unresolved tension is whether the same page discipline holds when factual grounding enters the score.
