# Source-lattice read

Traverse the evidence stack **without confusing doorway, primary shelf, secondary support, and synthesis**.

## Use when

- You know **which civilization-state case** owns the object but not which file to open
- Chronology, attribution, or provenance trouble has appeared mid-read
- Secondary scholarship is starting to **displace** primary source contact
- You are tempted to jump straight to civilization or empire essays before the shelf problem is clear

## Core law

```text
source first, support second, synthesis after
```

Four layers:

```text
doorway → primary floor → secondary support → widened interpretation
```

Full governing law: [Source-Lattice](../sources/source-lattice.md).

| Layer | Where | Reader question |
|-------|-------|-----------------|
| **Doorway** | volume `README.md`, `shelf-reader.md` | Which case is this? How do I traverse the shelf? |
| **Primary floor** | `sources/{civ}/bibliography.md`, `primary/{era}.md` | What are the direct source doors? |
| **Secondary support** | `sources/{civ}/secondary/{era}.md` | What clarifies chronology, provenance, translation, counterweight? |
| **Widened interpretation** | `civilization-*.md`, `empire-*.md`, sub-lenses under `volumes/{civ}/` | What judgment does the chain bear now? |

## Steps

1. **Open the doorway** — volume [README](../volumes/README.md) and, if needed, that volume's `shelf-reader.md`.

2. **Stay on the primary floor** when the issue is:
   - legitimacy wording or founding language
   - direct source contact or constitutional phrasing
   - the civilization's own self-description

   Open `sources/{civ}/bibliography.md`, then the era-matched `primary/{era}.md`. Era anchors: [Era spine](../docs/era-spine.md).

3. **Open secondary support** only when difficulty appears:
   - chronology, provenance, translation
   - institutional context or counterweight trouble

   Use `sources/{civ}/secondary/{era}.md` — then **return to primary** before widening upward.

4. **Move upward** only after the shelf problem is clarified:
   - volume introduction → **Civilization** → **Empire**
   - optional sub-lenses (`geo-strategy`, `secret-history`, `game-theory`) when pressure geometry is already clear

5. **Cross-volume comparison** only after one volume grammar is clear — [Cross-case recurrence](../essays/cross-case-recurrence-and-sovereignty.md).

## Switchboard (quick)

| Signal | Action |
|--------|--------|
| Legitimacy language, sacred grammar, legal form | Primary shelf |
| Attribution, dates, translation, counterweight | Secondary → back to primary |
| Present carrier, outward instrument, overreach | Civilization → Empire |
| "Which civ owns this?" not yet settled | [Civilization-first entry](civilization-first-entry.md) first |

## Do not

- Let secondary scholarship become the new center of gravity
- Open synthesis essays to substitute for primary contact
- Compare cases before one case's sovereignty chain is readable
- Skip the bibliography — it orients the era files
