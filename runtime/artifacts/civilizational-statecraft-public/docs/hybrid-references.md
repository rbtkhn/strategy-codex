# Hybrid References

This surface replaces a pure academic bibliography with a CIV-STATE-native references law.

It sits above, and does not replace, the bibliography that each civilization-state volume should carry for its own primary-source field.

It should answer three questions:

1. What source layers actually ground these books?
2. What evidence construction law governs trustworthy generation?
3. What named intellectual ancestry quietly shapes the apparatus without becoming its visible voice?

## Reference Law

Civilizational Statecraft uses a hybrid references model because the work is neither a raw archive nor a finished scholarly monograph.

Its references therefore combine:

- source basis
- primary sources
- secondary sources
- evidence construction law
- bounded named works and figures where grounding is stable

This prevents two errors:

- fake academic finish without real evidence discipline
- pure source-basis abstraction with no intelligible reference field

The governing bias is explicit:

- **primary sources should dominate**
- secondary scholarship should support, clarify, or counterweight
- named intellectual ancestry should explain apparatus formation, not replace evidentiary grounding

The practical stack therefore reads:

- `primary-sources` = sovereign evidence
- `shelf-reader` = traversal guidance
- `secondary-sources` = bounded clarification and counterweight
- `source records / excerpts / sidecar full text` = deeper primary-text substrate

The shared role taxonomy for this stack is:

- `chronology`
- `provenance`
- `translation`
- `institutional_context`
- `counterweight`
- `misreading_correction`

The shared recurrence taxonomy for repeated secondary works is:

- `cross_civilizational_recurring`
- `civilization_specific_recurring`
- `era_local`

The shared promotion taxonomy for repeated interpretive work is:

- `local`
- `promotable`
- `promoted`

## Primary-Source Preference

Whenever the references layer can name a primary source cleanly, it should do so before reaching for later interpretation.

Primary sources here include, as appropriate:

- founding laws, constitutions, decrees, oaths, and charters
- sacred texts, liturgies, doctrinal formulations, and canonical religious writings
- chronicles, annals, legal codifications, and state-forming texts
- speeches, letters, memoirs, diplomatic settlements, and treaty texts
- classical literary or philosophical works when they are carrying the civilization's own self-understanding directly

Secondary and tertiary materials should enter mainly to:

- corroborate
- bound
- counterweight
- explain why a primary source should be treated as structurally important

They should not displace the primary-source center of gravity.

## Generation Law

Default generation chain:

`seed MEM -> MEM CONNECTIONS cluster -> overview corroborators -> counterweight -> book-native translation`

Construction rules:

- start with one seed MEM
- read the relevant MEM CONNECTIONS cluster
- use `CIV-CORE-*`, `CIV-STATE-*`, and `CIV-DOCTRINE-*` as corroborators and bounds
- install counterweight during generation, not after
- translate into CIV-STATE-native book prose

Fallback rule:

- if evidence is weak, narrow the entry
- mark it provisional in substance even if not with a formal badge
- do not fabricate smoother completeness than the source can bear

## evidence spine Visibility Rule

`evidence spine` should be most visible in:

- this references surface
- selected provenance logic behind [Glossary](glossary.md)
- retrieval support in [Index](index.md)

It should be less visible in:

- [Table of Contents](table-of-contents.md)
- [Reader Guide](reader-guide.md)

Those surfaces should remain book-native and operator-facing rather than evidence-mechanical.

## Reference Mix by Surface

Use this bias inside the apparatus:

- [Glossary](glossary.md): primary-source-grounded concepts and names first; evidence spine and overview layers provide retrieval discipline behind them
- [Index](index.md): names, peoples, polities, and routes may reflect the evidence lattice, but should remain readable without source jargon
- each volume-local bibliography: primary sources dominate, bounded secondary supports remain subordinate, and evidence spine evidence law stays visible but translated
- each volume-local `secondary-sources` file: human-facing clarifiers and counterweights chosen through evidence spine construction law but written without evidence spine voice
- this references surface: the main visible place where primary sources, evidence spines, bounded secondary scholarship, and intellectual ancestry are distinguished from one another

## Bounded Intellectual Ancestry

The books are formed by an implicit statesman-historian lineage rather than by direct imitation.

### Whole-work carriage

- **Will Durant** - comparative civilizational sweep
- **Winston Churchill** - founding-to-present political motion and grave carriage

### Governing logic

- **Henry Kissinger** - order, legitimacy, equilibrium, settlement possibility
- **Niccolo Machiavelli** - founding, necessity, corruption, restoration
- **Otto von Bismarck** - unification through bounded power, post-victory restraint

### Continuity and settlement

- **Talleyrand** - survival through transformed carriers and regime change
- **Klemens von Metternich** - anti-chaos restoration and structured equilibrium

### Anglo-republican tact and contradiction

- **Benjamin Franklin** - practical tact, coalition-bearing usefulness, worldly statecraft sobriety
- **Thomas Jefferson** - republican creed under contradiction, especially in the American case

These figures are explanatory companions to the apparatus law, not citation authorities that replace public lecture corpus or evidence spine evidence.
