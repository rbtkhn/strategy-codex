# Sacred Grammar Library

WORK only; not Record.

This shelf is the canonical CIV-STATE retrieval layer for **deep grammar** and the canonical first stop when legitimacy or truth-order is governing the object.

Use it when the question is not yet "who opened the sovereignty chain?" or "who carries it now?" but rather:

- what makes authority feel rightful here
- what truth-order or symbolic inheritance stabilizes rule
- what covenant, ritual order, Orthodoxy, providence, juridical universality, or moral cosmology authorizes the claim
- what survives conquest, secularization, mutation, or humiliation more deeply than institutions alone

## What Sacred Grammar Means

Sacred grammar is the legitimacy substrate beneath sovereignty.

It includes:

- sacred order, myth, ritual, providence, law, and moral cosmology
- symbolic pictures of rightful rule
- continuity logic that survives regime change more deeply than office or administration
- civilizational self-understanding about justice, suffering, mission, restraint, corruption, or renewal

It is **not**:

- the same thing as sovereign opening
- the same thing as current carrier
- a synonym for official religion
- a theological encyclopedia
- a policy memo or transaction surface

## Retrieval Rule

Build sacred-grammar judgments in this order:

1. start with one seed MEM that most directly names the grammar
2. read that MEM's **MEM CONNECTIONS** section
3. traverse the most relevant connected MEMs
4. use `CIV-CORE-*`, `CIV-STATE-*`, and `CIV-DOCTRINE-*` only as corroborating overview layers
5. translate the result into CIV-STATE-native prose

Hard rule: this shelf uses `civilization_memory` as evidence only. It must not copy civ-mem sectioning, governance boilerplate, or template voice into operator doctrine.

- **Core grammar**

Treat the shelf as the router for:

- **Seed MEM**

## How To Route

- if the question is **what makes this authority feel rightful**, start here
- if the question is **who opened the political chain**, go back to the volume opener doctrine
- if the question is **who bears the chain now**, go to helix, state, and transaction surfaces
- if the question is **what instrument can be drafted from this**, continue downstream into lane or transaction files
