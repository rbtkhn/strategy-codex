# CIV-STATE Review Queue

WORK only; not Record.

This queue is the governed upstream membrane from repo-root statecraft back into `civ-state`.

Its purpose is narrow: capture source-memory discoveries exposed by downstream drafting without silently mutating the source base.

## What Belongs Here

Valid upstream candidate types:

- missing counterweight
- retrieval refinement
- object-schema improvement
- source-pattern correction
- transaction-hook refinement

## What Does Not Belong Here

- lane routing tweaks
- helix interpretation changes
- objection-matrix patches
- direct transaction drafting improvements
- silent source edits made from one live pass

Those belong in lane-local update surfaces or downstream statecraft artifacts.

## Candidate Shape

Use this block for each new reviewable candidate:

```markdown
## CIVEMP-YYYYMMDD-XX
- Candidate type:
- Triggering artifact:
- Source object(s):
- Problem found:
- Proposed source-memory change:
- Why this belongs upstream:
- Downstream artifact already adjusted? yes / no
- Review status: pending
```

## Review Law

- Draft downstream statecraft adjustments first when needed.
- Stage upstream source-memory issues here second.
- Do not silently synchronize both layers from a single drafting turn.
- Use this queue to make `civ-state` better at remembering, not to make it absorb downstream policy language.
