Purpose: define the first stable proof set for `statecraft/daily` method changes, audits, and future lightweight validators.

This manifest is intentionally small. It exists to falsify method changes quickly rather than to simulate full corpus coverage.

## Use Rule

Use this benchmark set whenever:

- the daily or monthly method changes
- the local skill contract changes
- the audit rubric changes
- a future validator or script begins enforcing structure
- a new output style claims to improve the shelf

The default benchmark question is:

`does the new method preserve or improve these proofs without flattening them into cleaner but weaker notes?`

## Future Additions

Add a new benchmark only when it proves something meaningfully new that the current set does not already cover.

Good reasons to add one:

- a sparse-day proof case is needed
- a Russia-heavy day exposes a different five-volume stress profile
- a later month proves a stronger version of cross-speaker compression

Do not grow this manifest just because more good notes exist. The point is fast falsification, not exhaustive canon-building.
