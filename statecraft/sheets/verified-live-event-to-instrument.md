# Verified Live-Event To Instrument

WORK only; not Record.

Use this sheet when the operator names one recent event and needs the shortest honest path from unstable facts to a statecraft artifact.

This is a teaching surface, not a second router. It exists to show the motion clearly:

`verify -> classify crisis object -> assign lane ownership -> choose output form -> draft instrument`

If you are already confident about that motion, go straight to `state-deploy`, the owning lane, or [transaction-router.md](transaction-router.md).

## Five Moves

1. **Verify the unstable fact pattern.**
   - Name what is actually known.
   - Separate fact from interpretation.
   - Refuse to draft from rumor, label-war, or atmosphere alone.

2. **Classify the crisis object.**
   - Ask what is actually being contested.
   - Prefer the narrowest classification that changes leverage, escalation, or settlement.
   - A quarantine is not yet an invasion.
   - A corridor is not yet extraterritorial control.
   - A command scare is not yet regime collapse.

3. **Assign lane ownership.**
   - Ask which lane has to carry the settlement logic if a draft is written now.
   - If ownership is unresolved, open `state-deploy`.
   - If ownership is clear, hand directly to the lane.
   - If the object is already cross-lane and mechanism-shaped, open [../compact/README.md](../compact/README.md).

4. **Choose the narrowest honest output form.**
   - Commentary when the object is still mostly naming pressure.
   - Lane note or memo when ownership is clear but the mechanism is still thin.
   - Transaction-fit note when the object may already belong to an existing bundle.
   - Full instrument only when the crisis object, authority carriers, and settlement spine are real.

5. **Draft the smallest instrument that preserves authority, restraint, and settlement.**
   - One clause, one memo wedge, one recognition formula, one review trigger, one corridor rule, one de-escalation channel.
   - Do not reward urgency with premature framework inflation.

## Quick Recognition Rules

- If the event is still mostly "who did what to whom?", stop at verification and classification.
- If the event is really "what kind of object is this?", stop at crisis-object naming.
- If the event is really "who has to carry the settlement?", stop at lane ownership.
- If the event is really "does a known bundle already fit?", open [transaction-router.md](transaction-router.md).
- If the event is really "what sentence or clause could stabilize this?", draft the narrowest wedge and stop.

## Common Failure Modes

- **Headline capture**: the event's salience replaces the crisis object.
- **Lane skipping**: a speaker, analogy, or preference is mistaken for ownership.
- **Framework inflation**: a good note is promoted into a treaty or compact too early.
- **Mechanism without carrier**: the clause sounds elegant but nobody real can carry it.
- **Settlement blur**: pressure is described well, but the off-ramp is still missing.

## False Elegance Ladder

Use this when a read sounds coherent too early.

The ladder is a deliberate three-pass stress test:

1. write the first wrong read
2. write the second wrong read
3. write the right read only after the two failures are visible

Default shape:

```markdown
**False Elegance Ladder**
- Wrong read 1:
- Wrong read 2:
- Corrected read:
- What the wrong reads blurred:
- What the corrected read makes obvious:
```

Pass condition:

- the corrected read names a sharper crisis object
- lane ownership becomes cleaner
- the next retrieval or drafting step becomes more concrete
- the earlier reads now look elegant but false

## Where To Apply It

The ladder is reusable anywhere the system is tempted to sound persuasive before it is well classified.

- **Lane ownership**
  Use it before or alongside `state-deploy` when a live object could be misowned by one lane or prematurely flattened into cross-lane elegance.
- **Transaction threshold**
  Use it before promoting an event into a compact or framework. One wrong pass assumes it obviously deserves transaction form; the corrected pass checks whether the crisis object and settlement spine are real.
- **Framework diagnosis**
  Use it before or alongside `statecraft-framework` when the operator may be confusing the civilization-state object, the doctrine, and the downstream drafting layer.
- **Sacred Grammar retrieval**
  Use it when a read risks collapsing deep legitimacy into either official religion or generic culture.
- **State-memory and arc-lens backfills**
  Use it when a note starts sounding rich but is really drifting into biography, grievance collage, or summary history.
- **Speaker-to-statecraft translation**
  Use it when a speaker sounds compelling and the system needs to separate usable statecraft object from speaker-overtrust or generic geopolitics.
- **Compact versus lane drafting**
  Use it when a cross-lane mechanism sounds elegant but may really belong inside one lane first.
- **Clause drafting**
  Use it at sentence level: tactically strong clause, morally elegant clause, and civilization-state-carryable clause.
- **Mutation analysis**
  Use it when an object may be keeping its name while changing function under pressure.
- **Singularity-to-statecraft handoff**
  Use it when an acceleration object may be lingering too long in substrate talk instead of being recognized as a civilization-state or instrument problem.

## Teaching Line

The shortest honest statecraft path is not "event -> opinion -> framework."

It is:

`event -> crisis object -> owner -> form -> instrument`

And when the path still feels too smooth too early, use the **False Elegance Ladder** before trusting the draft.
