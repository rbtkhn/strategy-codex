# Host Backbone - Napolitano and Davis Orthogonality - 2026-05

WORK only; not Record.

Use this sheet when a live statecraft read is bouncing between `Judging Freedom` and `Daniel Davis Deep Dive` and the operator needs to decide which host pressure actually owns the next move.

This is not a speaker shelf. It is a host-backbone routing note for preserving the repo's two clearest recurring host transformations without flattening them into one anti-war blob.

## Core distinction

| host | primary transformation | main question | common mistake |
| --- | --- | --- | --- |
| `Napolitano` | legal / process / constitutional pressure | What is illegal, incoherent, self-entangling, or institutionally absurd about this crisis path? | treating legal-process pressure as if it were feasibility analysis |
| `Davis` | feasibility / bargaining / settlement-room pressure | What can actually work, what leverage remains, and what settlement room is real? | treating practical war-termination analysis as if it were mainly legal critique |

## One-sentence rule

If the question is `who can authorize this, justify it, or survive it domestically?`, open `Napolitano` first. If the question is `can this still work in the real world, and what room is actually left?`, open `Davis` first.

## Shared backbone, different tasks

Both hosts repeatedly filter guests through anti-war pressure, but the pressure is not the same.

- `Napolitano` sharpens toward:
  - war powers
  - legal absurdity
  - command incoherence
  - executive self-entrapment
  - state overreach
- `Davis` sharpens toward:
  - force feasibility
  - coercive limits
  - bargaining geometry
  - inventory and posture reality
  - whether an off-ramp is structurally real

## Open first by problem type

### Open `Napolitano` first when the problem sounds like:

- `is this legal?`
- `who has constitutional authority?`
- `is this executive process coherent enough to count as real state action?`
- `has Washington boxed itself in?`
- `is the host sharpening the guest into a war-powers or civil-liberties problem?`

### Open `Davis` first when the problem sounds like:

- `can this military plan still work?`
- `what leverage is actually left?`
- `what can coercion no longer recover?`
- `is there any real bargaining room?`
- `what settlement structure survives the rhetoric?`

## Mixed-question rule

If the read contains both legal/process and feasibility/settlement content:

1. start with the host that owns the dominant failure mode
2. only open the second host if the first host leaves a real unanswered question
3. do not treat `agreement` between the two hosts as proof they are doing the same job

Typical examples:

- `Hormuz blockade legality` -> open `Napolitano` first
- `Hormuz blockade practicality` -> open `Davis` first
- `Trump boxed himself in and now has no workable military path` -> `Napolitano` then `Davis`
- `bombing campaign cannot achieve the political objective, and the legal story is collapsing too` -> `Davis` then `Napolitano`

## Drafting prompt

Before routing a mixed host problem, write one sentence:

> The dominant failure mode here is `[legal-process incoherence / feasibility-settlement collapse]`, so the first host to open is `[Napolitano / Davis]`.

Then write the second sentence only if needed:

> The secondary host matters only because `[specific unanswered question]` remains unresolved after the first-open read.
