# Expert orthogonality note

WORK only; not Record.

Purpose: preserve the distinct jobs of the Pape, Crooke, Ritter, and Parsi speaker objects when they cover the same Iran-war, Hormuz, escalation, or negotiation surface.

These four speakers should be read as adjacent instruments, not substitutes.

## Boundary Tests

### Pape vs Ritter

Both track escalation.

- Use **Pape** when the object is the escalation mechanism: trap, clock, threshold, falsifier, shortage chain, commitment ratchet.
- Use **Ritter** when the object is military feasibility: aircraft, ships, bases, personnel risk, recovery requirements, munitions, blockade mechanics.

### Pape vs Parsi

Both track coercion failure and bargaining.

- Use **Pape** when coercion fails because the system generates escalation, shortages, counter-pressure, or forecastable strategic branches.
- Use **Parsi** when coercion fails because the diplomatic terms, legitimacy structure, guarantees, sanctions relief, or regional architecture are wrong.

### Crooke vs Parsi

Both track off-ramps and negotiations.

- Use **Crooke** when negotiation language is theater inside a deeper structural or civilizational rupture.
- Use **Parsi** when the question is whether a specific diplomatic route, ceasefire, proposal, or settlement architecture can work.

### Crooke vs Ritter

Both can sound severe.

- Use **Crooke** when the severity comes from order-level unraveling, Western epistemic failure, or structural trap.
- Use **Ritter** when the severity comes from operational danger, military-professional warning, or force-employment reality.

## Anti-flattening Rule

Do not let shared topic overlap collapse the four objects into one generic Iran-war commentary shelf.

- Pape asks: **what mechanism is unfolding, and what would falsify it?**
- Crooke asks: **what deeper structure or misreading is driving the crisis?**
- Ritter asks: **what can the force actually do, and what danger follows?**
- Parsi asks: **what settlement architecture or diplomatic sequence could still matter?**

When a task touches all four, use them in that order only if the task itself requires it: mechanism, structure, force reality, diplomacy. Otherwise open the narrowest speaker object that matches the question.
