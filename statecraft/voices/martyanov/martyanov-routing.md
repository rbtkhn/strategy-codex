## Current Shelf Rule

Martyanov is canonical as a speaker shelf because the same military-systems object recurs across hosts.

He is not a month-ladder shelf because the chronology is still owned more cleanly by host arcs, source captures, and a bounded raw-input bench than by speaker-native monthly synthesis. But the 2025 Dialogue Works side is now visibly deeper than the shelf used to admit, so route through Martyanov earlier when the question is branch emergence rather than only fully materialized continuity.
