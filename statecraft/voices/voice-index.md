## Routing classes

- **Analyst voice** — recurring guest/author with `{slug}-index.md` under `statecraft/voices/<slug>/`.
- **Split identity** — same person is both a **guest** on other hosts and **host** on their own channel; one row with `guest:` and `host:` (Alkhorshid, Davis, Diesen, Mercouris).
- **Host-only channel** — show/host law only; **no** analyst voice shelf → **Channel indexes** section (Reason to Resist / Lascaris, Breaking Points, Judging Freedom, …).

Do not add host-only hosts as `voices/<slug>/` shelves. Route contract detail: [speaker-routing-doctrine.md](speaker-routing-doctrine.md).

## Source index vs source-lattice

- **Voice index** (this file and `*-index.md`; compat `*-source-index.md`) answers **where**: which materialized captures exist and which file to open first.
- **Source-lattice** answers **how / when**: layer order so summary, commentary, and synthesis do not replace the source floor.

After routing through a source index into [source-archive/statecraft/](../../source-archive/statecraft/), apply [docs/source-lattice-beyond-the-repo.md](../../docs/source-lattice-beyond-the-repo.md) (corpus tiers + reading layers). PH chapter objects additionally use [public/predictive-history/docs/source-lattice.md](../../public/predictive-history/docs/source-lattice.md).

Tier-4 commentary cannot substantiate tier-3 wire claims without receipts. See source-lattice doctrine for blocking rules.
