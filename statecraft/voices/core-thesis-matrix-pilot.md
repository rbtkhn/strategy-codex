## Tier Guide

These tiers are not prestige rankings. They are usage classes that help the notebook avoid flattening unlike objects into one thesis machine.

### Tier A - Authored-Pressure Anchors

Use these when the notebook needs one of the four strongest recurring crisis-analysis engines:

- Pape
- Ritter
- Parsi
- Crooke

### Tier B - Statecraft Complements

Use these when a draft needs a distinct complementary plane that the anchors do not carry as naturally:

- Marandi
- Mercouris
- Beebe
- Diesen
- Mearsheimer
- Matlock
- Sachs

### Tier C - Host-Native And Pressure Instruments

Use these when the note needs a host-native instrument or a pressure translator more than a whole civilizational doctrine:

- Davis
- Napolitano
- Barnes
- Johnson
- Baud
- Kent

### Tier D - Force-Balance And Imperial-Constraint Reinforcements

Use these when the notebook needs hard military realism, imperial-burden consequence, or doctrine-bearing reinforcement around the anchor engines:

- Macgregor
- Postol
- Martyanov
- Wilkerson
- Karaganov

### Tier E - Migration-Dependent / Boundary Cases

Use these carefully because the thesis set is strong, but the best canonical live surfaces are still partly migration-bound or unevenly distributed:

- Freeman
- Krainer
- Blumenthal
- Mate

Detailed thesis sections remain in accumulation order below. Use the tier guide as the fast normalization layer, and the speaker sections as the dense reference layer.

## Guardrails

- A `core thesis` must be recurring, source-backed, and shelf-defining.
- A host-conditioned variation does not become a separate thesis unless it changes the retrieval job.
- Some shelves may later prove to have `2 strong theses + 1 support thesis` rather than three equal theses. This pilot still uses three slots for comparability, but the notes below mark when one thesis is structurally lighter.
- `Best file` means best current entry surface, not exhaustive authority.
