# Ritter Historical Examples Audit

Purpose: establish the Ritter historical membrane for the bounded `2025-01-01 -> present` Ritter shelf, using exact Ritter raw-input quotes as evidence authority and `civ-state` as the primary interpretive source base for patterns those examples carry.

This wave is intentionally conservative. It creates the audit and the theme front door before promoting individual theme files or `civ-state` companion indexes.

## Method note

- Ritter raw-input provides quote authority.
- `civ-state` provides the primary pattern-reading layer.
- legacy `civ-mem` is fallback provenance only when `civ-state` is too thin to carry the interpretation.
- this file is an audit scaffold for the migrated statecraft-side Ritter shelf, not yet a full scored historical-example atlas.

## Membrane rule

- the Ritter quote proves that the example was used and shows the immediate claim it served
- the `civ-state` reading explains the deeper pattern, mechanism, and counterweight
- no `civ-state` or `civ-mem` reading should be allowed to overwrite Ritter's actual meaning or invent examples he did not invoke

## Promotion bar

An individual Ritter historical-theme file should be created only when all three are true:

1. the historical example family is explicit in materialized Ritter raw-input
2. the argumentative use repeats across more than one live Ritter route family or month cluster
3. a `civ-state` bucket can be assigned without forcing a speculative read

## Current migration judgment

The migrated Ritter shelf now has enough structure to support a real historical membrane, but this wave does not yet promote named theme files.
