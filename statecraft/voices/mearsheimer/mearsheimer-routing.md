Purpose: make the Mearsheimer speaker object faster to route without duplicating host chronology.

## Core rule

Transcript-first evidence, arc-first interpretation.

For transcript-led Mearsheimer analysis, open the strongest actual transcript or transcript-bearing raw-input first, then use the host-local arc to interpret the host-conditioned transformation.

Mearsheimer does **not** need a native chronology-owning monthly shelf of his own. The efficient structure is:

- host shelves hold chronology
- the speaker shelf holds object identity
- host-local speaker arcs do the primary routing work
- the source index holds the current `non-core appearance bench`
