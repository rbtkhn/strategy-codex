
# Mearsheimer Historical Themes

Purpose: hold the top-five Mearsheimer historical-theme commentary surfaces for the bounded `2025-01-01 -> present` Mearsheimer arc.

These files are not deep-history objects. They are speaker-side commentary surfaces that answer:

- what historical examples Mearsheimer invoked from Jan 1 2025 to the present repo state
- how he used them argumentatively
- which host or route families carry them most clearly
- which generic `civ-emp` bucket should deepen the theme backward through real history

## Use

Open this folder when the task is:

- tracing one recurring historical-theme class across Mearsheimer's 2025-present material
- preparing supplementary evidence for `academy-statecraft`
- deciding which Mearsheimer historical patterns deserve stronger backward historical scaffolding

Open [mearsheimer-historical-examples-audit.md](mearsheimer-historical-examples-audit.md when the task is ranking, scoring, or widening the evidence base.

## Boundary

- These files are not transcript authority; raw-input remains the authority for exact quotes.
- These files are not `civ-emp` objects; they stay on the Mearsheimer side of the membrane.
- There is not yet a dedicated Mearsheimer companion shelf under `academy/statecraft/civ-emp/indexes/`.
- Do not create one file per named example. Each file should hold a recurring theme family.
