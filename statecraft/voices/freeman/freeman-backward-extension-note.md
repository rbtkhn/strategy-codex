# Freeman backward extension note


Purpose: define the next consolidation pass that extends Freeman's canonical thread-atlas surface backward from December 2025 to January 2025 without pretending that the extension is already complete.

## Current situation

Freeman now has a canonical person arc, helix, routing surface, month-spine files for March-April-May 2026, and a canonical recurring-strand atlas at [freeman-dec-2025-may-2026-arc-threads.md](freeman-dec-2025-may-2026-arc-threads.md).

The remaining continuity gap is not structural. It is chronological:

- the current thread atlas begins in `2025-12`
- real Freeman continuity on disk already reaches back to `2025-01-10`
- late 2025 is much denser than early 2025, but early 2025 still matters because it shows the pre-December roots of the same diplomatic-memory and anti-hegemonic lines

This note exists so the shelf has an explicit path backward instead of an implied someday-extension.

## Extension target

The target is not a second competing atlas.

The target is one strengthened canonical atlas that eventually covers:

`2025-01 -> 2026-05`

The December 2025-May 2026 atlas should remain canonical during the extension pass. Expand it only when the earlier material is grouped and justified tightly enough to preserve orthogonality.

## Phase map

### Phase 1: January-May 2025 roots

Main visible anchors already on disk:

- `2025-01`: Davis and Dialogue Works beginnings
- `2025-03`: Diesen
- `2025-04`: Diesen
- `2025-05`: Dialogue Works and Diesen

This tranche is thinner, but it matters because it shows:

- settlement realism already active in Davis
- live-pressure decline language already active in Dialogue Works
- order-transition and diplomatic-collapse framing already active in Diesen

Primary job: identify which later canonical strands are genuinely present this early and which are not yet stable enough to back-project.

### Phase 2: August-November 2025 prelude

This tranche is much denser and should likely be the first actual backward-atlas expansion segment.

Main visible anchors already on disk:

- `2025-08`: Davis and Dialogue Works
- `2025-09`: Dialogue Works, Diesen, and Davis
- `2025-10`: Dialogue Works and Diesen
- `2025-11`: Napolitano, Dialogue Works, and Diesen

This is where the four-lane host system becomes visibly mature before the December crisis-intensification run.

Primary job: establish the pre-December continuity spine that makes the current atlas feel less like a sudden start.

## Recommended extension order

1. Build a bounded `August-November 2025` extension note or atlas-prep note.
2. Promote only the strands that are clearly stable by late 2025.
3. Add `January-May 2025` as roots and early-form evidence, not as forced equal-density material.
4. Only then widen the canonical atlas title/scope beyond `December 2025-May 2026`.

This order matches the evidence density and avoids flattening sparse early 2025 material into false symmetry with the denser late-2025 and 2026 run.

## Strand tests for backward promotion

Use these tests before pulling earlier material into the canonical atlas:

- does the earlier item clearly express one of the six current canonical strands?
- does it change routing use, or is it only a proto-version of a later stronger anchor?
- is the strand already visible across more than one host, or only in one isolated appearance?
- would adding the earlier item sharpen continuity, or merely increase volume?

If an earlier item fails those tests, keep it in the raw-input bench or month/phase prep note rather than broadening the atlas prematurely.

## Boundary

- Do not create a second canonical Freeman thread atlas.
- Do not widen the existing atlas title until the earlier material is grouped and tested.
- Do not let the desire for January coverage force equal treatment of sparse and dense periods.
- Preserve the current structure: person arc, helix, routing, month spines, and one canonical recurring-strand atlas.
