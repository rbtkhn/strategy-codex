
# Karaganov helix

Karaganov is a **single-helix** speaker object, not a multi-host helix.

That is intentional: the direct corpus is Diesen-anchored strategic doctrine, not a symmetric cross-host run like Marandi or Postol.

## The one mature branch

### Diesen × Karaganov

This branch owns:

- nuclear-threshold and deterrence-restoration argument
- world-war framing and anti-Europe escalation logic
- Greater Eurasia, Siberization, post-West identity
- civilizational vocabulary fused with hard-security warning

Sub-shapes inside the branch:

- **Doctrine-origin panel** — Karaganov + Mercouris on 2024-10-21 (Putin shift, Cold War deterrence history, Belarus/deep-strike threshold)
- **Civilizational-origin panel** — Karaganov + Mercouris on 2023-01-14 (Greater Europe → Greater Eurasia, Founding Act, BRICS/SCO, Iran, China)
- **Solo interviews** — pure Karaganov register (2025-05-14, 2025-12-25, 2026-05-10) — all in Statecraft Archive
- **Triangulation panel** — Karaganov + Mearsheimer on 2026-06-13 (doctrine vs structural realism)

## What is not a second helix strand

These are adjacent lanes, not parallel Karaganov host branches:

- **Ritter** — reaction / warning about Karaganov doctrine
- **Mercouris** — Kremlin and Russia-at-war interpretation (tier-4 commentary unless paired to primary)
- **Crooke** — structural rupture from a different speaker object
- **Mearsheimer** — when not co-guest, realism lens on Russian behavior

Do not inflate these into a false multi-host Karaganov helix.

## Boundary

- Single-helix ≠ weak shelf. Karaganov is canonical because the **doctrinal job** is distinct and recurrent.
- Grow toward multi-host shape only if direct Karaganov guest appearances materialize outside Diesen with real density.
- Until then, chronology ownership stays in [arc-karaganov-diesen-host.md](../../notes/arc-karaganov-diesen-host.md).
