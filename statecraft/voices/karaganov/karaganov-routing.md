# Karaganov routing

Purpose: make the Karaganov speaker object fast to route without duplicating Diesen chronology.

## Core rule

Karaganov should usually be opened when a crisis needs **internal Russian elite strategic vocabulary**, especially:

- nuclear-threshold and deterrence-restoration argument
- Europe-as-threat / pivot-east identity framing
- civilizational doctrine fused with escalation logic
- pressure-testing Western lanes against what Russian elite discourse actually says

Default host lane: [Diesen x Karaganov](../../notes/arc-karaganov-diesen-host.md).

## When not to open Karaganov first

Do not open Karaganov first when the task is primarily:

- Kremlin operational policy proof (use primary + Mercouris with fence)
- neutral battlefield ORBAT or map verification
- Iran / Persia MOU transaction shape (use [Marandi](../marandi/README.md) or Parsi)
- U.S. domestic liability (use [Barnes](../barnes/README.md))

## Boundaries

- Karaganov is **elite doctrinal vocabulary**, not settled state policy.
- Ritter / McGovern / Mercouris mentions of Karaganov are **not** direct appearances unless transcript-backed as guest/host.
- Legacy `codex/years/` captures remain valid until archive promotion; prefer `source-archive/statecraft/` when both exist.
