# Macgregor Historical Examples Audit

Purpose: establish the Macgregor historical membrane for the bounded `2025-01-01 -> present` Macgregor shelf, using exact Macgregor raw-input quotes as evidence authority and `civ-state` as the primary interpretive source base for patterns those examples carry.

This wave is intentionally conservative. It creates the audit and the theme front door before promoting individual theme files or `civ-state` companion indexes.

## Method note

- Macgregor raw-input provides quote authority.
- `civ-state` provides the primary pattern-reading layer.
- legacy `civ-mem` is fallback provenance only when `civ-state` is too thin to carry the interpretation.
- this file is an audit scaffold for the migrated statecraft-side Macgregor shelf, not yet a full scored historical-example atlas.

## Membrane rule

- the Macgregor quote proves that the example was used and shows the immediate claim it served
- the `civ-state` reading explains the deeper pattern, mechanism, and counterweight
- no `civ-state` or `civ-mem` reading should be allowed to overwrite Macgregor's actual meaning or invent examples he did not invoke

## Promotion bar

An individual Macgregor historical-theme file should be created only when all three are true:

1. the historical example family is explicit in materialized Macgregor raw-input
2. the argumentative use repeats across more than one live Macgregor route family or month cluster
3. a `civ-state` bucket can be assigned without forcing a speculative read

## Current migration judgment

The migrated Macgregor shelf now has enough structure to support a real historical membrane, but this wave does not yet promote named theme files.

Why:

- the shelf material clearly contains large-order and imperial-decline language
- the live migration work is primarily about speaker continuity, month segmentation, and compatibility safety
- the present evidence was sufficient to justify the membrane, but not yet to justify a stable top-level Macgregor theme set without another quote-scoring pass
