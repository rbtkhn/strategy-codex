
# Crooke Historical Themes

Purpose: hold the top-six Crooke historical-theme commentary surfaces for the bounded `2025-01-01 -> present` Crooke arc.

These files are speaker-side commentary surfaces that answer:

- what historical themes Crooke repeatedly activates from the first materialized 2025 Crooke evidence through the present repo state
- how he uses those themes argumentatively across authored and interview strands
- which route families carry them most clearly
- which `civ-state` companion surface should deepen the theme backward through real history

## Use

Open this folder when the task is:

- tracing one recurring historical-theme class across Crooke's 2025-present material
- preparing supplementary evidence for `civ-state`
- deciding which Crooke historical patterns deserve stronger backward historical scaffolding

Open [crooke-historical-examples-audit.md](crooke-historical-examples-audit.md when the task is ranking, scoring, or widening the evidence base. Open the `civ-state` companion files when the task is backward historical deepening rather than speaker-side recurrence.

## Boundary

- These files are not transcript authority; raw-input remains the authority for exact quotes.
- These files are not `civ-state` objects; they stay on the Crooke side of the membrane.
- Do not create one file per named example. Each file should hold a recurring theme family.
