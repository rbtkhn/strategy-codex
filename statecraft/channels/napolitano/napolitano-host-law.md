# Napolitano Host Law

Purpose: state the governing pressure Napolitano applies so live statecraft routing can open the right host without relying on retired codex doctrine.

## Core Rule

Napolitano is the host to open when the real question is:

- who has legal authority
- whether the process is constitutionally coherent
- whether state action is institutionally absurd
- whether command legitimacy is collapsing under its own contradictions

## Governing Transformation

Napolitano repeatedly pushes guests toward:

- war powers
- legal absurdity
- command incoherence
- executive self-entrapment
- state overreach

## Open Napolitano First When

- a crisis path is being sold through procedural nonsense
- the host pressure is turning a guest into a war-powers or civil-liberties read
- the practical question is secondary to legal or institutional legitimacy
- a shelf is trapped in feasibility language and needs constitutional pressure instead

## Do Not Misread Napolitano As

- a practical military-feasibility host
- a bargaining-geometry host
- a settlement-room host

Those can appear second, but Napolitano owns the legal-process test.
