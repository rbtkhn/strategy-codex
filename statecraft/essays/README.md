## Authority Rule

This README is the **canonical prose-discovery surface for compatibility holdings** in `statecraft/essays/` — not the default destination for new essays.

Use the classifications below strictly:

- `shelf-native` = current essay-class prose authority for this shelf
- `mirrored legacy promotion` = readable compatibility material while taxonomy settles, but **not canonical prose authority**
- `review-needed` = intentionally present edge case that should not be treated as proof that the shelf taxonomy is fully settled

Only items explicitly marked `shelf-native` should be treated as current shelf-native prose authority.

## Formal Role

Use `statecraft/essays/` for:

- more stable long-form arguments
- synthesized framing documents
- carriage-bearing interpretive essays
- stand-alone prose pieces that rise above one bounded route or one partial mechanism note

The local distinction is:

- a **statecraft essay** should carry a broader argument that can travel outside the originating route, bridge, or lane-local seam
- a **statecraft note** should preserve a bounded interpretive object without needing to become the final thesis above it

Do **not** use this folder for:

- constitutional kernels
- journals
- indexes
- sheets
- bridges as structural systems
- transactions
- source-bearing archive material

## Local Test

If the piece can be detached from its original routing context and still make its claim honestly, it is usually essay-class.

Machine-constitutional files stay where they already belong:

- kernels stay in domain roots
- journals stay in journal surfaces
- indexes stay in index folders
- sheets stay in `sheets/`
- bridges stay in `bridges/`
- transactions stay in transaction surfaces

## Promotion Path

Most statecraft essays should come from:

- notes whose bounded seam begins organizing multiple cases
- lane-local or root-level framing pieces that have matured into transportable arguments

Items that remain constitutional definitions, kernels, or operating doctrine should stay in their native surfaces even when the prose is strong.

Historically or institutionally researched essays may also carry:

- a support cluster
- an evidence matrix
- a short evidence posture naming what the citations can honestly sustain

When claim density is high and the evidence base is heterogeneous, prefer a
support cluster rather than forcing all evidence into one essay body.
