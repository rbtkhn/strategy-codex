# Speaker Credibility Matrix


This matrix is the shared comparison surface for provisional speaker trust.

Question:

**How much provisional trust should the notebook extend to this speaker, on what terms, and with what verification burden?**

Do not use this file to decide whether a speaker is "correct overall." That is the job of the paired [speaker-accuracy-ledger.md](speaker-accuracy-ledger.md).

## Factor Rules

- `high` = strong repeated signal in the current materialized corpus
- `medium` = meaningful but mixed signal
- `low` = weak or adverse signal
- `unclear` = too thin, too migration-bound, or not yet audit-closed

## Native Adjustment Notes

- `mercouris`
  - frequent factual walk-backs matter more here than for many shelves because cadence is so high and the stream is so dense
- `ritter`
  - collective and mission-level admission is a real credibility signal here, not merely a rhetorical flourish
- `mearsheimer`
  - retrospective strategic revision matters more than tactical walk-back frequency
- `freeman`
  - lower visible revision should not automatically reduce trust when mechanism, scope restraint, and source seriousness remain high
- `parsi`
  - this shelf earns trust more through settlement architecture and implementation logic than through conspicuous self-correction
  - coherent bargaining design should not be mistaken for already-closed political outcome
- `pape`
  - because this is an authored-forecast-first shelf, falsifier structure matters more than visible revision frequency
  - interview compression should not be treated as identical to the authored ledger
- `macgregor`
  - hard mechanism can coexist with rhetorical inflation; do not treat those as the same thing
- `wilkerson`
  - treat intensity as a host-conditioned style variable unless it degrades evidence posture or scope honesty

## Boundary

- `I hope I'm wrong` is weaker than `I was wrong`
- host-side `correct me if I'm wrong` does not count as speaker correction
- one conspicuous correction does not equal a correction habit
- agreement with the notebook is not a credibility factor
