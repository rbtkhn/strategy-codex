# Speaker Audit Hub

This surface is non-authoritative and subject to revision.

This folder is the live statecraft home for speaker trust and track-record work.

Use this hub when the notebook needs to answer two different questions without collapsing them:

- **Credibility:** how much provisional trust should the notebook extend to this speaker, on what terms, and with what verification burden?
- **Accuracy:** when this speaker makes a bounded claim, how well does it survive later review?

The hub is intentionally central. V1 does not push this tracking burden down into every speaker shelf.

## Governing Preferences

This audit system is calibrated to the following operator preferences:

- truth model: `fallibilist realism`
- core virtue: `revision under disconfirmation`
- confidence rule: bold is acceptable if testable
- evidence rule: primary-source first
- method: critical realism
- comparison rule: hybrid normalization
- charity rule: provisional credit with explicit caveat
- miss rule: weight misses by testability
- rhetorical rule: separate heat from credibility
- deep purpose: trust calibration, not prestige ranking
- objectivity posture: situated but real
- moral norm: intellectual honesty

## Source Hierarchy

Prefer this evidence order:

1. raw transcript / raw input / primary document
2. canonical speaker shelf file that clearly cites primary material
3. compact routing or arc file
4. meta-summary or audit surface

Rules:

- credibility judgments may use shelf synthesis, but strong claims should point back to primary anchors where available
- accuracy scoring should always point to at least one primary or near-primary file
- if a primary text exists, do not justify a strong correction score from tertiary summary alone

## V1 Scoring Defaults

### Credibility

Use only:

- `high`
- `medium`
- `low`
- `unclear`

No numeric rollup in v1.

### Accuracy

Use claim-row statuses only:

- `hit`
- `partial`
- `miss`
- `mistimed`
- `mechanism-right-outcome-wrong`
- `outcome-right-mechanism-wrong`
- `unresolved`
- `not-yet-scoreable`

Also record testability weight:

- `high-testability`
- `medium-testability`
- `low-testability`

## Correction Taxonomy

Use these labels when classifying revision behavior:

- `explicit factual correction`
- `explicit forecast revision`
- `retrospective strategic correction`
- `collective wrongness, not personal correction`
- `conditional openness only`
- `no visible correction in current corpus`

These are credibility labels, not accuracy statuses.

## Boundary

- This hub is not a prestige ranking engine.
- It should not reward timidity or punish boldness by default.
- It should not confuse agreement with the notebook for credibility.
- It should not promote a single composite score before the proving set shows that the categories are stable.
