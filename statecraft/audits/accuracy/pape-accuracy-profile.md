# Pape accuracy profile


## Summary

Pape makes scoreable claims in two main forms: authored forecast rows with explicit falsifiers, and interview-side mechanism calls that push those forecasts into public compression. V1 tracks only bounded 2026 Iran-war claims that already have at least partial closure inside the current corpus.

## Review window

- start: `2026-02-25`
- end: `2026-05-27`

## Claim-selection rule

- include authored forecasts with explicit falsifiers or time windows
- include interview-side claims only when they materially sharpen the forecast into a scoreable proposition
- exclude broad long-horizon geopolitical reorder claims that cannot yet close honestly

## Synthesis

- what this speaker tends to get right: escalation mechanism, coercive leverage structure, and the transition from symbolic military events to wider political-economic consequences
- what this speaker tends to miss or overstate: closure speed and the degree to which a strong mechanism can be treated as near-complete outcome proof before the window matures
- whether the speaker revisits errors: not visibly enough in the current shelf to count as a strong revision habit

## Boundary

- This profile does not yet score Pape's largest long-horizon claims about nuclear timing, global power transition, or postwar oil repricing beyond the present review window.
