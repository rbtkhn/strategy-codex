# America Bounded-Command Vs Burden-Sharing Bridge

WORK only; not Record.

Purpose: regulate the transition inside the America lane when the real uncertainty is still whether the object should be read command-first or settlement-first.

## Trigger

Open this bridge when America already owns the object and the remaining uncertainty is:

- whether the live problem is still mainly about command legitimacy, review, authorization, coercive-center bounding, and domestic carry
- or whether it is already mainly about allied burden-sharing, off-ramp architecture, sanctions sequencing, and successor-stable settlement

If lane ownership is still unclear, do not use this bridge yet.

## What This Bridge Chooses

This bridge chooses drafting posture, not lane ownership and not final clause language.

- **Bounded-command-first** -> use the state, war, and empire-side control surfaces to bound authority before mechanism design
- **Burden-sharing-settlement-first** -> use the peace and transaction-facing surfaces to test whether the mechanism can be carried without imperial drift

## Bounded-Command-First Rule

Use the bounded-command path when the live object is still primarily about:

- emergency authority, war powers, command legitimacy, or review
- whether coercion is bounded or drifting into self-justifying control
- whether America is accidentally confirming the adversary's leverage
- whether the smallest real control claim has been identified

## Burden-Sharing-Settlement-First Rule

Use the burden-sharing path when the live object is already primarily about:

- allied cost carrying and partner reassurance
- transit guarantees, sanctions relief sequencing, or protected channels
- successor-stable off-ramps and settlement architecture
- whether a mechanism can be inherited without narrating it as decline

Return to the America lane once the settlement path is clear enough to identify the governing carrier problem or transaction family.

## Return Path

After the bridge run:

1. return to [America helix](../america/helix.md) if the integrated line still needs restoration
2. return to [America state](../america/state/) if authority, review, or successor carry now governs the next move
3. return to [America transactions](../america/transactions/) if the object has truly crossed into clause or mechanism work

## Mistake This Bridge Prevents

This bridge exists to prevent two recurrent errors:

- treating command legitimacy and settlement architecture as if they were the same problem
- jumping into burden-sharing or off-ramp language before bounded authority has been made politically real

Inside the America lane, command legitimacy is not the same thing as settlement carry. The bridge exists to decide which one still governs.
