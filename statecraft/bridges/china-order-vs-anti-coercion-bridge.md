# China Order-Vs-Anti-Coercion Bridge

Purpose: regulate the transition inside the China lane when the real uncertainty is still whether the object should be read stabilization-first or leverage-architecture-first.

## Trigger

Open this bridge when China already owns the object and the remaining uncertainty is:

- whether the live problem is still mainly about energy stability, route continuity, anti-chaos posture, quiet diplomacy, and avoiding public ownership
- or whether it is already mainly about insurance, payments, yuan settlement, ports, finance, route alternatives, and reducing U.S. coercive reach

If lane ownership is still unclear, do not use this bridge yet.

## What This Bridge Chooses

This bridge chooses drafting posture, not lane ownership and not final clause language.

- **Order-preserving stabilization-first** -> use the state, peace, and quiet-stabilizer surfaces to keep the object anti-disorder before mechanism design
- **Anti-coercion leverage-architecture-first** -> use the empire, geo, and route-finance surfaces to build a control stack that weakens coercive dependence without forcing public ownership

## Order-Preserving Stabilization-First Rule

Use the stabilization path when the live object is still primarily about:

- energy stability, route continuity, or anti-chaos posture
- quiet diplomacy, public restraint, and avoiding visible ownership
- whether China can stabilize without becoming policeman
- whether order can be restored before coalition pressure hardens

## Anti-Coercion Leverage-Architecture-First Rule

Use the leverage-architecture path when the live object is already primarily about:

- insurance, payments, yuan settlement, or route alternatives
- ports, finance, infrastructure, and control architecture
- reducing U.S. coercive reach through quiet alternatives
- whether a mechanism can preserve optionality without public bloc ownership

## Return Path

After the bridge run:

1. return to [China helix](../china/helix.md) if the integrated line still needs restoration
2. return to [China state](../china/state/) if party-state implementation or quiet carrier reality now governs the next move
3. return to [China transactions](../china/transactions/) if the object has truly crossed into clause or mechanism work

## Mistake This Bridge Prevents

This bridge exists to prevent two recurrent errors:

- treating anti-disorder stabilization and anti-coercion architecture as if they were the same problem
- jumping into a finance, route, or infrastructure mechanism before deciding whether the lane still needs quiet stabilizer logic first

Inside the China lane, order preservation is not the same thing as leverage architecture. The bridge exists to decide which one still governs.
