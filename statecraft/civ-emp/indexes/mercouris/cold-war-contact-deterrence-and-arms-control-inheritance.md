# Cold War Contact, Deterrence, And Arms-Control Inheritance

## Purpose

Provide a `civ-emp` source scaffold for the Mercouris theme in which dangerous rivals still require contact channels, remembered escalation boundaries, and treaty-shaped deterrence literacy.

## Cybernetic Activation

Mercouris-side activation surface: [Cold War contact, deterrence, and arms-control inheritance](../../../../speakers/mercouris/themes/cold-war-contact-deterrence-and-arms-control-inheritance.md)

## Backward Historical Question

When do rival great powers preserve enough contact and treaty memory to manage danger, and what breaks when those procedural inheritances collapse?

## Source Basis

- Mercouris modern examples: Cold War contact, direct-strike threshold, INF / SS20 memory
- `civ-emp` retrieval contract for `state-memory` and `war`
- lane-local deterrence or arms-control objects where they exist
- legacy `civ-mem` only if a specific hotline or treaty lineage needs deeper provenance

## Arc Pattern

`rivalry -> preserved contact and bounded deterrence -> managed tension`

Failure pattern:

`rivalry -> contact collapse + threshold confusion + treaty amnesia -> brittle escalation`

## Continuity / Transformation / Current Carrier / Failure Mode

- Continuity: rival powers still need procedural channels
- Transformation: new strike and media environments make older restraint habits easier to discard
- Current carrier: hotlines, summit channels, deterrence doctrine, treaty memory
- Failure mode: policymakers inherit the conflict without inheriting the caution

## Statecraft Use

Use this scaffold when drafting or testing:

- hotline or summit reopening
- direct-strike threshold questions
- deterrence comparisons
- whether a past treaty world still meaningfully maps to the present one

## Counterweight

Cold War memory can itself mislead if treated as a complete model rather than as a warning about what procedural seriousness used to require.

## Transaction Hooks

- ask whether channels exist even amid hostility
- ask whether an analogy relies on a force or treaty system that no longer exists
- ask whether the policy is moving from proxy logic toward direct confrontation

## Citation Preference

1. Use lane-local deterrence and treaty objects when they already exist.
2. Use this scaffold when the question is still about contact-regime patterning.
3. Use legacy `civ-mem` only when a specific Cold War lineage needs deeper archival provenance.
