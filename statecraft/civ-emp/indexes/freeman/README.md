# Freeman-CIV-EMP Theme Companions

Purpose: hold the `civ-emp`-facing companion surfaces for the six Freeman historical themes activated in the `2025-01-01 -> present` Freeman arc.

These files move backward through real history from a present-day Freeman activation surface. They are not transcript commentary files. They are thin source scaffolds or pointer objects for statecraft retrieval.

## Theme Set

- [Settlement precedent and broken agreement](settlement-precedent-and-broken-agreement.md)
- [Thucydidean misfit and civilizational-state difference](thucydidean-misfit-and-civilizational-state-difference.md)
- [Roman collapse and strong-man return](roman-collapse-and-strong-man-return.md)
- [Bombing is not political success](bombing-is-not-political-success.md)
- [Monroe Doctrine and hemispheric prerogative](monroe-doctrine-and-hemispheric-prerogative.md)
- [Maritime hegemony transition and adaptation](maritime-hegemony-transition-and-adaptation.md)

## Use

Open this folder when:

- the Freeman-side theme is already known
- the task now needs backward historical scaffolding
- a theme needs a compact `civ-emp` retrieval surface before lane-local translation

## Boundary

- These files do not replace lane-local `civilization/`, `empire/`, `state/`, `helix.md`, or `transactions/` surfaces.
- These files do not make Freeman the upstream authority for civilizational history.
- When an existing `civ-emp` object already carries the pattern, point to it rather than duplicating it.
