## Reading posture

Read this note as a first-pass orientation discipline.

Its job is not to replace source objects. Its job is to stop three common failures:

1. reading a civilizational object as though it were only about power
2. reading a truth-order as though it were only rhetoric
3. reading temporal memory or appetite as though it were only atmosphere

Short rule:

> First ask what kind of power this is, then what kind of truth legitimates it, then what kind of time carries or distorts it.

This checklist inherits the repo's five-era background architecture:

- `Ancient` -> `476`
- `Medieval` -> `1453`
- `Colonial` -> `1815`
- `Industrial` -> `1945`
- `Cybernetic` -> `1945-present`

Use that architecture as orientation, not as a mandatory first-router. When a post-1945 object is clearly about deterrence, computation, identity rails, platform authority, signal management, or systems governance, `Cybernetic` is usually the better overlay than `Digital`.

## When to use it

Use this checklist when:

- the object keeps expanding beyond one lane's normal grammar
- legitimacy, sacred order, expertise, or ideology seem load-bearing
- memory, humiliation, restoration, revenge, appetite, or novelty drive seem load-bearing
- the operator needs a cleaner higher-order summary before choosing a lane or family

Do not use it when:

- the problem is already clearly tactical and local
- the object is already mature enough for clause stress-testing
- the task is simply to reopen a known lane object and extend it one step

## Entry sequence

Run the checklist in this order:

1. **Power pass**
2. **Truth pass**
3. **Time pass**
4. **Integration pass**
5. **Return path**

If the object fails early, stop and route before pretending the whole triad is necessary.

## 1. Power pass

Ask first:

- what civilizational inheritance is being amplified here
- what imperial or state instrument is carrying it
- whether the instrument still protects the inheritance or is now degrading it

Name the power object in one line:

- inheritance under amplification
- order under strain
- empire outrunning civilization
- civilization lacking instrument

If you cannot name the power object clearly, return first to:

- [CIV-EMP Source Retrieval Matrix](indexes/source-retrieval-matrix.md)
- the governing lane helix
- or the [Helix-First front door](migration/orientation-helix-front-door.md)

## 2. Truth pass

Ask next:

- what truth-order authorizes this actor's claim
- whether the claim is carried by sacred grammar, historical destiny, expertise, procedure, constitutional creed, revolutionary doctrine, or some hybrid
- whether that truth-order restrains power or merely rationalizes it

Name the truth object in one line:

- sacred legitimacy under pressure
- technocratic legitimacy without moral depth
- procedural legitimacy losing cultural belief
- civilizational truth-order resisting imported categories

Signs this pass matters:

- the dispute is not only about interests but about what can be said, justified, or recognized
- the actor cannot be understood without its sacred, ideological, or expert grammar
- outside observers keep misreading the actor as cynical when it is partly doctrinal, or as doctrinal when it is mostly procedural

Default router for this pass:

- if the live question is legitimacy, sacred order, covenant, providence, Orthodoxy, juridical universality, or constitutional creed with civilizational depth, open the [Sacred Grammar Library](sacred-grammar/README.md) first
- use the shelf's evidence spine before forming statecraft claims
- only then return downstream to lane-local `god`, `state-memory`, `lit`, helix, or transaction surfaces

If this pass adds nothing real, note that and continue. Not every object requires a heavy truth-order read.

## 3. Time pass

Ask next:

- what memory the actor is preserving, replaying, or defending
- what desire is driving acceleration, appetite, restoration, escalation, prestige hunger, or novelty seeking
- whether the actor is continuity-seeking, restoration-seeking, or exit-seeking

Name the time object in one line:

- memory preserving continuity
- desire outrunning inheritance
- restoration drive under humiliation memory
- novelty drive severed from continuity

This is where the object often sharpens.

If the power read is clear but the behavior still feels excessive, theatrical, or compulsive, the time pass is usually where the missing mechanism sits.

## 4. Integration pass

Now compress the object into one structured sentence:

> This is a `power` problem carried by `civilization / empire`, authorized by a `truth` order rooted in `faith / science`, and destabilized or sustained by a `time` dynamic of `memory / desire`.

Then answer four integration questions:

1. Which of the three layers is actually governing the object?
2. Which layer is most misread by outsiders?
3. Which layer is most likely to produce the object's failure mode?
4. Which layer must a later lane translation preserve to avoid flattening the case?

If all three layers seem equal, you are probably still being too abstract. Pick the governing layer.

## 5. Return path

After the triad pass, choose the right next surface.

### If power is clearly governing
Return to:

- [CIV-EMP Source Retrieval Matrix](indexes/source-retrieval-matrix.md)
- the relevant lane helix
- relevant lane `civilization/`, `empire/`, or `state/` surfaces

### If truth is clearly governing
Return to:

- [Sacred Grammar Library](sacred-grammar/README.md) first
- then lane-local `god`, `state-memory`, `lit`, or adjacent civilization objects where present
- relevant speaker-state retrieval adapters if the object arrived through a speaker arc
- cross-lane family notes only after the truth-order has been named clearly

### If time is clearly governing
Return to:

- `state-memory`
- continuity-sensitive family notes
- [continuity and self-misread architecture](migration/canonical-family-continuity-misread-architecture.md)

### If the object is now ready for drafting
Move downstream to:

- [Helix-First Operator-Task Router](migration/orientation-operator-task-router.md)
- then [Helix-First Clause-Review Checklist](migration/orientation-clause-review-checklist.md)

## Quick version

Use this six-line pass when time is short:

1. What inheritance is being amplified?
2. What instrument is carrying it?
3. What truth-order authorizes it?
4. What memory sustains it?
5. What desire distorts or accelerates it?
6. Which layer actually governs the object?

## Failure signs

The retrieval is still weak if any of these are true:

- you can describe leverage but not legitimacy
- you can describe legitimacy but not the inheritance it protects
- you can describe continuity but not the appetite or restoration drive bending it
- you can name all three layers but cannot say which one governs
- the final summary sounds profound but does not improve routing

## Output expectation

A successful use of this checklist should produce:

- one sentence naming the governing power object
- one sentence naming the governing truth-order
- one sentence naming the governing time dynamic
- one judgment about which layer most needs protection in later drafting
- one clear return path into lane, family, or clause-review work

## Bottom line

This checklist exists so `civ-emp` does not become merely a power-memory machine.

It forces one extra discipline:

- power must be read with its truth-order
- truth must be read with its temporal carrier
- time must be read as politically real

That is the operational meaning of `power / truth / time` inside CIV-EMP retrieval.
