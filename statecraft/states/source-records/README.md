# Source Records

This surface is non-authoritative and subject to revision.

This folder holds structured CIV-STATE source records.

Each record gives one bibliography source door a stable machine-readable identity before any excerpt or full text is stored.

Core rule:

- one `source_id`
- one canonical witness
- one canonical working translation when translation is needed
- alternate translations noted, not treated as coequal defaults

Use these records to track:

- source identity
- civilization, era, and branch placement
- witness and translation provenance
- rights and storage class
- excerpt availability
- full-text availability
- sidecar linkage

This folder should remain light and structured. It is not the place for long quotations or bulk payloads.
