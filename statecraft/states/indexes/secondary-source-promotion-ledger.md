# Secondary-Source Promotion Ledger


Use this ledger when a recurring secondary explanation is no longer best housed only in local era shelves.

## Status Key

- `local` = explanation should remain in the era shelf
- `promotable` = explanation is recurring enough to justify upstream doctrine support
- `promoted` = explanation has already been absorbed into glossary, retrieval doctrine, pattern-library, or chapter counterweight language
