# Interpretive Difficulty Map


Use this map when the operator needs to know which shelves generate the hardest chronology, translation, provenance, nostalgia, flattening, or teleology problems. This is not a prestige list. It is a comparative guide to where the layered CIV-STATE stack most needs secondary support.

## Chronology Trouble

- **Rome ancient** is a strong chronology shelf because republic-to-principate transition is easy to oversimplify.
- **Persia medieval** is a strong chronology shelf because imperial, Islamic, and Persianate transformations are easy to compress too smoothly.

- **Persia ancient** is also high-friction because sacred and imperial terms carry dense civilizational load.
