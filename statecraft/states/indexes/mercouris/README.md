# Mercouris-CIV-STATE Theme Companions

Purpose: hold the `civ-state`-facing companion surfaces for the six Mercouris historical themes activated in the `2025-01-01 -> present` Mercouris arc.

These files move backward through real history from a present-day Mercouris activation surface. They are not transcript commentary files. They are thin source scaffolds or pointer objects for statecraft retrieval.

## Theme Set

- [Cold War contact, deterrence, and arms-control inheritance](cold-war-contact-deterrence-and-arms-control-inheritance.md)
- [Broken settlement, Minsk, and Istanbul sequencing](broken-settlement-minsk-and-istanbul-sequencing.md)
- [Yalta myth and European exclusion anxiety](yalta-myth-and-european-exclusion-anxiety.md)
- [Habsburg residue and European legitimacy fracture](habsburg-residue-and-european-legitimacy-fracture.md)
- [Geostrategic defeat and unipolar exhaustion](geostrategic-defeat-and-unipolar-exhaustion.md)
- [Helsinki process and post-hegemonic security architecture](helsinki-process-and-post-hegemonic-security-architecture.md)

## Use

Open this folder when:

- the Mercouris-side theme is already known
- the task now needs backward historical scaffolding
- a theme needs a compact `civ-state` retrieval surface before lane-local translation

## Boundary

- These files do not replace lane-local `civilization/`, `empire/`, `state/`, `helix.md`, or `transactions/` surfaces.
- These files do not make Mercouris the upstream authority for civilizational history.
- When an existing `civ-state` object already carries the pattern, point to it rather than duplicating it.
