# Historical Example Retrieval Matrix

Purpose: make historical-example use operational during statecraft drafting by turning the citation policy into a repeatable retrieval table.

Use this matrix together with:

- [Anchored Historical Citation Policy](../../bridges/anchored-historical-citation-policy.md)
- [CIV-STATE Source Retrieval Matrix](source-retrieval-matrix.md)

Governing law:

`historical examples may support doctrine only when they are retrieval-anchored, mechanism-matched, and falsifier-aware`

Hard gate:

`no anchored path -> no doctrinal historical claim`

## How To Use This Matrix

For any example you want to cite:

1. identify the mechanism family
2. confirm the anchor path
3. note the citation tier
4. use only the allowed function
5. carry the misuse warning with the citation rather than after it

If no row fits, either:

- demote the example to `suggestive analogy`, or
- create a stronger source object first

## Pairing Guidance

The matrix is often strongest when one row from a continuity family is paired with one row from an architecture family.

Useful pairings:

- `Mossadegh / 1953` + `JCPOA`
- `Qajar concession politics` + `end-of-Cold-War verbal assurance / treaty-form dispute`
- `Iran-Iraq War` + `Austrian State Treaty`
- `Hormuz restraint` + `settlement-room architecture`

The point of pairing is to stop one example from doing too much work.

## Demotion Rule

If an example is:

- famous but unanchored
- anchored to the wrong mechanism
- rhetorically useful but not falsifier-aware

then mark it:

`suggestive analogy`

and do not let it carry doctrine.
