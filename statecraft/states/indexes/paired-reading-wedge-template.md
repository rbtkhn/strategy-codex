# Paired Reading Wedge Template


Use this template when an operator needs a compact layered reading wedge rather than a full shelf descent.

## Two Primary Anchors

1. Primary text one that carries the governing legitimacy, legal, sacred, or institutional language.
2. Primary text two that carries the transformation, rupture, or present-carrier hinge.

## One Clarifier

- One secondary source used for `chronology`, `provenance`, `translation`, or `institutional_context`.

## One Counterweight

- One secondary source used for `counterweight` or `misreading_correction`.

## Use Rule

Use a wedge when the operator needs a fast, bounded layered read that still preserves primary authority. Do not let the clarifier or counterweight become the center of gravity.

## Return Path

- Return to the matching primary shelf if the wedge surfaced more source-level difficulty.
- Return to the matching secondary shelf if the wedge exposed a larger interpretive problem.
- Move upward into the matching chapter surface once the wedge has clarified the present statecraft question.
