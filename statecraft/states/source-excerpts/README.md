# Source Excerpts

This surface is non-authoritative and subject to revision.

This folder holds bounded excerpt collections tied to CIV-STATE `source_id` records.

Excerpt law:

- short
- rights-safe
- edition-aware
- source-linked
- load-bearing

Default bias:

- preserve one legal / doctrinal / legitimacy-bearing passage when available
- preserve one narrative / chronicle / literary carrier when available

Excerpts are not substitutes for source records or full-text sidecars. They are the fast-reopen layer between them.
