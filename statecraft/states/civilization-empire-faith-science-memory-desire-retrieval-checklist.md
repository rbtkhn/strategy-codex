# Civilization, Empire, Faith, Science, Memory, Desire Retrieval Checklist

WORK only; not Record.

Status: Active checklist
Surface: `civ-state`
Purpose: turn the six-part CIV-STATE doctrine into a bounded retrieval discipline before lane translation or clause drafting
Last updated: 2026-05-26

## Purpose

Use this checklist when a live object feels larger than route geometry, leverage, continuity, or one lane's grammar alone and you need a disciplined higher-order read before descending into:

- lane `civilization/` and `empire/` surfaces
- lane `state/` or `helix.md`
- `state-memory`, `god`, `lit`, or adjacent arc-lenses
- transaction routing or clause drafting

This is a retrieval instrument, not a drafting instrument.

## Reading posture

Read this note as a first-pass orientation discipline.

Its job is not to replace source objects. Its job is to stop four common failures:

1. reading inheritance as though it were only instrument
2. reading truth-order as though faith and science were interchangeable
3. reading memory as atmosphere rather than continuity-bearing force
4. reading appetite, novelty, prestige, or resentment as noise rather than as governing desire

Short rule:

> Ask first what inheritance is at stake, then what instrument carries it, then what faith-order and science-order authorize it, then what memory sustains it, and finally what desire is bending it.

When periodization matters, use [Era Law](framework/era-law.md) as background architecture rather than as a mandatory first-router.

`Cybernetic` is the right overlay when the object is governed by deterrence, sanctions, networks, platform authority, system administration, or other post-1991 command forms.

## When to use it

Use this checklist when:

- the object keeps expanding beyond one lane's normal grammar
- legitimacy, sacred order, expertise, or procedure are load-bearing in different ways
- continuity, humiliation, restoration, prestige, or acceleration are load-bearing
- the operator needs a cleaner higher-order summary before choosing a lane or family

Do not use it when:

- the problem is already clearly tactical and local
- the object is already mature enough for clause stress-testing
- the task is simply to reopen a known lane object and extend it one step

## Entry sequence

Run the checklist in this order:

1. **Civilization pass**
2. **Empire pass**
3. **Faith pass**
4. **Science pass**
5. **Memory pass**
6. **Desire pass**
7. **Integration pass**
8. **Return path**

If the object fails early, stop and route before pretending all six are necessary.

## 1. Civilization pass

Ask first:

- what civilizational inheritance is at stake
- what legitimacy substrate, sacred grammar, or continuity-bearing pattern is being defended
- whether the object is really about inherited order rather than immediate instrument

Name the civilization object in one line:

- inheritance under pressure
- legitimacy substrate under strain
- continuity-bearing order defending itself
- civilization lacking a trustworthy carrier

Default router:

- if the live question is legitimacy, truth-order, covenant, ritual order, Orthodoxy, providence, juridical universality, or what makes authority feel rightful, open the [Sacred grammar (volume-local)](reader-guide.md#sacred-grammar-volume-local) first

## 2. Empire pass

Ask next:

- what outward instrument is carrying the object
- whether the instrument is coercive, financial, legal, infrastructural, alliance-based, cybernetic, or procedural
- whether the instrument still protects the inheritance or is now degrading it

Name the empire object in one line:

- inheritance under amplification
- order under instrument stress
- empire outrunning civilization
- instrument without durable legitimacy

## 3. Faith pass

Ask next:

- what sacred, moral, symbolic, covenantal, or civil-religious order authorizes the actor's claim
- what the actor treats as forbidden, profane, or morally non-negotiable
- whether faith restrains power or merely sacralizes it

Name the faith object in one line:

- sacred legitimacy under pressure
- covenantal authority defending continuity
- moral boundary against humiliation
- instrumentalized faith masking domination

## 4. Science pass

Ask next:

- what technical, procedural, expert, managerial, or cybernetic order authorizes the actor's claim
- whether the actor trusts verification, expertise, bureaucracy, systems control, legality, or some hybrid
- whether science restrains power or merely rationalizes it

Name the science object in one line:

- technocratic legitimacy without moral depth
- procedural authority under civilizational strain
- cybernetic competence carrying the settlement
- expert order rationalizing overreach

## 5. Memory pass

Ask next:

- what memory the actor is preserving, replaying, or defending
- what humiliation, sacrifice, restoration, or inherited wound is load-bearing
- whether the actor is continuity-seeking, restoration-seeking, or succession-anxious

Name the memory object in one line:

- continuity defended by inherited wound
- restoration drive under humiliation memory
- succession fear preserving a hard line
- memory preserving continuity under pressure

## 6. Desire pass

Ask next:

- what appetite, prestige hunger, novelty drive, resentment, or compensatory ambition is active
- whether desire is accelerating the object beyond its continuity-bearing limits
- whether the actor is defending inheritance or trying to escape inherited limits

Name the desire object in one line:

- prestige appetite outrunning inheritance
- novelty drive severed from continuity
- resentment accelerating overreach
- restoration desire destabilizing settlement

## 7. Integration pass

Now compress the object into one structured sentence:

> This is a `civilization / empire / faith / science / memory / desire` problem in which `X` governs, `Y` carries, and `Z` is most likely to distort the case if later drafting flattens it.

Then answer five integration questions:

1. Which of the six actually governs the object?
2. Which paired term carries or contests it most directly?
3. Which layer is most misread by outsiders?
4. Which layer is most likely to produce the failure mode?
5. Which layer must later lane translation preserve most carefully?

If all six seem equal, you are still being too abstract. Pick the governing layer and the governing pair.

## 8. Return path

After the six-part pass, choose the right next surface.

### If civilization is clearly governing

Return to:

- [Sacred grammar (volume-local)](reader-guide.md#sacred-grammar-volume-local)
- lane civilization surfaces
- lane `state-memory`

### If empire is clearly governing

Return to:

- [CIV-STATE Source Retrieval Matrix](indexes/source-retrieval-matrix.md)
- relevant lane `empire/`, `state/`, or `helix` surfaces
- transaction router when instrument form is already visible

### If faith is clearly governing

Return to:

- [Sacred grammar (volume-local)](reader-guide.md#sacred-grammar-volume-local) first
- then lane-local `god`, `lit`, or adjacent legitimacy objects

### If science is clearly governing

Return to:

- procedural, technical, governance, verification, or implementation surfaces
- current carriers and mechanism design

### If memory is clearly governing

Return to:

- lane `state-memory`
- continuity-sensitive family notes
- rupture-tracking and successor-order surfaces

### If desire is clearly governing

Return to:

- mutation and escalation sheets
- prestige, overreach, novelty, or appetite diagnostics
- family notes where appetite distorts the inherited object

## Quick version

Use this seven-line pass when time is short:

1. What civilizational inheritance is at stake?
2. What empire instrument is carrying it?
3. What faith-order authorizes it?
4. What science-order authorizes it?
5. What memory sustains it?
6. What desire distorts or accelerates it?
7. Which layer actually governs the object?

## Failure signs

The retrieval is still weak if any of these are true:

- you can describe instrument but not inheritance
- you can name sacred legitimacy but not procedural authority
- you can name procedure but not moral limit
- you can describe memory but not appetite
- you can name all six layers but cannot say which one governs
- the final summary sounds broad but does not improve routing

## Bottom line

This checklist exists so CIV-STATE does not collapse inheritance, instrument, truth-order, continuity, and appetite into one elegant but unusable summary.

Its discipline is simple:

- civilization must be distinguished from empire
- faith must be distinguished from science
- memory must be distinguished from desire
- the governing layer must be named before drafting begins
