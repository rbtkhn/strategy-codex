## Scoring Legend

- `5`: strong pass; no meaningful revision needed
- `4`: pass; minor polish may still help
- `3`: conditional; usable, but a specific fix is required before template promotion
- `2`: fail; substantial weakness blocks promotion
- `1`: fail; the object or pair does not currently perform the required function

Pass thresholds:

- Hard pass: no audit category below `4`, and the pair-level public orientation average is at least `4.2`
- Conditional pass: one or two categories may score `3` only if no pair-level orientation function falls below `4`
- Fail: any category scores `1-2`, or any pair-level orientation function falls below `4`
