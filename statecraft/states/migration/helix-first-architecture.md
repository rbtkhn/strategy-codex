# Helix-First Architecture

This note defines the Phase 2 architecture shift without erasing the Phase 1 scaffold that made the first-wave corpus possible.

## Governing Claim

Phase 1 proved that the statecraft corpus needed both `Civilization` and `Empire` in order to avoid a rich civilization side paired with a skeletal empire appendix. That scaffold remains valid as migration history and balance discipline.

Phase 2 changes the authored ontology. `Civilization` and `Empire` are no longer treated as the final top-level units. They now function as supporting **strands** beneath a primary **lane helix object** that integrates authorization, protection, deformation, and restoration into one governable reading.

## Phase Distinction

- **Phase 1 = strand scaffold**
  `state-memory`, `geo`, `war`, `peace`, and `empire-instrument` remain the evidence-bearing first-wave objects. They preserve provenance, counterweight, transaction hooks, and canonical-family service.
- **Phase 2 = helix-authored layer**
  The lane helix object becomes the primary interpretive surface. It reads the strand set together and routes back down into the appropriate strand when the draft needs narrower detail.

The strand layer is therefore preserved, not displaced. Helix-first cutover does not delete first-wave objects, erase provenance, or treat the strand set as redundant.

## Division Of Labor

- **Lane README**
  Entry and routing surface. It tells a reader where to start and where to go next.
- **Helix**
  Primary authored interpretation. It integrates civilization authorization, imperial protection, imperial deformation, and regulation / restoration logic.
- **Strand objects**
  Evidence-bearing source surfaces. They hold the detailed first-wave answer-capacity, provenance, counterweight, and transaction hooks.
- **Migration notes**
  Control-plane truth. They describe what has been built, how it is verified, and what remains staged.

## Verification Implication

Helix-first verification asks a different question than Phase 1C lane verification.

Phase 1C asked:

- does the lane have a mature first-wave set?

Phase 2 asks:

- is the helix now the preferred top-level interpretation?
- does it route cleanly to all strands?
- do the strands route back to it?
- is canonical-family service clearer through helix-plus-strand interaction than through strand reading alone?

Phase 2 verification therefore sits **above** the earlier lane notes. It does not invalidate them.
