## Helix-Primary Verification Standard

For the Iran transfer case, helix-primary verification requires all of the following:

1. the helix is now the preferred top-level interpretive surface for the lane
2. the lane README routes to the helix first and to strand objects second
3. the helix routes clearly to all five first-wave strand objects
4. all five first-wave strand objects route back to the helix
5. canonical-family service is legible through helix-plus-strand interaction
6. the lane no longer depends on the two-volume split as its governing interpretation, even though the strand split remains valid as scaffold history
7. the strand layer still preserves provenance, counterweight, and transaction hooks
8. the control plane reflects Iran as a bounded transfer case from the earlier proving set rather than as an unexamined all-lanes default

## Verdict

- Helix-primary lane: `yes`
- Phase 2 proving-set status: `complete across the four active lanes`

Iran now works as a **helix-primary lane**.

That claim is justified because the lane no longer needs the two-volume split to provide its top-level interpretation. The split still exists as a supporting strand scaffold, but a reader can now enter at the helix, understand the dignity / sovereignty / leverage problem as one integrated object, and then descend into the correct strand when the question narrows.

Iran is also the final transfer case in the first helix-first proving set. That matters because it closes the earlier asymmetry in which America, Russia, and China had already moved upward into Phase 2 while Iran remained only a mature Phase 1C lane.

## Recommended Interpretation

Use Iran to show that the helix-first model is not limited to one style of statecraft grammar:

- **America** proves the architecture can work
- **Russia** proves the architecture is not America-specific
- **China** proves it also transfers to quiet-leverage and anti-disorder logic
- **Iran** proves it can also carry dignity, sanctions, chokepoint, and anti-humiliation statecraft without collapsing back into strand-first reading

With Iran complete, the next verification question is no longer lane transfer. It is whether the four-lane set now coheres as one helix-first corpus layer above the shared strand scaffold.
