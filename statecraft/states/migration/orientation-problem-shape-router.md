
# Helix-First Problem-Shape Router

## Purpose

Use this note as the second corpus-level orientation / retrieval surface for the helix-first statecraft layer.

The first orientation note, [orientation-helix-front-door.md](orientation-helix-front-door.md), helps when you are deciding whether to start with a lane or a family. This note answers a different question:

- if the object already feels cross-lane, what **kind** of cross-lane problem is it?

This note groups the existing synthesis layer by entry problem rather than by canonical-family title.

## Reading Posture

Read this as a routing aid, not as a substitute for the synthesis notes themselves.

Its job is to reduce entry friction once the family layer exists. It does that by clustering the six current synthesis notes into a smaller number of recurring problem-shapes:

- settlement-room problems
- escalation-governance problems
- continuity and self-misread problems

If the shape is clear, use this note to pick the right synthesis surface quickly. If the shape is still unclear, fall back to [orientation-helix-front-door.md](orientation-helix-front-door.md).

## Problem-Shape Map

### 1. Settlement-Room Problems

Use this cluster when the live question is about whether a peace, room, review mechanism, or direct great-power bargain is actually inhabitable.

Typical signals:

- the text of settlement sounds better than the architecture behind it
- recognition and actual access may be diverging
- the room may include an actor symbolically while still bypassing it materially
- review, guarantor, corridor, or relief carriers are the real hinge

Start with:

- [Canonical-family synthesis: real settlement](canonical-family-settlement-real.md)
  Use when the question is whether a settlement is real or theatrical in its ownership, review, and successor carry.
- [Canonical-family synthesis: exclusion and direct settlement](canonical-family-exclusion-settlement.md)
  Use when the question is whether the room, corridor map, or access design still reproduces remembered exclusion.

Shared hinge:

- settlement becomes real only when recognition, access, and carry point in the same direction

Meta-surface:

- [Meta-synthesis: settlement-room architecture](canonical-family-settlement-room-architecture.md)
  Use when the real question is whether peace ownership and room inhabitation have become one larger architecture problem rather than two adjacent ones.

### 2. Escalation-Governance Problems

Use this cluster when the live question is not merely whether force exists, but whether force is still governable.

Typical signals:

- coercion keeps going, but no one can say what counts as enough
- proxy or indirect pressure looks politically cheaper than direct settlement
- contact channels, review logic, or reciprocal procedures may be thinner than the operators admit
- the system still knows how to intensify but no longer knows how to stop credibly

Start with:

- [Canonical-family synthesis: coercion conversion](canonical-family-coercion-conversion.md)
  Use when the question is why pressure fails to convert into a bounded political result.
- [Canonical-family synthesis: broken contact regimes and arms-control inheritances](canonical-family-broken-contact-regimes.md)
  Use when the question is whether escalation risk is being underpriced because a thinner contact regime is being mistaken for a thicker inherited one.

Shared hinge:

- escalation becomes more dangerous when the instruments remain more available than the stop conditions

Meta-surface:

- [Meta-synthesis: escalation governance](canonical-family-escalation-governance.md)
  Use when the real question is whether bounded political conversion and living contact procedure have become one larger governance problem rather than two adjacent ones.

### 3. Continuity And Self-Misread Problems

Use this cluster when the live question is whether a state's current behavior is being overdetermined by older memory, inherited mission, or a mistaken reading of its own persistence.

Typical signals:

- an older humiliation, sovereignty, or exposure memory still governs what counts as prudent
- current leverage may be mistaken for durable strategic health
- the state may be reading inherited tools or stories as proof that its deeper order still holds
- the real issue is continuity-filtering rather than immediate settlement or escalation design

Start with:

- [Canonical-family synthesis: older strategic memories](canonical-family-older-strategic-memories.md)
  Use when the question is whether an older continuity or humiliation memory is still acting as a live plausibility filter.
- [Canonical-family synthesis: pressured hegemon misreading power](canonical-family-pressured-hegemon.md)
  Use when the question is whether a state is mistaking still-available instruments or stories for proof that its deeper durability remains intact.

Shared hinge:

- present action becomes unstable when inherited memory and inherited self-image stop being checked against actual carrying capacity

Meta-surface:

- [Meta-synthesis: continuity and self-misread architecture](canonical-family-continuity-misread-architecture.md)
  Use when the real question is whether inherited plausibility filters and present self-reading have become one larger review architecture problem rather than two adjacent issues.

## Quick Router

If the object is still blurry, use this shorter sequence:

1. **Does the problem sound like peace without room?**
   Go to the settlement-room cluster.

2. **Does the problem sound like force without a believable stop condition?**
   Go to the escalation-governance cluster.

3. **Does the problem sound like memory or inherited power image distorting present judgment?**
   Go to the continuity and self-misread cluster.

4. **If none of those fit cleanly,** return to [orientation-helix-front-door.md](orientation-helix-front-door.md) and choose by lane first.
