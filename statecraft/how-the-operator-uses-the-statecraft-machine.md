This is not a general theory of the system. It is a grounded note about actual observed usage across the recent statecraft buildout.

## Core Claim

The operator has been using `statecraft/` less like a notebook and more like a governed comparative cognition machine.

The live pattern is not:

- collect material
- summarize it
- store an opinion

It is closer to:

- route a live object into the right constitutional layer
- identify the lane-native ambiguity
- test whether the lane has real membrane thickness
- convert continuity and leverage into a reusable instrument
- extract reusable law when a pattern survives transfer

That is a different class of workflow from traditional strategy or historiography.

### 3. Membrane Testing

The operator repeatedly asks whether a lane is proving itself through its own doctrine and proof inventory or only through borrowed shared objects.

This is not ordinary comparison. It is a question about whether an analytic surface is computationally autonomous.

### 4. Falsifiable Pattern Transfer

The operator does not treat a successful pattern as proven after one case. The recurring move is:

- transfer the pattern
- adapt it
- then try to break it on a different lane

Concrete examples:

- [recursive-learning-three-lane-audit.md](recursive-learning-three-lane-audit.md)

- Russia became the falsification target rather than a mere expansion target

That is a meta-strategic use of the machine, not ordinary documentation.
