# Statecraft Multi-Lens Bench Pressure Test - 2026-05

Purpose: pressure-test the first-wave `statecraft-multi-lens` preset bench on a small set of live objects so the skill can start refining itself from use rather than only from design.

This note does **not** test every lens. It tests whether the current preset bench is already separating real question families cleanly enough to be useful.

## Method

Three live objects were chosen because they stress different parts of the bench:

1. `Iran-war to deal transition`
2. `coercive plan collapse versus actual bargaining room`
3. `Hormuz escalation as imperial and order consequence`

For each object, the test asks:

- which preset fits best
- which preset is a viable runner-up
- which preset overlaps or underperforms
- what this implies for future preset refinement

## Object 1

### Iran-war to deal transition

Question:

`is the object still trapped, has the recognition floor hardened, and is architecture already appearing anyway?`

Best fit:

- **Pape / Marandi / Parsi**

Why it wins:

- the object is explicitly stage-of-reality contested
- trap, threshold, and architecture all do real work
- no lighter preset carries the full sequence without hiding one decisive layer

Runner-up:

- **Marandi / Parsi**

Why it still helps:

- if the operator already accepts the trap as ambient background, the dual lens remains a clean, fast compression

Weakened preset:

- **Pape / Parsi**

Why it weakens:

- it sees motion and design, but misses the anti-humiliation floor that repeatedly decides whether design can even become real

Refinement signal:

- `Pape / Parsi` is not dead, but it is currently a **secondary shortcut preset**, not a first-open preset for the Iran-war settlement object

## Object 2

### Coercive plan collapse versus actual bargaining room

Question:

`why can the war not work, and what real room remains once coercive fantasy collapses?`

Best fit:

- **Macgregor / Davis**

Why it wins:

- the object is not primarily about recognition or order transition
- it is about force-feasibility failure and practical-room realism
- `Davis` adds a genuinely different second function rather than decorative agreement

Runner-up:

- **Macgregor / Pape / Ritter**

Why it still helps:

- when the object is not only unwinnable but also visibly drifting toward a more dangerous threshold, the third-function warning becomes real

Weakened preset:

- **Macgregor / Pape / Ritter** on ordinary coercive-failure objects

Why it weakens:

- `Ritter` is valuable when the danger threshold itself is active
- on more ordinary `this plan cannot work` objects, the preset can over-warn and become too hot relative to `Macgregor / Davis`

Refinement signal:

- **Macgregor / Davis** is unexpectedly strong and may become one of the bench's most reusable non-canonical dual presets
- **Macgregor / Pape / Ritter** should stay, but it currently looks like a **specialty escalation-warning triad**, not a general coercive-failure preset

## Object 3

### Hormuz escalation as imperial and order consequence

Question:

`is this mainly a systemic order-transition object, or mainly an imperial-decay / institutional-failure object?`

Best fit:

- **Freeman / Sachs / Wilkerson**

Why it wins:

- this object is strongest when the question is why escalation worsens leverage, why the project still carries, and what institutional decay it reveals
- `Wilkerson` adds a real third function: imperial-command and competence collapse

Runner-up:

- **Diesen / Mearsheimer / Parsi**

Why it still helps:

- if the object shifts from diagnosis of decline toward `what wider order is forming and what architecture might become possible`, this triad becomes more useful

Weakened preset:

- **Freeman / Sachs**

Why it weakens:

- the dual lens still reads the backfire and the carrier
- but on Hormuz-as-system-consequence, `Wilkerson` adds enough real institutional-decay signal that the triad is noticeably stronger

Refinement signal:

- **Freeman / Sachs / Wilkerson** is an unexpectedly strong altitude preset
- **Diesen / Mearsheimer / Parsi** feels less like a diagnosis preset and more like a `system-shift plus structure plus architecture` preset for later-stage objects

## Bench Findings

### Strong presets

- **Pape / Marandi / Parsi**
  - still the strongest all-purpose stage-of-reality preset
- **Macgregor / Davis**
  - stronger and cleaner than expected
- **Freeman / Sachs / Wilkerson**
  - the clearest current `imperial decay under live escalation` triad

### Useful but narrower presets

- **Marandi / Parsi**
  - best when trap logic is already accepted and the real question is threshold versus design
- **Macgregor / Pape / Ritter**
  - best when coercive failure and danger-threshold warning are both live
- **Diesen / Mearsheimer / Parsi**
  - best when order transition, structural bargaining space, and architecture are all truly in play

### Presets that currently overlap

- **Pape / Parsi** overlaps upward with the canonical tri-lens on Iran-war settlement objects
- **Freeman / Sachs** overlaps upward with **Freeman / Sachs / Wilkerson** on imperial-decay objects

These are not yet retirement cases, but they are real overlap signals.

## Early Review Verdicts

### Presets that look stronger than expected

- **Macgregor / Davis**
- **Freeman / Sachs / Wilkerson**

### Presets that look weaker than expected

- **Pape / Parsi** as a first-open Iran-war settlement preset

### Presets not yet falsified, but still specialty tools

- **Macgregor / Pape / Ritter**
- **Diesen / Mearsheimer / Parsi**
- **Davis / Mercouris / Marandi**

`Davis / Mercouris / Marandi` was not the best fit for any of the three chosen objects, which means it is still conceptually plausible but operationally under-tested. It needs a legitimacy-fracture object that is more explicitly about what remains negotiable beneath a broken imperial or settlement carrier.

## What This Changes

The current bench is not bloated yet, but it is starting to separate into three classes:

- `core reusable presets`
- `specialty presets`
- `overlap-watch presets`

Current classing:

- **core reusable**
  - `Pape / Marandi / Parsi`
  - `Macgregor / Davis`
  - `Freeman / Sachs / Wilkerson`
- **specialty**
  - `Marandi / Parsi`
  - `Macgregor / Pape / Ritter`
  - `Diesen / Mearsheimer / Parsi`
  - `Davis / Mercouris / Marandi`
- **overlap-watch**
  - `Pape / Parsi`
  - `Freeman / Sachs`

That does not yet force demotion or retirement.

It does mean the next pressure tests should target:

- one object designed specifically for `Diesen / Mearsheimer / Parsi`
- one object designed specifically for `Davis / Mercouris / Marandi`
- one object designed specifically to see whether `Pape / Parsi` still earns a first-wave slot

## Bottom Line

The bench is already good enough to use, but not yet mature enough to trust symmetrically.

The strongest lesson from these three runs is:

`preset breadth is still paying for itself, but only because a few presets are already emerging as clearer first-opens than the rest`

That means the recursive refinement law is now live.
