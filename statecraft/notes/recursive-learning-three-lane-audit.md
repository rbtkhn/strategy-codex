# Recursive-Learning Three-Lane Audit


Purpose: compare the first three statecraft lanes that have received the top-three recursive-learning pattern pass so the pattern can be judged as adaptive reuse rather than decorative repetition.

## Question

Has the same pattern family now generalized across three genuinely different lane logics?

The tested pattern family is:

1. orientation-card logic
2. spine and support ring
3. bridge doctrine

The tested lanes are:

- [Persia](../../README.md)
- [America](../../README.md)
- [China](../../README.md)

## Shared Invariant

All three lanes now share the same canonical route:

```text
Helix -> current state carriers -> transaction drafting
```

All three also share the same bounded sub-bench entry logic across:

- `state/`
- `civilization/`
- `empire/`
- `transactions/`

This is the reusable invariant.

## Adaptive Difference

The proof of learning is not the shared invariant. It is the difference in what each lane treats as its governing ambiguity.

| lane | lane identity | bridge ambiguity | native proof anchor |
| --- | --- | --- | --- |
| Persia | recognition, dignity, leverage | recognition-first vs settlement-first | [Hormuz recognition transit transaction](../../codex/academy/statecraft/persia/transactions/hormuz-recognition-transit-transaction.md) |
| America | bounded command, burden-sharing, successor authority | bounded-command-first vs burden-sharing-settlement-first | [Digital identity continuity before platform control](../america/transactions/digital-identity-continuity-before-platform-control.md) |
| China | continuity, order, anti-chaos stabilization | order-preserving stabilization-first vs anti-coercion leverage-architecture-first | [Taiwan inspection pressure without blockade ownership](../china/transactions/taiwan-inspection-pressure-without-blockade-ownership.md) |

That table is the core result. The lanes no longer differ only by topic. They differ by what kind of statecraft problem they think they are solving.

## What The Audit Shows

### Persia

Persia remains the clearest leverage-and-recognition lane. The bridge clarifies whether the object is still about dignity and political legibility or already about settlement architecture.

### America

America now carries its own authority logic rather than reading only as a Persia counter-surface. The bridge clarifies whether the problem is still command legitimacy and review or has crossed into burden-sharing and successor-stable settlement.

### China

China now carries a third, non-overlapping posture. The bridge clarifies whether the object is still about anti-disorder stabilization or already about route, finance, and anti-coercion architecture.

## Membrane Result

The lane membrane is now stronger than before because each lane has:

- one shared route grammar
- one lane-native bridge ambiguity
- at least one lane-native proof anchor

The shared transaction layer remains useful, but it no longer bears the whole proof burden for America or China.

## Guardrail

The guardrail remains decisive:

```text
same pattern does not mean same lane
```

If future edits preserve the headings and route grammar but collapse the bridge ambiguity, native exemplar, or pressure vocabulary into one generic style, the recursive-learning proof fails.

## Current Lesson

Statecraft has now learned enough from `ph-civ` to reuse one pattern family across three different lane types:

- leverage-recognition
- bounded-command
- continuity-order

That is the first point at which the pattern can be treated as real statecraft architecture rather than an interesting Persia-only experiment.
