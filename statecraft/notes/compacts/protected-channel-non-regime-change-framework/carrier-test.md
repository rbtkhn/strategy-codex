# Protected Channel / Non-Regime-Change Framework - America Carrier Test

Purpose: test whether the protected-channel / non-regime-change framework has a durable America-side authority carrier rather than only a plausible clause set.

## Carrier judgment

The framework has a **real but composite** America-side carrier.

It does **not** survive as a purely presidential instrument.
It becomes plausibly durable only when several carriers are bound together:

- President / White House for public assurance and activation
- State Department for protected-channel designation and mediator handling
- Treasury for reversible visible sanctions relief markers
- Congress for notification, review, and successor-stable legitimacy
- mediator secretariat for breach logging, consultation, and quiet channel continuity
- allied liaison layer for reassurance and spoiler restraint

Short judgment:

`President starts it; State runs it; Treasury prices it; Congress legitimates it; mediator records it; allies keep it from fragmenting.`

## Carrier-by-carrier test

| Carrier | What it can credibly carry | What it cannot safely carry alone | Judgment |
| --- | --- | --- | --- |
| President / White House | public no-regime-change / no-partition assurance; activation signal; immediate crisis legitimacy | successor-stable durability; sanctions detail; spoiler restraint over time | necessary but insufficient |
| State Department | named protected carriers; mediator contact chain; diplomatic handling; deconfliction language | coercive override legitimacy; durable domestic permission without White House and Congress | strong operational carrier |
| Treasury | narrow reversible relief marker; escrow or technical waiver; administrative reversibility | political meaning of de-escalation by itself; broad settlement legitimacy | essential but subordinate |
| Congress | notification, review clock, legal-basis discipline, anti-drift legitimacy | fast activation in a crisis; quiet channel management | necessary for durability |
| mediator secretariat | breach record, confidential notice, consultation clock, witness role | sovereign enforcement by itself; domestic political carry in Washington | necessary external stabilizer |
| allied liaison layer | reassurance to Gulf / European partners; spoiler management; burden-sharing language | primary authority over U.S.-Iran bargain | supporting but important |

## Successor-stability test

The framework passes the successor-stability test only in a **medium** sense.

It can survive beyond one executive impulse if:

1. the public assurance is written, not merely rhetorical
2. Congress is notified and given a review role
3. Treasury's first-step marker is reversible and administratively legible
4. the mediator secretariat keeps a visible breach record
5. allies are explicitly placed inside the reassurance geometry rather than treated as spectators

It fails the successor-stability test if any of these become purely personal:

- personal presidential promise without written form
- one-off sanctions waiver without review clock
- secret channel without external witness
- no congressional reporting
- no allied reassurance language

## Main carrier bottleneck

**Main bottleneck:** Congress and allies must see the object as bounded command rather than disguised retreat.

The framework is already good at solving the Iran-side dignity problem in text. The harder America-side problem is preserving domestic and alliance legitimacy while forbidding the very coercive signals some actors treat as proof of command.

## Best carrier patch

Minimum America-side carrier package:

1. presidential public assurance in fixed written form
2. State-led protected-carrier designation with named mediator chain
3. Treasury-administered narrow visible relief marker
4. automatic congressional notification and short review clock
5. allied liaison consultation for reassurance and spoiler restraint

## Durability verdict

Status: `conditionally carriable`

This object is no longer blocked by lack of clause logic. It is blocked by whether Washington can bind enough institutional carriers together to make restraint look like command instead of weakness.
