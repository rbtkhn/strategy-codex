# Statecraft Notes

work only; not Record.

This shelf indexes **bounded statecraft analytical objects** generated by the statecraft machine.

Open [shared prose index](/C:/dev/strategy-codex/docs/prose-index.md) first when the class decision is still open. This README assumes the answer is already note-class and only explains the local statecraft version of that shelf.

## Formal Role

Use `statecraft/notes/` for bounded interpretive objects such as:

- bounded interpretive notes
- route notes
- mechanism notes
- bridge notes
- compact reflections
- exploratory or partial prose that still belongs to `statecraft/`

The local distinction is:

- a **statecraft note** preserves one mechanism, one route question, one threshold distinction, one audit object, or one comparison seam
- a **statecraft essay** carries a broader statecraft argument that should stand on its own outside the original routing context

Do **not** use this folder for:

- constitutional kernels
- journals
- indexes
- sheets
- bridges as structural systems
- transactions
- source-bearing archive material

## Local Test

If removing the surrounding machine context would break the piece, it is usually still a note.

Machine-constitutional files stay where they already belong:

- kernels stay in domain roots
- journals stay in journal surfaces
- indexes stay in index folders
- sheets stay in `sheets/`
- bridges stay in `bridges/`
- transactions stay in transaction surfaces

## Promotion Path

Most statecraft notes are promoted from:

- bridges when a comparison needs to become a bounded reusable seam
- audits when a workflow or maturity question becomes a local analytical object
- root or lane-local notes when one mechanism deserves preservation without widening into doctrine

Promotion to `../essays/` happens when the bounded object starts carrying a broader stand-alone claim rather than one local statecraft seam.

## Existing Likely Candidates

Some existing statecraft prose surfaces may later migrate here in bounded cleanup passes:

- compact route or mechanism notes now living at the root
- bounded interpretive notes attached to one lane or one bridge problem
- short machine-facing reflection notes that are not themselves doctrine

This first rollout is forward-only. Do not move existing prose here automatically.
