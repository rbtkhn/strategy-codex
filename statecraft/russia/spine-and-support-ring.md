## Core Spine

The canonical Russia lane spine is:

```text
Helix -> current state carriers -> transaction drafting
```

Read it this way:

1. [Russia helix](helix.md) restores the integrated line of strategic depth, recognition, leverage, deformation, and restoration.
2. [Russia state](state/) decides who can authorize, implement, restrain, bargain, or contradict the live move.
3. [Russia transactions](transactions/) converts the resolved lane object into spendable mechanism or clause language.

This is the honest main route. It should stay stable unless the lane itself is redesigned.
