# Lane-Hardening Law


Purpose: name when a statecraft lane has earned the bounded second-order surfaces that make it draftable without flattening it into a template.

## The Four Questions

### When does a lane earn orientation-card logic?

Use orientation-card logic once a lane's front doors have become high-density enough that cold-entry confusion is a recurring failure mode.

This solves: "I know this lane exists, but I do not know where this surface sits or when to return from it."

This is not: a reason to convert every file into a card.

`ph-civ` extraction: many objects do not need full cards, but many front doors need card logic.

Statecraft reuse rule: add bounded-entry sections to lane benches when operators keep arriving at the right folder through the wrong surface.

### When does a lane earn spine and support ring?

Use spine and support ring once a lane has one real canonical route but too many equally-plausible side openings.

This solves: "Everything looks useful, so nothing feels primary."

This is not: a redesign of the lane's underlying doctrine.

`ph-civ` extraction: keep one canonical route stable and let support material strengthen it without competing with it.

Statecraft reuse rule: declare the main route once the helix, carrier, and transaction sequence has become the actual working line.

### When does a lane earn a bridge?

Use bridge doctrine once the lane repeatedly fails at one posture threshold that routing alone does not resolve.

This solves: "Ownership is clear, but the next interpretive move keeps splitting in the same place."

This is not: another router and not a substitute for lane drafting.

`ph-civ` extraction: when two layers are often confused, name the bridge and give it doctrine.

Statecraft reuse rule: add a bridge only when one recurring ambiguity keeps producing the wrong next surface or the wrong mechanism family.

### When does a lane need a native proof anchor?

Require a native proof anchor once a lane risks proving itself only through shared cross-lane bundles.

This solves: "The doctrine sounds lane-specific, but all the proof objects still belong somewhere else."

This is not: a ban on shared exemplars.

`ph-civ` extraction: support can stay shared, but the main route needs its own carrying surface.

Statecraft reuse rule: every mature lane needs at least one local exemplar that expresses its own governing ambiguity without default dependence on another lane's crisis.
