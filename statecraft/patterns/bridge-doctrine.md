# Bridge Doctrine

## Problem It Solves

Statecraft surfaces often fail when two adjacent layers are both relevant but the operator has no explicit transition rule between them.

## When To Use

Use bridge doctrine when:

- two layers are repeatedly confused
- the real uncertainty is transition posture, not raw ownership
- the operator needs a named handoff rather than another generic note

## What It Is Not

- not a substitute for lane drafting
- not a generic cross-link
- not a license to keep drifting between layers without return discipline

## `ph-civ` Extraction

```text
when a threshold matters, name the bridge and give it doctrine
```

## Statecraft Reuse Rule

A bridge note should say:

- what uncertainty triggers it
- what it chooses or resolves
- where it returns once the uncertainty is cleared
- what mistake it exists to prevent

If the surface cannot answer those four questions, it is probably not a real bridge.
