# Orientation-Card Logic

## Problem It Solves

Dense statecraft surfaces often need a fast entry interface before the operator is ready for a full memo, transaction, or comparative pass.

## When To Use

Use orientation-card logic when a surface is:

- a real entrypoint
- dense enough to confuse first contact
- bounded enough to summarize honestly
- still downstream of deeper source or drafting authority

## What It Is Not

- not a substitute for the underlying note set
- not a mandatory file class
- not a demand to import `ph-civ` YAML or card formatting into statecraft

## `ph-civ` Extraction

```text
bounded interpretive entry can be more useful than exhaustive opening prose
```

## Statecraft Reuse Rule

Give the surface a compact entry shape:

- where this sits
- reading posture
- pressure points
- limits of the frame
- return path

Reuse the logic, not the exact artifact form.
