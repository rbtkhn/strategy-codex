# Statecraft Recursive-Learning Patterns

WORK only; not Record.

Purpose: hold the reusable drafting and routing laws that `statecraft/` has extracted from prior recursive-learning events.

This layer is not the journal. The journal records when statecraft learned. This folder records what was learned in a reusable form.

## Use Rule

Open this folder when the question is:

- what reusable pattern should shape a new statecraft surface
- whether a lane or shelf is mature enough for a bounded second-order interface
- how to adapt a proven pattern without copying its source corpus literally

## Pattern Set

- [Orientation-card logic](orientation-card-logic.md) - bounded entry logic for high-density surfaces that need fast interpretive access
- [Spine and support ring](spine-and-support-ring.md) - one canonical route plus strengthening material that does not overload the core line
- [Bridge doctrine](bridge-doctrine.md) - explicit transition objects for layers that are often confused in practice
- [Lane-hardening law](lane-hardening-law.md) - the compact operator rule for when a lane has earned bounded entry, route discipline, a bridge, and a native proof anchor
- [Doctrine-hardening law](doctrine-hardening-law.md) - split architecture, routes, continuity hypotheses, and interpretation before promoting corpus-level doctrine
- [Essay membrane law](essay-membrane-law.md) - three essay tiers (constitutional · history sub-lens · hexagonal demonstrator) for multi-term civ-state volumes; prep-before-encode routing sequence

## Journal Distinction

- [Recursive learning journal](../recursive-learning-journal.md) = durable log of learning events
- `statecraft/patterns/` = reusable laws extracted from those events

If a pattern has not yet survived adaptive reuse on a second object, it belongs in the journal first, not here.
