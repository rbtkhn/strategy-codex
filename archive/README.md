# Archive

This is the repo-root **legacy freeze and preserved-snapshot** layer.

`archive/` is **not** the live source-capture owner for repo-root systems. It exists so historical bundles, freezes, and old residues can remain accessible without teaching active routing.

**Grace-Mar fork freeze pointer:** [`grace-mar-frozen.md`](grace-mar-frozen.md) — operator-archived cognitive fork; doctrine in [`docs/grace-mar-instance-boundary.md`](../docs/grace-mar-instance-boundary.md).

Use this tree for:

- preserved companion freezes
- legacy user or system snapshots
- deprecated export bundles
- historical residues kept for archaeology rather than active use

Do not use this tree for:

- new live `statecraft/` source captures
- new live `singularity/` source captures
- continuity notebooks
- synthesis notes, essays, bridges, or drafting surfaces

Routing law:

- use [`source-archive/`](../source-archive/README.md) for canonical full-source captures intended for active downstream use
- use [`codex/`](../codex/README.md) for chronology, accumulation, days, threads, and open loops
- use [`statecraft/`](../statecraft/README.md) and [`singularity/`](../singularity/README.md) for synthesis, routing, interpretation, notes, essays, bridges, and judgment-bearing outputs

This is a one-way preservation surface, not an intake lane.
