# GitHub rename: civ-emp → civ-state

Operator procedure for the public repository rename (Phase A).

## Steps

1. Open **https://github.com/rbtkhn/civ-emp/settings**
2. **General → Repository name** → enter `civ-state` → **Rename**
3. Verify redirect: `https://github.com/rbtkhn/civ-emp` → `https://github.com/rbtkhn/civ-state`
4. Push exported book content from strategy-codex staging:

```bash
# From strategy-codex repo root
python scripts/export_civilizational_statecraft_public.py
python scripts/validate_civilizational_statecraft_public.py

# Clone or use existing civ-state worktree, copy runtime/artifacts/civilizational-statecraft-public/* 
# Commit reshape v0.2 + tag v0.1.0
```

5. Update local remotes:

```bash
git remote set-url origin https://github.com/rbtkhn/civ-state.git
```
