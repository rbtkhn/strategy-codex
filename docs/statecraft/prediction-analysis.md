# Prediction analysis — disagreement and timeline

work only; not Record.

## Two disagreement modes

Generated by `python3 scripts/build_prediction_disagreement.py` into [`runtime/artifacts/prediction-disagreement.json`](../../runtime/artifacts/prediction-disagreement.json).

### Prediction-level disagreement

Counts **every** prediction note per event.

Answers: *What did the archive contain?*

### Latest voice-level disagreement

Counts only each speaker's **latest** stance per event (by `date_made`, tie-break `file`).

Answers: *What do the voices currently think?*

This avoids overweighting prolific speakers.

## Disagreement score

Gini-style impurity over the four stance buckets:

```text
raw_score = 1 - Σ(p_i²)
```

Normalized:

```text
normalized_score = raw_score / 0.75
```

Maximum raw score with four stances is `0.75`.

Both scores are in `[0, 1]`.

## Timeline

Generated by `python3 scripts/build_prediction_timeline.py` into [`runtime/artifacts/prediction-timeline.json`](../../runtime/artifacts/prediction-timeline.json).

Per event:

- **`entries`** — all predictions sorted by `date_made`
- **`latest_by_speaker`** — most recent stance per speaker
- **`shifts`** — consecutive stance changes within the same speaker/event pair

Repeated identical stances do not produce shift records.

## Shift taxonomy

| Transition | Type |
| --- | --- |
| `yes` ↔ `no` | `flip` |
| `yes`/`no` ↔ `conditional` | `qualification_shift` |
| anything ↔ `uncertain` | `certainty_shift` |
| other distinct changes | `stance_change` |

Hard **flips** (`yes` → `no`) are analytically distinct from **qualification shifts** (`no` → `conditional`) and **certainty shifts** (→ `uncertain`).

## v1 limitations

Not supported in v1:

- probabilistic scoring
- Brier scores
- horizon weighting
- automatic event creation
- automatic resolution
- visual dashboards

See [event-system.md](event-system.md) and [prediction-metrics.md](prediction-metrics.md).
