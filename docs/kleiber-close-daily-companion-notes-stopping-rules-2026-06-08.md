# Kleiber Close - Daily Companion Notes Stopping Rules - 2026-06-08


Replication pass of the **2026-06-01 Hormuz** Kleiber shape on a different substrate:
**daily synthesis contract repair** instead of transcript phrase repair.

## What This Family Taught

```text
validator contract repair needs stopping rules as much as tail-label detection
```

The gain was not only renaming nineteen headings.

The gain was allowing **one error class** to end honestly while **forty-one unrelated validator errors** remained visible and named.

## Shape Used (Hormuz Parallel)

```text
detect clearly   -> before audit (19 files, 15 visible tail errors)
repair narrowly  -> one mechanical rename only
name remainder   -> quote-anchor, section-order, five-volume, monthly tranches
stop when proved -> zero `Statecraft Notes` grep + zero tail validator errors
```

## What Made Closure Possible

- one bounded audit family ([before](../runtime/artifacts/daily-synthesis-audits/statecraft-companion-notes-tail-audit-before.md))
- one bounded direct repair (heading rename)
- zero reviewed exceptions
- one post-repair artifact proving tail remainder is zero ([after](../runtime/artifacts/daily-synthesis-audits/statecraft-companion-notes-tail-audit-after.md))

## Anti-Patterns Avoided

- widening into quote-anchor repair because adjacent errors were visible
- claiming the full `validate_statecraft_daily_synthesis` backlog is closed
- stopping with “headings look better” and no post-repair count

## Best Line

```text
the contract repair pass is finished when the named error class hits zero
and every other class is listed as an explicit next tranche
```

## Falsifier

```text
If any migrated daily under statecraft/synthesis/day/ regains ## Statecraft Notes
or the validator again reports unexpected daily trailing sections for that label,
this close did not hold.
```
