## What clicked

- The real failure was not Git itself; it was a broken publication line. Once the canonical checkout, remote mode, and worktree ownership were made explicit, the sync path became legible again.
- Worktrees are fine for coding lanes and terrible as an accidental publishing surface. Raw-input needs one home, one branch posture, and one verification rhythm.
- A tiny guard script is more valuable here than another long explanation because it can falsify the "maybe it landed somewhere else" fear before another session gets consumed by it.

## Friction / questions

- HTTPS push from this environment still behaves inconsistently when credentials are needed, so the human shell remains the most reliable final publication surface.
- There are still large unrelated local modifications across the repo; raw-input publication discipline has to stay scoped or it will get tangled in that ambient noise again.
