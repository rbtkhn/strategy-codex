# Source-hygiene packets

**Purpose:** A source-hygiene packet is a compact WORK-layer packaging move for a live seam that is strategically useful but not yet clean enough to compose directly into `days.md`, a weave, or a stronger notebook judgment.

Interpretive companion: [packet-before-synthesis-doctrine.md](packet-before-synthesis-doctrine.md) - use the doctrine note for packet-first tempo, dual-register maturity, and anti-flattening judgment; keep this file for packet shape and procedure.

**Output shape:** usually a **pair**:

- one **refined page** that extracts the seam’s reusable mechanism, process, or register
- one **source-hygiene note** that states what is primary, what is commentary-tier, what still needs pinning, and how the seam should be reused

This is **not** a Record artifact, **not** a gate substitute, and **not** a claim that the underlying facts are already settled.

## When to use this

Use a source-hygiene packet when all of the following are true:

1. the seam is strategically promising enough to preserve
2. the underlying object is still mixed in evidence quality
3. later composition would benefit from a prebuilt evidence boundary
4. you want something stronger than a raw-input receipt but lighter than a full promoted page

Typical triggers:

- a strong interview whose **framework** is better than its factual pinning
- an **X cluster** with real process value but weak primary closure
- a high-rhetoric lane whose **register** matters, but whose claims cannot yet be loaded as fact

## Core rule

The packet’s job is **not** to prove the seam true. The packet’s job is to make the seam **reusable without tier confusion**.

If the packet makes later work flatter, louder, or more certain than the source can support, it failed.

## Required sections

### Refined page

Use this shape:

1. `Verbatim`
2. `Reflection`
3. `Foresight`
4. `Appendix`

The refined page should:

- summarize the seam in readable prose
- preserve attribution
- name the seam’s actual value
- state the right future use
- link back to the raw-input SSOT

### Source-hygiene note

Use this shape:

1. `What is primary here`
2. `What is commentary-tier, not fact-tier`
3. `What needs external primary pinning before heavier reuse`
4. `What we can reuse now`
5. `Best next use`
6. `Boundary`

The source-hygiene note should:

- distinguish attributed claims from notebook-safe facts
- state exactly what is still unpinned
- tell a future operator how to reopen the seam safely

## Three packet shapes

### 1. Mechanism packet

Best when the main value is structural explanation.

Use when:

- the analyst’s causal chain is the real prize
- factual rungs are mixed or still need receipts

Example:

- [pape-page-2026-04-29-youtube-pape-grim-nuclear-iran-inevitable.md](../../../codex/2026/pape/pape-page-2026-04-29-youtube-pape-grim-nuclear-iran-inevitable.md)
- [pape-source-hygiene-2026-04-29-pape-grim.md](../../../codex/2026/pape/pape-source-hygiene-2026-04-29-pape-grim.md)

### 2. Process packet

Best when the main value is bargaining language, sequencing, or diplomatic shape.

Use when:

- the seam explains how a negotiation or ceasefire is being named
- the underlying event chain is thinner than the process insight

Example:

- [parsi-page-2026-04-21-x-ceasefire-hormuz-cluster.md](../../../codex/2026/parsi/parsi-page-2026-04-21-x-ceasefire-hormuz-cluster.md)
- [parsi-source-hygiene-2026-04-21-ceasefire-hormuz.md](../../../codex/2026/parsi/parsi-source-hygiene-2026-04-21-ceasefire-hormuz.md)

### 3. Register packet

Best when the main value is voice, red-line language, or legitimacy framing.

Use when:

- the lane is high-rhetoric but still strategically informative
- the voice itself is a signal, but should not be laundered into fact

Example:

- [marandi-page-2026-04-21-blockade-islamabad-hormuz.md](../../../codex/2026/supporting-voices/marandi/marandi-page-2026-04-21-blockade-islamabad-hormuz.md)

## Placement rules

- Put the packet in the **lane that actually owns the seam**.
- Do **not** create a new taxonomy shelf just for the packet.
- If a lane still lives on an older shelf shape, add the packet there rather than silently migrating the whole lane mid-pass.
- Add one **light pointer** from the lane’s README, consolidation note, or thread surface when useful.

## Non-goals

A source-hygiene packet should **not**:

- become a stealth `days.md` compose
- claim quote-grade fact closure without primaries
- merge commentator language with official language
- erase tension between voices by summarizing too smoothly
- replace raw-input SSOT

## Minimal operator test

Before calling the packet done, ask:

1. What can I now reuse safely?
2. What still absolutely needs pinning?
3. If someone reopened this seam in two weeks, would they know where the danger is?

If the packet does not answer all three quickly, it is still too loose.
