# Voices supersede minds — migration doctrine (2026-06)

WORK only; not Record.

**Status:** For active strategy-codex operator workflow, **`statecraft/voices/<speaker>/<speaker>-profile.md`** is the **canonical SSOT** for named-speaker identity, linguistic register (Tier A detailed fingerprint), role/contrast pointers, and in-voice emulation discipline.

**`strategy-expert-*-mind.md`**, **`CIV-MIND-*.md`**, and **`docs/skill-work/work-strategy/minds/`** are **compatibility surfaces** during migration — **not** the primary read path for new sessions.

## What replaced minds (for new work)

| Old (compatibility) | Use instead |
|---|---|
| Read **`strategy-expert-<id>-mind.md`** first for in-voice register | Read **`statecraft/voices/<speaker>/<speaker>-profile.md`** `#linguistic-style-fingerprint-detailed` when Tier **A** |
| **`CIV-MIND-*.md`** as corpus body | **Redirect only** → mind file → **voice profile** (do not duplicate) |
| **`work-strategy/minds/README.md`** as entry hub | **[`statecraft/voices/README.md`](../../../statecraft/voices/README.md)** § Speaker profile law |
| Mind § IV as structured register SSOT | Profile 8-family tables; mind § IV = **frozen quote bank** until rows migrate, then archive |
| “Mind pass” / “tri-mind lens” vocabulary (legacy) | **Voice pass** — one named **speaker profile** or **statecraft-multi-lens** |

## Read order (agents)

1. **`statecraft/voices/<speaker>/<speaker>-profile.md`** — Identity, Tier A/B fingerprint, convergence/tension, failure modes, orthogonality links.
2. **Archive slug** when a claim must be transcript-grounded — `source-archive/statecraft/…`, not mind prose.
3. **`strategy-expert-<id>-mind.md`** — **only** when profile is Tier **B** (no detailed section yet) **or** operator explicitly asks for extended quote bank lines not yet in the profile table.
4. **`CIV-MIND-*.md`** — stable redirect links only; never treat as a second SSOT body.

## What is **not** deprecated (yet)

- **Mind file bodies** as **read-only migration residue** and extended quote storage until profile Tier A absorbs rows.
- **Historical** notebook / demo references to “CIV-MIND” or “mind pass” in archived prose.
- **Speaker names** (Mercouris, Mearsheimer, Barnes) — only the **mind-file SSOT role** is superseded by **voice profile**.

## Migration notes for operators

- **Promote Tier A** on a speaker before freezing the mind file; migrate role/contrast and Family 8 orthogonality into profile + shared SSOT (see [`_scratch/triad-voice-orthogonality-june-2026.md`](../../../statecraft/voices/_scratch/triad-voice-orthogonality-june-2026.md) for B×M×Me).
- **Do not** add new structured register tables to mind files — add rows to the voice profile.
- After Tier A is stable: mind file head → **redirect stub** pointing at canonical profile (pattern: [`codex/speakers/mearsheimer/mearsheimer-profile.md`](../../../codex/speakers/mearsheimer/mearsheimer-profile.md)).
- **`tri-mind`** remains deprecated separately — [TRI-MIND-DEPRECATED.md](TRI-MIND-DEPRECATED.md).
