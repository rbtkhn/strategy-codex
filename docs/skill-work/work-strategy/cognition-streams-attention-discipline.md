# Main uploads vs suspected clips as attention discipline

The split between **main uploads** and **suspected clips** is not just housekeeping.

It is a small discipline about **attention**.

The daily pass is meant to answer a bounded question: what deserves first strategic notice today?

That question is distorted if the notebook gives equal visual weight to:

- full interviews or monologues
- short excerpts
- teaser fragments
- promotional repackaging

So the split is a way of preserving proportion.

It says:

- full uploads usually deserve first look
- clips may still matter
- but clips should have to **ask** for attention rather than receiving it automatically

That is why the skill uses a conservative keep bias instead of a hard suppression rule. The point is not to pretend clips never matter. The point is to stop them from silently setting the day’s agenda.

In that sense, the filter is a restraint device. It protects the notebook from confusing:

- packaging for signal
- repetition for importance
- excerpt velocity for genuine daily movement

So `main uploads` versus `suspected clips` is best understood as an operator attention policy: first look goes to the most likely primary daily objects, while borderline items remain visible but secondary.
