# Arc Lens Usage


Arc lenses are recurring WORK-layer routing and synthesis handles. They help sort new Ukraine/Europe inputs into durable analytic questions without treating the tag or lens as a truth claim.

## Current Arc Tags

- `arc:peace-leverage` - use when a source materially updates what terms remain available as battlefield, industrial, fiscal, or political facts accumulate.
- `arc:capacity-gap` - use when a source materially updates the gap between Western strategic language and execution capacity.
- `arc:proxy-patron` - use when a source materially updates the patron/client problem: continued support, burden transfer, exit management, or client exposure.

## Tagging Rule

Tag daily inputs only when the source materially updates an arc. Do not tag routine repetition, background noise, or material that merely mentions Ukraine, NATO, Europe, sanctions, or ceasefires.

A single inbox item may carry multiple arc tags only when it genuinely updates multiple arcs.

## Boundary

Arc tags are not Record facts, not source verification, and not truth labels. They are grep-friendly handles for later WORK-layer synthesis.

Do not retroactively tag old inbox rows unless the operator explicitly asks for a backfill pass.
