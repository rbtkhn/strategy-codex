# Predictive History review packets

Use this file when `strategy-codex` is reviewing work from the external [ph-workshop](https://github.com/rbtkhn/ph-workshop) repo.

For the broader ownership and migration summary behind this packet contract, see [../../predictive-history-boundary-handoff.md](../../predictive-history-boundary-handoff.md).

## Packet contract

Each packet should include:

- scope: what changed or what is being reviewed
- source pointer: commit, PR, file path, or pasted excerpt origin
- review goal: editorial, structure, source discipline, or strategy resonance
- bounded payload: diff, snapshot, excerpt, or short file set

## Good packet shapes

- one PR diff plus 1-3 review questions
- one file snapshot plus a source-discipline check request
- one chapter outline plus structure critique request
- one prediction-tracking artifact plus strategy resonance request

## Default outputs from strategy-codex

- editorial critique
- structure feedback
- source-discipline warnings
- strategy-notebook commentary

## Non-goals

- no direct patching of Predictive History from this repo
- no regeneration of external PH artifacts here
- no reactivation of `continuity/predictive-history/` as a canonical lane
