# Reader-facing `CIV-MEM Context` block template

Use this as the portable template for the visible CIV-MEM block that should
appear near the top of a Predictive History lecture or chapter.

## Placement

Recommended placement:

- after title and basic metadata
- after or beside any short orientation note
- before long transcript density, deep exposition, or chapter body

It should be close enough to the top that it changes how the reader enters the
unit.

## Job of the block

This block should:

- place the unit in a larger civilizational frame
- tell the reader what kind of object this really is
- identify the main historical or institutional logic
- direct attention without pre-empting the whole argument

It should **not**:

- duplicate the `At a glance` summary
- become a full analysis memo
- collapse into one vague line

## Target length

Default target:

- 1 compact paragraph
- plus 2-4 short labeled lines or bullets if needed

Ideal total size:

- roughly 90-180 words in normal cases
- shorter for low-fit units
- slightly longer only when the context is structurally central

## Standard shape

```markdown
## CIV-MEM Context

[Short paragraph that places the lecture/chapter in a larger historical arc.]

- **Primary object:** ...
- **Dominant slots:** ...
- **How to read this unit:** ...
```

Optional fourth line:

- **Limit note:** ...

## How it differs from `At a glance`

`At a glance` answers:

- what the lecture/chapter says
- what happens in the argument
- what the immediate subject matter is

`CIV-MEM Context` answers:

- what larger civilizational object the unit belongs to
- what arc or structure surrounds it
- how the reader should frame the material while reading it

Compressed distinction:

- `At a glance` = topic and argument
- `CIV-MEM Context` = historical-civilizational frame

## Reader guidance rule

The block should end by shaping the reader's mode of attention.

Good endings:

- read this less as isolated commentary than as a map of a larger system
- watch for the institutional seam beneath the event narrative
- notice that memory and legitimacy are doing more work here than immediate
  tactical detail

The block should help the reader **carry a frame** into the rest of the unit.
