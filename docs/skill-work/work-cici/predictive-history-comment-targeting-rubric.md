# Predictive History Comment Targeting Rubric

WORK only; not Record.

## Purpose

Use this rubric to decide which Predictive History YouTube videos deserve comment effort first.

The goal is not backlog completion. The goal is to place high-quality comments where they are most likely to create serious reader curiosity and visible engagement.

## Ranking Dimensions

Score each target from `1` to `5`.

| Dimension | What it asks |
|---|---|
| Theme fit | Does the video connect cleanly to a strong Predictive History pattern or doctrine line? |
| Audience quality | Is the likely audience serious enough to notice a good comment? |
| Comment freshness | Is the thread still alive enough for a new comment to be seen? |
| Leverage | Would a good comment here improve recognition more than average? |
| Bridge potential | Can the comment naturally point toward deeper `ph-civ` curiosity without sounding promotional? |

## Priority Buckets

### Tier 1 - immediate targets

Use first when:

- score is `20+`
- the video is recent or still actively commented on
- the topic is central to Predictive History's strongest themes
- the comment opportunity feels specific rather than generic

### Tier 2 - good backlog

Use when:

- score is `15-19`
- the video is still relevant but less alive
- the topic is useful but not the strongest possible bridge

### Tier 3 - low urgency

Use only if:

- score is below `15`
- there is a special strategic reason to comment
- or the comment model already works and you are expanding coverage deliberately

## Fast Exclusions

Do not prioritize a video if:

- the thread is effectively dead
- the topic is too generic to support a lecture-specific comment
- the likely audience is low-fit for serious Predictive History readers
- the comment would only add generic praise
- the best available comment would sound like marketing

## Default Rule

If two targets are close, choose:

- the one with the stronger lecture-specific angle
- then the one with the more active thread
- then the one more likely to attract readers rather than casual drive-by engagement
