# Singularity-Academy First-Response Handling

non-authoritative. This is an operator reply-routing sheet, not a script to use blindly.

## Purpose

Handle first replies to the AI Operating System Sprint without improvising away the offer.

The point is to route the response toward:

- packet
- call
- proposal
- parked
- lost

## Use order

When a reply arrives:

1. classify the response type
2. choose the smallest honest next step
3. update the outreach log
4. update the pipeline stage

Use with:

- [Singularity-Academy First-Wave Outreach Log](singularity-academy-first-wave-outreach-log.md)
- [Singularity-Academy Sprint Prospect Pipeline](singularity-academy-sprint-prospect-pipeline.md)
- [Singularity-Academy Sprint Discovery Call](singularity-academy-sprint-discovery-call.md)

## Response types

### 1. Curious but vague

Signal:

- `interesting`
- `tell me more`
- `what does this look like`

Route:

- send the short page or packet
- ask whether one recurring workflow already comes to mind

Reply shape:

```text
Happy to send the short version.

The sprint is intentionally narrow: one recurring workflow, one reporting or review layer, and one clearer boundary around what AI may do versus what still needs human judgment.

I will send the one-pager. If one workflow already comes to mind on your side, that will tell us quickly whether a short call makes sense.
```

Next stage:

- keep at `reply` until the packet is sent
- move to `call` only after a real workflow conversation starts

### 2. Ask for the one-pager

Signal:

- `send the page`
- `send more detail`

Route:

- send:
  - [Singularity-Academy Sprint External Packet](singularity-academy-sprint-external-packet.md)
  - the matching target packet
- add [Singularity-Academy Sprint FAQ](singularity-academy-sprint-faq.md) only if the reply shows practical confusion, price friction, or uncertainty about what the sprint is
- ask for a short call only after they have the packet

Reply shape:

```text
Absolutely. I am sending the short packet plus a tighter note on why I thought the fit might be real.

If the shape looks close after that, the best next step is a short workflow call to decide whether there is one real workflow worth scoping.
```

Next stage:

- `reply`, then `call` if they accept the bounded ask

### 3. We already use AI heavily

Signal:

- `we already have AI everywhere`
- `this is not new for us`

Route:

- narrow to review, trust, and reuse
- do not widen into general AI consulting

Reply shape:

```text
That is actually the intended fit.

The sprint is not for teams starting from zero. It is for teams where AI is already active, but one workflow still depends on hidden trust work, rescue, or review that is harder to see than the generation layer.

If there is one workflow where that is true, a short call will tell us quickly whether the sprint is relevant.
```

Next stage:

- `reply`
- move to `call` only if one workflow can be named

### 4. We need software, not a sprint

Signal:

- `we want tooling`
- `this sounds like consulting`

Route:

- hold the line on bounded install first
- frame software as a later decision from evidence

Reply shape:

```text
That may be true eventually.

The reason I start with the sprint is to make one workflow legible before anyone commits to a larger tool or automation build. The output is a clearer reporting, review, and authority layer, plus evidence about what should and should not become software next.

If that first proof step is useful, we can tell quickly on a short workflow call.
```

Next stage:

- `parked` if they only want software procurement now
- `reply` if they are open to a proof-first step

### 5. Too early / not now

Signal:

- `not a priority`
- `too early`
- `come back later`

Route:

- do not push the call
- ask for timing only if the note is warm

Reply shape:

```text
Understood.

The sprint only makes sense when one workflow is painful enough that a 30-day intervention would matter. If that changes later, I am happy to reconnect.
```

Next stage:

- `parked`

### 6. Price friction

Signal:

- `too expensive`
- `budget is tight`

Route:

- clarify base sprint first
- do not discount immediately

Reply shape:

```text
That is helpful to know.

The smaller entry point is the `$2,500` base sprint, which is designed for one workflow only. If even that is too large for the current pain level, then it is probably better to park this than stretch the scope or the promise.
```

Next stage:

- `parked` or `call`, depending on whether the smaller package is real

### 7. Clear no

Signal:

- explicit no fit
- no workflow pain
- wrong timing and no interest

Route:

- close cleanly

Reply shape:

```text
Thanks for the clarity.

That helps. I will treat this as a no-fit for now rather than keep pushing something that does not match your current workflow.
```

Next stage:

- `lost`

## Call routing rule

Offer the call only when at least one of these is true:

- the prospect can name one recurring workflow
- the prospect asks how the sprint would fit their team
- the packet produced real curiosity rather than polite interest

If none of those are true, do not force the call.

## FAQ routing rule

Do not send the FAQ by default.

Use it only when the reply implies:

- practical questions about how the sprint works
- price confusion
- uncertainty about what would actually happen during the 30 days

If the reply is simply positive and asks for more, default to:

- [Singularity-Academy Sprint External Packet](singularity-academy-sprint-external-packet.md)
- the matching target packet

## Proposal routing rule

Do not send the proposal template before the call.

Use:

- [Singularity-Academy Sprint Proposal Template](singularity-academy-sprint-proposal-template.md)
- [Singularity-Academy Sprint Proposal Cover Notes](singularity-academy-sprint-proposal-cover-notes.md)

only after:

- workflow is named
- authority blur is named
- package fit is obvious enough to scope

## Objection capture

When a reply contains resistance, translate it into one of these:

- fit problem
- framing problem
- package problem
- timing problem
- proof problem

Then log it in:

- [Singularity-Academy Sprint Prospect Pipeline](singularity-academy-sprint-prospect-pipeline.md)

## Failure signal

If replies keep pulling you into:

- generic AI education
- software procurement
- abstract futurism

then the outreach or targeting is drifting away from the real wedge.
