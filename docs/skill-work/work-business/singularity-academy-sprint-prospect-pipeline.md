## Pipeline rule

This sheet is for close-fit prospects only.

If a prospect is so distant that the first sentence must explain the whole philosophy of `singularity-academy`, they are probably too cold for the first wave.

## Stage definitions

- `idea` = plausible fit, not contacted
- `sent` = outreach sent
- `reply` = meaningful reply received
- `call` = workflow call scheduled or completed
- `proposal` = base or premium sprint clearly offered
- `won` = paid sprint closed
- `lost` = explicitly not moving
- `parked` = maybe later, but not active now

## Fit heuristics

Score higher when the prospect:

- already uses AI weekly or daily
- has one recurring workflow with obvious blur or rescue burden
- values review, trust, or reuse
- can buy a small sprint without procurement drag
- is close enough to trust a bounded experiment

Score lower when the prospect:

- wants generic AI education only
- wants autonomous execution first
- needs enterprise security theater before any trial
- cannot name a recurring workflow

## Minimum weekly review

Once per week answer:

1. how many close-fit prospects are active?
2. how many meaningful replies came back?
3. did anyone understand the offer quickly?
4. which objection is dominant?
5. is the `$2,500` or `$5,000` package sounding more plausible in the market?

## Failure signals

Rerank the offer if:

- nobody understands the workflow problem being sold
- everyone likes the theory but resists the service shape
- all prospects want custom software instead
- the premium package sounds implausible even to strong-fit buyers

## Success signal

The pipeline is healthy when at least one prospect moves from `call` to `proposal` without requiring the offer to become generic AI consulting.
