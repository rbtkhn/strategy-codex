# Singularity-Academy Sprint Receipt Template

non-authoritative. Reusable closeout receipt for one sprint instance.

## Purpose

Capture the minimum durable evidence that a sprint actually happened, what changed, and where the boundary still held.

## Receipt template

```text
singularity_academy_sprint_receipt
client={name}
workflow={one workflow in scope}
package={base sprint|proof-loop sprint}
window={YYYY-MM-DD to YYYY-MM-DD}
status={completed|narrowed|stopped}

before_summary={one sentence}
after_summary={one sentence}

workflow_clarity_before={1-5}
workflow_clarity_after={1-5}
proof_clarity_before={1-5}
proof_clarity_after={1-5}
review_visibility_before={1-5}
review_visibility_after={1-5}
authority_clarity_before={1-5}
authority_clarity_after={1-5}
reuse_before={1-5}
reuse_after={1-5}
reentry_before={1-5}
reentry_after={1-5}

artifact_1={path or pointer}
artifact_2={path or pointer}
artifact_3={path or pointer}

what_changed={one or two concrete gains}
what_stayed_weak={one or two weak points}
operator_note={where rescue still existed or where the boundary mattered}
next_step={one recommended next move}
```

## How to use it

- pair it with the scorecard
- keep the `what changed` line concrete
- if the sprint was narrowed or stopped, say so plainly

## Good receipt behavior

Good:

- `authority_clarity_before=2`
- `authority_clarity_after=4`
- `what_changed=the team now uses one weekly brief with explicit proof fields and operator review`

Bad:

- `AI transformation complete`
- `team is now autonomous`
