# Root Layer Routing

Use this note when you need the shortest truthful routing rule across the repo-root storage and output layers.

## Root Stack

- [`archive/`](../archive/README.md) = frozen preservation of legacy or inactive materials
- [`source-archive/`](../source-archive/README.md) = canonical full-source captures intended for active downstream use
- [`continuity/`](../continuity/README.md) = chronology, notebook accumulation, days, threads, and open loops
- [`statecraft/`](../statecraft/README.md) and [`singularity/`](../singularity/README.md) = synthesis, routing, interpretation, notes, essays, bridges, and judgment-bearing outputs

## Routing Law

- use `archive/` for preserved freezes, historical bundles, and non-live holdings
- use `source-archive/` for full source objects that active systems will consume
- use `/codex` for continuity, accumulation, and dated notebook memory
- use `statecraft/` when the object is judgment-bearing, legitimacy-bearing, or statecraft-native
- use `singularity/` when the object is acceleration-, agency-, substrate-, or alignment-native and has not yet matured into a statecraft judgment object

## Practical Distinction

The shortest distinction is:

- `archive/` remembers what is preserved
- `source-archive/` preserves what live systems still read from
- `/codex` remembers what the work has been building over time
- `statecraft/` and `singularity/` turn those lower layers into live analytical output
