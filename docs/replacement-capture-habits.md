## Outside work (normal — not a failure mode)

Most of a live day is **not** repo work until something lands on disk. These beats are **outside the work membrane** by default.

| Beat | Membrane class | Default action |
|------|----------------|----------------|
| **Read / watch / scroll** without capture | External consumption | None |
| **Judgment in head** before you choose a fork | Operator cognition | None until you pick a lane |
| **Harness / warmup / handoff paste** in chat | Runtime / derived | Read for orientation; not policy |
| **Frozen Record read** (`self.md`) | Record (read-only) | **fork revive only** to write |

**Short rule:** *No governed surface + no git audit → not work — weather or life.*

Full class grammar: [work-membrane-v2.md](work-membrane-v2.md).

## Read but do not ingest

Use when material is useful for the session but **not** worth verbatim retention.

**Do not:** force `source-archive/` capture “because we looked”; stage gate candidates for ambient reading.

**Optional breadcrumb:** one line in [`self-memory.md`](../self-memory.md) short horizon — continuity only, not Record.
