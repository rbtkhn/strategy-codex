## Daily challenge structure (outline)

| Day | Human | Agent | Log |
| --- | --- | --- | --- |
| 1 | Define one micro-workflow goal + scope limit | Execute one step | Review: approve/reject |
| 2 | Tighten guardrail from Day 1 failure | Execute two steps | Exception note |
| 3 | Add escalation owner | Multi-step attempt | Intervention % |
| 4–6 | Peer accountability check-in | Daily micro-task | Done/stuck (ADOPT pattern) |
| 7 | Summarize before/after | Final run | Challenge completion cert (internal only) |

**Hybrid pattern:** Human defines goals/guardrails → Agent executes → Human reviews/escalates → Mutual improvement loop (matches Builder module).
