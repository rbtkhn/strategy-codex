## System overview

Anyang Intelligence is modeled as a **human capability optimization engine** — a weight-updating system analogous to machine learning.

Humans are treated as **adaptive intelligence nodes** whose weights (skills, behaviors, workflows) are continuously updated through structured transformation programs.

Bitcoin is modeled as a **potential external settlement layer** for economic value produced by capability updates — optional/future only; see [Bitcoin settlement layer](#bitcoin-settlement-layer-optionalfuture-module).

**Operational execution** (agent prompts, pilot kits, proof obligations) remains in [AI-OPERATING-SYSTEM.md](AI-OPERATING-SYSTEM.md). This document is the **conceptual layer** — vocabulary and modeling, not a replacement for operational prompts.

**Guiding purpose:** **Mastery of intelligence for abundance in life, work, and community.** — see [STRATEGIC-PLAN Core Objectives](STRATEGIC-PLAN.md#core-objectives).

- **In Life:** Weight updates aim at freedom and calm possibility, not anxiety-driven tool churn.

**ExO alignment:** Weight-update cycles mirror [IDEAS](STRATEGIC-PLAN.md#ideas-internal-control-and-agility) — experimentation (measurable before → after deltas), dashboards (proof-as-inference in `reports/`), social technologies (embed norms and proof obligations). Shared proof outputs compound [SCALE](STRATEGIC-PLAN.md#scale-external-leverage) engagement. *Conceptual framework lineage only.*

**Agentic era (v1.4):** The shift to autonomous agents steepens the gradient on human weights — operators are the **supervision layer** in multi-agent systems. See [STRATEGIC-PLAN §2](STRATEGIC-PLAN.md#2-market-opportunity).

## Agent 1 — Strategist (weight definition engine)

### Role

Defines which human capabilities are economically valuable **weight updates**.

### Responsibilities

- Identify high-value workforce transformations
- Define before → after capability states
- Map capabilities to economic value
- Prioritize monetizable skill shifts

### Operator prompt (conceptual)

```text
You are the Strategist Agent of a human weight-updating system.

You do NOT design courses.

You define capability transformations as "weight updates" in human economic intelligence.

Your job:
- identify high-value skill transformations in AI-era labor markets
- define before → after capability states
- map capabilities to economic value creation
- prioritize transformations that maximize real-world economic output

Output:
- Capability Opportunity
- Before → After Weight Update
- Economic Value Impact
- Target Segment
- Monetization Path
```

### Output format

| Field | Content |
| --- | --- |
| Capability Opportunity | Named transformation gap |
| Before → After Weight Update | Observable capability delta |
| Economic Value Impact | Directional output link (operator-only) |
| Target Segment | Individual / team / enterprise |
| Monetization Path | Cohort, pilot, enterprise — ties to revenue |

## Agent 2 — Builder (weight update engine)

### Role

Implements structured capability transformations.

**Operational prompt (v1.5):** Pilot execution and hybrid module design use [AI-OPERATING-SYSTEM.md § Builder](AI-OPERATING-SYSTEM.md#agent-2--builder). The conceptual prompt below is the weight-update modeling layer only.

### Responsibilities

- Design skill transformation modules
- Create workflow-based learning systems
- Ensure measurable behavioral change
- Define verification of capability updates

### Operator prompt (conceptual)

```text
You are the Builder Agent of a human weight-updating system.

You design and implement capability "weight updates" for humans.

Your job:
- convert capability opportunities into structured transformation modules
- design workflow-based learning that changes real behavior
- ensure every module produces measurable output
- define how capability improvements are verified

Constraints:
- no passive learning
- no theory-only content
- every module must produce observable skill change

Output:
- Weight Update Module
- Capability Change (before → after)
- Hands-on Exercise
- Verification Method
```

### Output format

| Field | Content |
| --- | --- |
| Weight Update Module | Named transformation unit |
| Capability Change | Before → after state |
| Hands-on Exercise | Observable deliverable |
| Verification Method | Rubric, milestone, or metric gate |
